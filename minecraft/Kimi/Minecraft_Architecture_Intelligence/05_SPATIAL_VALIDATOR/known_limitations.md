# known_limitations — Spatial Validator 已知盲区与易误报场景（P2）

> 诚实记录检不出/易误报的场景。凡此处声明的情形，校验结果中相关触发的
> confidence/basis 已相应标注；不要把这些触发当作确定缺陷。

## 1. 数据与建模边界

1. **蓝图不含地形**：参考蓝图通常只有建筑本体。凡"入口/楼梯底部悬在包络底界"的
   情形按隐含地面假设放行（`assume_ground` / `skip_bottom_at_envelope_floor`）。
   代价：真实世界中"门悬空在包络内半空"（非底界）仍会触发 V002，但底界悬空不会。
2. **洪泛 interior 语义的脆弱性**：带无玻璃窗洞、拱洞的建筑，内部空气会被洪泛
   判定为 exterior，导致 interior_stances 偏少。V001/V003/V004 的真实性依赖
   interior 判定；门/开口检测已不要求内侧必须是 interior（缓解了主要症状），
   但 connectivity_score 在这类建筑上系统性偏低。
3. **内部空间的"意图"不可判定**：密封装饰空腔（空心树腔、陵墓墓室、船底压舱、
   屋顶结构层）在几何上 = "无入口的封闭空间"。V001/V004 会触发。这是客观事实，
   是否缺陷取决于作者意图——静态分析判不出，已按 UNKNOWN 纪律保留触发并在报告中
   标注"歧义阳性"。
4. **机制类通道未完全建模**：
   - 关闭的铁门 = 阻挡（即使旁边有按钮/拉杆；红石机关语义不建模）；
   - 关闭的非铁质活板门 = 半格实体（玩家实际可翻开），舱口竖井部分由梯子边覆盖，
     但"活板门-楼梯交替"式紧凑竖井（REF-0006 实测）仍判堵；
   - 此类情形经"隔离环机制感知"降级为 WARNING（V003/V004），V005/V006 不降级。
5. **玩家能力近似**：不模拟跳跃（跳上 1 格不算可通行）、不模拟游泳、不模拟
   潜行通过 1.5 格空间。跑酷式设计会被判为断裂。

## 2. 规则级盲区

| 规则 | 检不出 / 易误报 |
|---|---|
| V001 | 无梯子的垂直天井口（纯开口上下层）不识别为入口；多开口大厅被洪泛吸收后，残留的封闭侧室触发 |
| V002 | 门外 2 格以外的台阶接近路径不识别；贴墙假门（装饰）会触发 |
| V003 | 主入口选错（多入口建筑）改变可达率分子；"出后门绕到侧门"在图上连通，不算不可达 |
| V004 | 1 格高爬空间无站位、不计；家具/地毯造成的建模外断连可能残留 |
| V005 | 建筑架空的塔楼底梯（底格 y>0 但下方无支撑）可能误报 |
| V006 | 顶部经关闭活板门的舱口出口判堵（可翻开）；螺旋梯环绕柱体的装饰纹理梯（埋顶）触发 WARNING |
| V007 | 楼层密度启发式把密实屋顶/树冠层误判为"楼板"（REF-0042/REF-0035 实测伪影） |
| V008 | 双开门逐扇判定，一扇被另一扇遮挡时可能误报 |
| V009 | "通道压抑"与"装饰性暗格/阁楼地板下空间"不可区分，触发率偏高（33%），仅 WARNING |
| V010 | 无玻璃开窗 = 真实泄漏，与围护断裂不可区分；通向洪泛 exterior 大厅的大缺口不计 |
| V011 | 天井/中庭（设计性露天室内）触发；全库 0 触发说明阈值保守 |
| V012 | 死端≠错误（壁龛/房间尽头），纯统计提示 |

## 3. 与 P1 的一致性声明

P2 校准修复了 walkability.py 三处（return_graph 新增、梯子同高程二部连接、栅栏门
可交互开启）。`02_BLUEPRINT_METADATA/blueprint_metadata.jsonl` 中的连通性字段
（walkable_components / isolated_space_count / vertical_connections 等）是**修复前**
模型计算的，与 P2 结果存在已知差异（梯子多的建筑分量数偏多、栅栏门两侧不连通）。
如需一致，重跑 `scripts/extract_blueprint_metadata.py` 即可（P2 未代为重跑，避免越权
改动 P1 已验收产物）。

## 4. 性能与适用范围

- 全库 123 张（最大 ~17 万体素包络）单批运行约 2 分钟内（Windows, py -3）。
- 包络超过工程上限（128 边）的蓝图未测；多 Region 仅 REF-0123 一张，已通过。
- Validator 只回答"有没有客观空间错误"，不评价审美/风格（那是 Critic 的职责）。
