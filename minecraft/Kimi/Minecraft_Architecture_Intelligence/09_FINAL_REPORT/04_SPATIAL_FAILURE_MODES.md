## 2. 误报迭代 0.829 → 0.496 的教训（校准轨迹）

| 迭代 | 关键修复 | hard_fail_rate |
|---|---|---|
| 0 | 初版 | **0.829** |
| 1 | 梯子同高程二部连接（REF-0005 守卫房漏接实测）+ 门内侧空气不限 interior + V005/V006 任一可进/可出 + 紧致性门控 | 0.659 |
| 2 | 门 facing 通行轴 + open 门轴旋转 + 包络底界隐含地面 | 0.626 |
| 3 | V001 内部站位门控（排除爬空间/结构缝隙）+ V008 排除全嵌墙装饰门 | 0.577 |
| 4 | V003/V004 机制感知分级（隔离环含门/活板门/梯子/栅栏门 → WARNING） | 0.529 |
| 5 | 舱口主入口 clearance 降 WARNING | 0.529 |
| 6 | 栅栏门可交互开启（修复 REF-0009 等一批梯顶误报）+ V005 入口语义 + V006 埋梯降 WARNING | **0.496** |
| 7 | 主内部分量锚定主入口 | 0.496（稳定） |

**五条工程教训**：
1. 初版 0.829 证实任务书预判——高硬失败率首先是**校验器问题**，不是库的问题；任何空间校验器上线前必须用真实库校准。
2. 最大的误报源是**语义定义**而非阈值：洪泛 interior 的脆性（无玻璃窗洞 → 室内被判 exterior）、"露天分量 ≠ 孤立房间"（屋顶/树梢天然分量曾贡献 V004 全库性误报）、"封闭空间 ≠ 缺陷"（装饰空腔/墓室意图不可静态判定）。
3. **机制语义必须建模**：栅栏门/非铁门可交互开启、活板门半格实体、梯子二部连接——每处修复都对应一批真实误报的消除。
4. **分级比阈值更重要**：机制感知分级（隔离环含可交互构件 → WARNING）让"模型无法分辨意图"的情形有了诚实出口，不虚构通过也不误杀。
5. 残余 0.496 的触发经逐条人工抽查为**真阳性/歧义阳性为主**，无系统性误报残留；所有不可判情形均已降级或在 known_limitations 声明。

## 3. "楼梯尽头是墙"族谱（Q1 的类型学回答）

该失败族在实测中呈现三个子类，可检测性不同：

| 子类 | 实例 | 可检测性 |
|---|---|---|
| **顶格被墙堵死 / 无净高** | 回归夹具 stair_top_blocked（顶端三面砌墙）必现；REF-0006 活板门压顶 | **确定性可检**（V006，OBSERVED 级；顶格在站位图无出边 = 数学判据） |
| **底格不可进入** | REF-0054/0056 装饰梯被栅栏围死 | 确定性可检（V005） |
| **楼梯通向无意义空间**（能站上去，但上去没有功能空间） | V4 C-before 第二段楼梯通向"只有小平台的第三层"——V005/V006 **均未触发**，当年由 Critic 语义审查发现（REMOVE 处置） | **不可确定性检测**，仍需 Critic/人工 |

根因归属（详见 `08_EVALUATION/B_VS_C_PIPELINE.md` §5.3）：**生成阶段缺乏全局可达性推理 = 主因；验证层无空间拓扑检查 = 放大器；方块施工与 preview 环节排除**（C-before 从未施工；终稿施工 9,478 坐标全量一致；preview 是 2D 可视化而非检查器）。
