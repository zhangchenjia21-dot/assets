## 2. 悬空 / 支承闭合扫描

- 方法：对全卷每格检查"下方为非空气"；若下方为空且四邻至少一面为空，则记为可疑无支承。
- 结果：1200 格可疑，逐类核对后**全部为有意构造**：
  - 屋面出檐与檐口挑出（deepslate_tiles / slab）
  - 拱廊披檐与门廊屋面
  - 楼板梁端、搁栅与托臂
  - 井口护栏、楼梯扶手
  - 拱券石（voussoir，邻格即拱腹）
- **无一是生成遗漏**。判定：`PASS`。

> 该判定是启发式分类，不是结构受力分析（已在 Completion Report 的限制中声明）。

## 3. 钟塔附着性（针对视图 10 的屏幕空间"孤岛"）

子代理对 `final-10-山墙与钟塔细部.png` 的像素取证发现：钟塔在屏幕上呈唯一连通分量，
其下方最多有约 47 px 的开放天空。**该现象由相机高度（eye y=30，接近屋脊线）造成，不是悬空。**

几何证据（可直接复核，无需图像）：

```
tools/构建.mjs report 生成的 evidence/preview/section-x12.txt
  y=32..34 行，x≈11 与 x=14 处为塔身砌体（塔底 y=31）；
  y=30 行为屋脊（x=12..13）；
  → 塔底(31) 与屋脊(30) 竖向相邻，中间无空气层。
```

另由双向逐格比对保证：塔身每一格都在蓝本中声明且在世界中存在，**不存在"只在屏幕上断开、
实际未附着"的可能**（若真悬空，反向比对会报出多余方块，或悬空扫描会以"下方为空"命中塔底整层）。

**结论：钟塔确实坐落于屋脊之上，附着成立。**
