# T01 研究与设计记录

本轮类型：LANDSCAPE / MIXED_ENVIRONMENT。原创园林，取苏州宅园的构成逻辑，不宣称复原某座历史园林或某年状态。

## 已实际读取的研究来源

1. 华盛顿大学《中国文明视觉资料》，Gardens：https://depts.washington.edu/chinaciv/home/3garintr.htm 。完整正文已保存。关键依据：园林从居宅院落发展；建筑与石、水、植物共同组织空间；围墙形成私人园域；观看以多处亲密尺度场景为主；明代江南特别发展。
2. 同课程 Garden Design：https://depts.washington.edu/chinaciv/home/gardesig.htm 。完整正文已保存。关键依据：江南城居文人、商人宅园是微缩自然；选址、水管理、植物和建筑需共同设计；四要素为石、水、建筑、植物。
3. Wikipedia, Humble Administrator's Garden：https://en.wikipedia.org/wiki/Humble_Administrator%27s_Garden 。作为辅助概览使用，正文已读取，页面版本 1366154414。采用的可交叉核实关系：南部居宅、池水与岛山相连、临水厅堂与游廊构成连续观景。不同历史阶段改造显著，因此不以现代平面冒充明代原貌。未采用条目中缺乏交叉核实的个别植物季节表述。

UNESCO、Met、Huntington 在前次尝试返回验证页；ChinaCulture 旧引用 URL 重定向到首页。以上不计为已读研究来源。

## 空间方案

- 园界约 184×148 格，西北山地、中央偏东主池、南侧入口小院、东侧竹院与水榭。围墙对应宅园边界，其规则性有功能依据；水岸、山径及植被不沿网格均布。
- 平面：由南门入园，屏墙迫使右转；到西南岸出现主水面；南岸听荷厅面水观岛；西岸山径连接山亭，山后路径回到北岸；曲桥到水心亭；东岸环路通水榭、竹院并返回南部。
- 剖面：超平坦自然地面 Y=63；池水方块 Y=62、池床 Y=61；常规路径表面 Y=63–65；竹轩基座 Y=67；山亭基座 Y=76；大冠树形成比低厅亭更高的背景。局部山石由预览发现遮挡后降低，保留回望方向。
- 序列：门厅和屏墙收紧 → 绕墙出院 → 水面展开 → 西岸叠石收紧 → 登高回望 → 北岸树下 → 曲桥水心 → 东岸临水 → 竹院停留 → 南院返回。
- 留白：主水面承载对景与倒映；入口铺地服务到达；南侧砾石疏林庭院服务厅后停留。西山林下留出路径与视线，不以均匀种树填满。
- 资产：已查询正式 asset-catalog 与 reference catalog。正式资产以中世纪建筑为主；参考树中有白桦、云杉、巨树、樱花等，但没有匹配本轮职责的成套苏州植被。采用任务内原创树、亭与山石，不进行正式资产晋升。

## 施工前修订

1. 首次 Macro 预览发现西岸裸土断崖，改成与山体相连的叠石岸。
2. 小亭改用较低的四坡屋顶，与长厅区别；侧面保持开放。
3. 南侧无明确用途的草地改为入口铺地与砾石疏林庭院。
4. 西岸叠石与路径相交，明确开出可走山径；西院入口改线避开屏墙。
5. 登山、山后下行及竹院高差位置采用石砖楼梯。
