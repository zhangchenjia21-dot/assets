## 只读复核

需要 Python、NumPy、Pillow；执行：

```text
python 检查实存.py 05-Water
python 检查完整性.py 05-Water
python 最终核验.py
python 渲染实存.py 05-Water
```

体素布局为 little-endian UInt16、shape `[52,240,288]`、索引顺序 Y/Z/X，世界原点 `[0,12,0]`。调色板在同阶段实存元数据中。渲染脚本可修改相机自行检查；Windows 字体路径需按本机调整。执行这些只读脚本不访问游戏存档。
