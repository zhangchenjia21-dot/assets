# T07 绿洲驿站：研究与施工方案

独立样本，MIXED_ENVIRONMENT。只使用当前任务、读取的 minecraft-builder v1.5、以下本轮资料及本轮世界。未读取 T01—T06 的评审、反馈、结论或施工脚本。Skill 原文保存在研究/技能原文-SKILL.md；不修改源 Skill。

## 研究及适用范围

- [Caravanserai](https://en.wikipedia.org/wiki/Caravanserai)：逐段读取 Function / Architecture / Variations。乡间驿站服务一日行程，安全入口、露天庭院、商旅房间、货物与驮畜空间；萨法维伊朗常见四伊万庭院、拱廊和突出门楼。本文引用学术建筑史，但本轮未直接读取所引书籍，不冒称第一手研究。
- [Qanat](https://en.wikipedia.org/wiki/Qanat)：读取 Features、Impact on settlement patterns、Construction。山麓冲积扇地下引水、检修竖井、出口后沿地势分渠；上游水用于生活，下游用于灌溉。现实微坡小于方块分辨率，末段以同标高封闭渠道表达，不造阶梯水片。
- [FAO Date Palm Cultivation, Chapter II, A. Zaid / P.F. de Wet](https://www.fao.org/4/y4360e/y4360e06.htm)：椰枣长期栽培，伊朗在分布带内，灌溉技术支撑绿洲种植，树干及叶片用于覆顶。只提取农业和材料事实，不采用文中宗教概述。
- [Tabas](https://en.wikipedia.org/wiki/Tabas)：核对地理部分，热荒漠中椰枣与柑橘绿洲的区域可行性；当代城市数据不用于复原历史布局。
- UNESCO 世界遗产页与 Iranica 返回 403，UNESCO Silk Roads 旧链接重定向栏目首页：不作为已读驿站建筑证据。

## 主目标与空间因果

原创的 17 世纪伊朗东部、塔巴斯区域语境的山麓小型绿洲驿站；不复原具体遗址。主目标是让穿越干燥荒漠的旅人抵达可补给、交易、休息的有水荫蔽节点。

约 288 × 240 格场地。北侧裸岩低脊与冲积坡、南西侧风积沙，中央砾质缓地承载驿站。地下引水末段从北侧出露，在生活取水之后分配至棕榈园和小块耕地。驿站偏东，避开水源及最高价值耕地。南来商路到门前卸载区，继续绕向东部出口；当地步道接市场、取水处、园地。驮畜外饮水与粪肥处理位于生活取水下游一侧。

Plan：东侧围合院驿站；西侧水池与棕榈园；南侧小市集、维修与烘烤；西南灌溉田；北侧引水检修地带。院内秩序来自围护与服务分间，不延伸为全场道路网格。

Section：超平坦沙质画布表面 y=15；核心自然缓地 y=20；池水方块 y=19，底 y=16；北侧脊高约 y=35；檐顶约 y=28，门楼最高约 y=38；棕榈约 10—15 格。入口不以高台抬升，驿站沿原规划砾地局部找平。

Sequence：南来干燥沙路 → 树冠与门楼远标 → 门前交易卸货 → 厚门洞压缩 → 大庭院释放 → 阴影拱廊 → 后部厩棚；支路经水屋与取水池 → 棕榈树荫 → 农田 → 北脊回望。屋面观景经明确实梯到达。

## 施工与检查

1. Macro：新世界与身份验证；沙地、低脊、冲积坡、水池渠底岸、结构棕榈、驿站大体量。保存后读取世界、斜视、剖面与尺度检查。
2. Meso：拱廊客房、厩棚、门楼与屋顶、道路接口、市场维修、农田及灌溉。检查入口净空、路线可达、空间关系、前序水体和墙体。
3. Micro：材料构造、铺地磨损、耕作、池岸湿生带、干旱地被和照明；复查支承、建筑外壳、路线、流体围护。若发现重大缺陷，限定范围修订。

执行器关闭邻接副作用，未提供受控流体 tick 接口。因此水采用同标高、实体床岸约束，最终单列 fluid stability unverified，不以静态连通冒充流体运行验证。截图优先实际存档读取的三维图；如无实机截图须清楚标注呈现方式与限制。
