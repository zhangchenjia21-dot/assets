# T08 独立建筑方案

任务 BUILDING。已完整读取当前 minecraft-builder v1.6，原文见研究/技能原文-SKILL.md；不修改 Skill，不读取 T01—T07 的评审、反馈、findings、Regression Report 或结论。

## 本轮研究

1. [English Heritage: Description of Rievaulx Abbey](https://www.english-heritage.org.uk/visit/places/rievaulx-abbey/history-and-stories/history/description/)：教堂东部修士与西部俗家兄弟使用区别；1220 年代东部重建及三层立面；回廊连接读书、参事、宿舍等空间。采用空间组织事实，不复制遗址，也不把毁坏状态当成完整建筑。
2. [Fountains Abbey](https://en.wikipedia.org/wiki/Fountains_Abbey)，Architecture：带侧廊的长中殿、十字交叉、东部礼拜空间；南侧回廊、东侧参事堂与上层宿舍；早期哥特与更晚塔体分期。仅选 13 世纪语境，不混入 16 世纪高塔。
3. [Gothic architecture](https://en.wikipedia.org/wiki/Gothic_architecture)，Pointed arches / Rib vaults / Flying buttresses：尖拱、四分肋拱顶、柱束与外扶壁的传力关系；英格兰偏重长度，飞扶壁使用较克制；柳叶窗适合早期哥特。

Met、Smarthistory 页面受限，Byland/Roche 指定地址为 404，不算已读研究来源。百科所引原著未直接阅读。

## 主目标

原创 13 世纪中期英格兰石砌修道院教堂。通过低入口前室、高中殿、低侧廊、横向耳堂、东部唱诗席/圣坛，以及南侧低回廊与两层宿舍的对比，表现集体礼拜与日常修道生活的不同尺度。主教堂长约 98 格，场地约 160×144 格，环境只做前院、进路及回廊草庭。

Plan：西入口在 X=30，沿 X 正向到东方；中殿中心 Z=56，侧廊分列南北；X=95 附近十字交叉；东端方形圣坛。南回廊可由教堂侧门进入，东翼下层参事交通，上层宿舍，经南端折返梯到达；参事堂从东廊横向进入，祭衣间邻南耳堂。

Section：原超平坦草面 Y=15，基础/室内地面 Y=17，由西端两级浅阶进入；侧廊檐约 Y=29、中殿墙檐 Y=43、主屋脊约 Y=55；肋拱顶在屋架下方形成独立内表面，窗带位于侧廊顶之上。交叉部只设较小钟楼及尖顶，避免把修道院教堂解释成双巨塔主教座堂。宿舍二层楼面 Y=26，独立折返梯；回廊檐约 Y=23。

Sequence：西进路 → 前室压缩 → 中殿纵向展开 → 柱列侧廊 → 十字交叉横向释放 → 唱诗席/东窗；支路从南侧门 → 回廊安静尺度 → 参事堂 → 宿舍楼梯。主要路线都以入口、净空和真实层高实现，不用传送替代交通。

## 阶段与质量门

Macro 建成结构性的主轮廓、屋顶和高低关系，实际保存后做无材质轮廓图、远中距透视与纵横剖面；完成 Massing Gate 后才继续。Meso 做中殿拱廊、拱顶、扶壁、柳叶窗、附属交通；Micro 做门窗收边、栏杆、少量陈设与必要场地。各阶段从存档读回并检查透视、内部体验、接口；最后核验屋顶、墙、楼板、开口、可达性及有意悬挑/意外孤立的区别。

本轮无开放水体。无需为了变化制造地形或园林。建筑为原创整体，不将不明作者的哥特资产拼装；本轮没有大型植被资产需求。实体图、剖面和统计只提供不同证据，不能单独代替建筑质量判断。
