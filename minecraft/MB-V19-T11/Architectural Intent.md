# T11 Architectural Intent

任务 BUILDING；单一 Scope：原创江户后期京都呉服商宅及使其成立的短街、两侧界面、中庭、后庭与附属仓储。目标 FINISHED，须通过 v1.9 Finishing Completion Gate。

1. **Purpose**：约 1840 年、下京一条商街上的中型呉服商，销售与批发购入的布匹，进行验货、丈量、折叠、包装和记账；不是把织造工厂塞进住宅，也不是复原杉本家。
2. **Users / Activities**：店主家庭、掌柜和少量住店伙计；顾客在前店看样、谈价，熟客可被引入后座敷。货物沿东侧土间进出仓库，不必经过洁净起居地板。家庭用餐、烹饪、休息和夜间收店有明确位置。
3. **Site / Context**：北面短街为出入口，东西地界紧凑；临街表屋遮蔽私宅，前后之间留小庭采光通风，后庭为座敷提供安静边界。只表达邻接街道与地界，不建完整街区或独立园林。（原文字误写南面；实际设计与施工始终为低 Z 的北街。）
4. **Program / Space Graph**：街→前店/土间；店→账房验货区→取合部→家庭起居→后座敷/缘侧→后庭。侧土间→厨房→后服务路→仓库/厕间。账房旁楼梯→表屋低二层→伙计休息与干货储物；顾客路线与货运可分流。
5. **Hierarchy / Sequence**：街面木格子与低檐形成尺度明确的接近；抬升一格的木地板划分鞋履与清洁面；前店相对开放，中段因庭光和转折安静下来，后座敷借缘侧面向后庭。厨房的高挑烟道与前屋低二层形成剖面对比。
6. **Plan + Section**：审计场地 56×96 格。商宅地界约 X12..39、Z17..88，前店 X13..37、Z18..33，取合部与中庭 Z34..43，居住主屋 Z44..63，后庭/服务 Z64..74，仓库 Z76..86。街/土间 Y16，居住地板 Y17；前屋二层地板 Y23，主要屋脊约 Y33。楼梯属于 Core，保留可真实站立的低二层净空，不机械照搬现实狭窄陡梯。
7. **Structure / Material / Technology**：木柱梁与土壁，局部石础，坡屋面瓦材转译为深灰石砖阶梯/半砖。表屋梁柱按房间与门口排布；厨房不设二层楼板，烟与热向高处逸出；仓库为独立厚抹灰体量。榻榻米、障子及格子需在 Minecraft 中可读，但不冒称真实抗火或抗震计算。
8. **Form + Minecraft Translation**：宽度和进深来自商宅活动链与采光庭，前后屋脊横向、侧土间连续、后仓库独立。放大门与楼梯宽度，使用半砖、栅栏、活板门等表达木细构；远景仍保持低密度屋脊，室内用房间、光口与地板序列表达身份。避免以大平面上几件道具代替正常游览距离的完成感。

## 施工前实际研究

- [杉本家保存会：住宅介绍与一层平面](https://www.sugimotoke.or.jp/about/)：30×52 米场地，临街店舗通过取合部联系居室的表屋造；厨子二阶、格子、通路兼作业的走庭、厨房和仓库。已查看其平面与室内照片。**现存主屋 1870 年重建，仅作延续江户类型的参照**，不当作 1840 年原件；不采用其洋间。
- [杉本家历史](https://www.sugimotoke.or.jp/about/%e6%9d%89%e6%9c%ac%e5%ae%b6%e3%81%ae%e6%ad%b4%e5%8f%b2/)：1743 年京都开业，1764 年购现址，1807 年支店，1864 年火灾，1870 年重建。用于确认商宅与经营网络的时间背景。
- [二条阵屋：公事宿万屋历史](https://nijyojinya.net/about/history/)：1840 年后米/兑换商记录，现存住宅嘉永年间重建，并有后期改造。用于确认江户后期京都商业与宅内接待的联系；其防卫机关与公事宿制度不移植到本呉服商。
- [京都市景观・町づくりセンター：京町家のいろは](https://www.kyoto-machisen.jp/machiya_iroha/)：京都市发行的建筑与生活入门资料，包含表屋造、一列三室与织屋建等不同类型。实际读取目录与出版说明，未将未读章节冒称已读证据。
