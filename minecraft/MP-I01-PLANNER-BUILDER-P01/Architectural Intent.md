# MP-I01｜下肩修理与值守户

**Purpose**：首卸后的小件修理、工具短储和日常值守，与一户生活共存。它不是矿石仓、冶炼厂或公共旅店。

**Users / Activities**：Builder以两名常住经营者试配一户；一人接单时另一人仍能进家、做饭、上楼或到私院。人数是设计假设，不是新Canon或Planner人口额度。顾客进入低修理翼，家庭从较高的独立入口进入。

**Site / Context**：仅在BDP-01的151列斜边地块内设计。东侧地面较高、来货方向在西；低翼地坪顶Y132，高主屋顶面Y133，北西侧余地作为折转家庭小院。没有抬平整片公院；公共路线缺线位/高程，外部对接保持HOLD。

**Program / Space Graph**：低修理间与高生活间通过受控一格高差短阶相连；生活间向上到两人寝层，向北到家庭院落。营业流不穿家庭私院。详见design/program-space-graph.json。

**Hierarchy / Sequence**：顾客先在低门前停留，再进入低而结实的石质作业间；家庭从高门进生活间，经北侧直梯升入安静寝层，或从北门转向后缘后再到西院。低翼与较高主屋的差别来自工/居剖面，而不是添塔造型。

**Plan + Section**：主屋外包8×6减一个转角列，低翼6×6减一个转角列，合计82列建筑占地。修理间净包络4×4；主屋每层净包络6×4，楼梯、栏杆和家具另扣。首层生活地坪顶Y133、寝层Y137；北侧单格宽直梯升4格，东端落脚再沿寝层南部通道分配到两铺。

**Structure / Material / Technology**：石质基础与首层承重墙，木楼层、上层木框架与土色填充；短跨屋架、拉梁和中柱承托硬质坡屋面。普通石木技术，不引入魔法供水或空间扩容。小件修理以台面作业为主，家用封闭灶具沿东墙接嵌入式烟道。

**Form + Minecraft Translation**：低翼屋脊顶Y139，主屋顶Y144，烟道顶Y145；主要门洞2格宽、3格高，北家庭门1格宽、3格高。内部楼层净高至少3格；楼梯按半格台阶构形。石砖、云杉木、土色填充和深板岩屋面承担不同构造角色，玻璃仅为窗位代理。没有将地块填满，也没有套用既有北岩台建筑。
