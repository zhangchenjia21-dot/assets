## 2. Premise：为何形成这个区域系统

矿业、冶金、石工和多个山地地方共同体是 Canon 方向。由此真正产生的是劳动者的生活、维修、工具和食物输入、产品交换、风险处理、地方协商，而非“一座矿都加若干工业区”的建筑清单。

北部接近上游中域接口，但约 70–110 格的上升并不廉价。台地相互分离，使常住与日常工作不能全靠下山完成。一个较可集中的交换服务点和一个较小的内部工作生活点，比将全部功能塞在上游代表点上更有理由。两者仍共同分享供给和外出联系，不能为了展示地方自治制造完全重复的机构配额。

东南距离更远。只有资源位置、饮水、当前生计和真实运输同时成立，才应维持常住。否则允许季节活动甚至没有节点。神圣／魔法存在不能替代饮水、燃料、食物和道路的普通条件。

土地与普通司法由地方掌握；共享服务或通道维护是本轮建议的协作关系，不是制定新政治制度。没有具体敌国或战争方向证据，因此安全需求限于保通、事故支持、污染隔离和维护，不布置预设前线要塞。宗教保持地方性和共享活动可能，不规定逐节点独立神庙。

**Premise Gate**：上述角色可在当前尺度作为关系／capacity/search proposal 成立；矿源和供给未知被明确保留为启用条件。没有把未调查实存标成 Greenfield。

## 3. 地形深化：从大搜索窗到候选口袋

原始数据库从获准 R1 gzip 重新解压到 `MP-P02-cache`，验证 SHA256。读取自然列与人工材料标记，不读人文 targets/assessments 或派生 k2/k3/k4/k5/zones。

口袋算法使用 8×8 聚合：整个单元为东岛陆地，至少 75% 柱满足 slope8≤0.20 且 relief32≤12；四邻接成组，至少六单元。这些阈值是分析假设，不是普适建筑坡度规范。共识别 36 个达到最小规模的候选口袋；面积是粗单元量，不是净可建地。

窗口中有 1,894 个东岛陆地柱带原调查人工材料标记。最初四个候选搜索窗分别有 24、8、129、0 个标记柱。标记可能受材料规则影响，既不能断言建筑存在，也不能忽略。阻力模型避开带标记的粗单元；选址仍要求重新检查整个搜索窗。0 个标记也不等于无人为实存。

搜索窗的低阻力柱统计分别约 17,343、8,664、8,529、5,203。它们不能直接相加得到可建容量：连续形状、坡缘、安全、饮水、人工实存和权属仍会扣减。规模图把绿色口袋单元和紫／棕／蓝面积符号分开画；没有把面积圆裁成“已经证明的建设地块”。

## 4. 交通阻力、候选路线与运输分工

本轮在原始地形上计算两组 8 格模型，均要求粗单元所有 64 柱为东岛陆地、无人工材料标记，且对角线不跨水角。边成本为 `length × (1 + 12 × grade²)`；分别比较 grade≤0.25 与 ≤0.50。它们是用于敏感性比较的**地形模型**，不是玩家、驮畜或前现代道路标准。

| 通道 | 较严模型长度／累计上升 | 较宽松模型长度／累计上升 | 规划含义 |
|---|---|---|---|
| C01 中域接口→N01 | 1,577／112 格 | 563／76 格 | 短线与缓坡不是同一个方案；对外交换需承担显著成本 |
| C02 N01→N02 | 456／42 格 | 420／43 格 | 北部两个簇有局部相互服务关系，非任意等距布局 |
| C03 N01→N03 | 模型未找到路 | 1,774／167 格 | 不经已撤销暂歇点；仍为条件远端链 |
| 已撤销的 N04 中转方案 | 未选择 | 两段共 2,594 格 | 比直接线多820格、约46%，故撤点；见比较证据 |
| 备选 N02→南部大口袋 | 模型未找到路 | 1,381／141 格 | 大片平地也不自动赢得城镇地位，保留比较而非第二个待建矿城 |

逐格回读沿线发现最大地面阶差 2–4 格。这明确反对“模型连通即 usable route”。均值路径仍未模拟路基宽度、头部净空、台阶、填挖、桥梁、地下空洞、权属及生物碰撞。严格模型无路也不证明所有工程方案不可能。

较严 C01 绕西侧低地再抬升，图上保留其真实弯绕；较宽松直捷方案留在证据数据和比较剖面中。下层应比较短线所需工程与长线运营代价，不机械照着任一折线铺路。不能用人为提高容许坡度来宣布上游路已验证。

食品、工具向内，山地产品向外，是长期骨架。矿种／燃料未知，初选、冶炼、锻造在哪一端只给条件比较：若减量收益高且有水燃料，可有近源处理；若燃料与水不足，则转运到条件成立的位置。没有“必须所有冶炼上山”的规定。

N01↔N02 是日常生活／维修与周期交换的混合关系；公众协商访问分享通达，但与危险生产装卸需要兼容。N03 仅小量、季节或条件流。服务腹地随实际资源、当地权利和可用通道交叠，不用最近距离生成独占行政分区。

北部总量由上游 6–14 千格²收敛为 **6–13 千格²**，拆分而非复制容量。东南含内部服务从 3–9 收敛为 **条件性的 3–6 千格²**；未启用为 0。两部分均成立时全案为 9–19 千格²，不能把这些全部当作现在已有的建成区。

容量仍为 LOW，因为来源不是实存人口或下层规划。算术透明保存在 `settlement-capacity.json`：

- N01：18–32 户压力 × 130–160 格²日常用地 + 1,660–2,880 格²共享服务 = 4,000–8,000。
- N02：10–22 × 120–150 + 800–1,700 = 2,000–5,000。
- N03：8–16 × 150–200 + 1,800–2,800 = 3,000–6,000，包含当地服务。
- N04：已撤销，0；区域内暂歇需求若成立，先嵌入既有活动，不凭空设固定中转点。

这不是人口 Canon、通用密度或详细地块指标，而是解释空间量级的假设。日常院落和内部通行已包含；完整矿场、农业、燃料林和水源保护不包含。口袋地形没有验证这些住户能吃喝生存，尤其不允许默许地图外无限输入。

如果供水或供应不足，先减规模、减少专用服务或周期化；如果区域角色完全失去条件，则退回本案或 parent 的最小受影响因果链。上限不是必须填满的指标。

**搜索窗≠建成区≠服务腹地**：搜索窗是下一层查证位置，圆是面积量级符号，腹地是资源／服务／权利的关系。山区形态预计碎片化、贴台地且不同密度；不是把面积圆推平。图 02/03 采用不同实际比例和比例尺，让各节点的规模仍可读。

## 6. Demand、Anchor、开放地与外部影响

详见 `demand-model.json`：五组需求涵盖生活与供应、地方协商、资源生产、条件停留和基础保障，每项有使用者、量级、频率、成熟度、邻接、外部影响和可能响应。

N01 是重复交换形成的 growth anchor；N02 的当期工作生计是 origin anchor；N03 只有条件成立才有 origin 作用；原 N04 没有证明服务收益足以抵消绕行，已撤销。移除 N03，远端支线及其服务需求必须同时消退。

开放空间不是填充装饰。水源与坡缘保护由当地共同体控制并服务下游用水／安全，持续不建是为维持生活；具体水源、排流和界线尚未知，不画假精确隔离区。公共交接与访问由参与共同体共享，日常和会集时使用，不能被常住地块或堆货侵占；其容量已经包含在节点服务面积内。

矿害、烟火、噪声和装卸对生活既有邻近便利，也有污染和安全负担。L2 应根据真实地形、水流和活动安排相邻／隔离关系，不从未知风向指定“下风工业区”。燃料林更新、食物供给和开采地目前没有范围证据，保留为输入条件，不能把所有未建山地等同可支配林地。

## 7. 历史逻辑与实施流程分开

`growth-sequence.json` 只给逻辑历史，不指定已发生的年表：

G1 当期生计／资源活动 → 生活工作簇 → 原路／权利惯性 → 交换压力。

G2 重复交换与跨坡损耗 → 北台地集中部分服务、内侧保留工作生活 → 共享对外接口 → 协作维护。

G3 地方间事务 → 公共访问分享北部服务链 → 权利与货运兼容 → 可选远端压力。

G4 仅资源、水、路、供给均成立 → 东南与暂歇需求 → 更长维护链 → 季节化、收缩或改线。

每一步在不知道未来的情况下都应可运作。没有用未来矿镇正当化早期道路，也没有虚构现存老路、旧墙、墓地或火灾。现状调查后应根据真实继承关系调整逻辑历史。

项目顺序则是本案审核 → L2 先查实存和生计/通道 → 收敛聚落形态与容量 → L3 等后续 Planner 递归，最后才可能 Builder。不是按历史 G1–G4 在世界中施工。本任务到本案交付停止。

## 8. Program、Kit 与 L2 交接

Program 从需求而非建筑数量产生，见 `building-program.json`。允许共享／嵌入日常生活、维修、协商、存储与照护；独立专用设施须由真实量级证明。本轮没有房间、精确 footprint、层数、街宽、屋顶或方块材料设计。

区域 Kit 只要求支持：贴台地的混合工作生活；不同高差的服务与公共入口；共同体之间而非单一城市内部的协作；生产污染与饮水安全分离；小规模日常与周期高峰的共享；局部维修和分期适配。Canon 的石构／挡土／垂直发展是能力方向，不能以一栋 Blueprint 克隆全域。

交付三个 `SETTLEMENT` Planner 包：

1. PACKAGE-01 北台地交换聚落：校准真实实存与服务容量，解决中域接收接口及内部活动。
2. PACKAGE-02 内侧生产聚落：先证资源或其它生计，形成工作／生活关系并与 N01 共享服务。
3. PACKAGE-03 东南条件聚落：只有启动证据成立才设计常住形态；N04 已撤销，不得按旧候选自动恢复。

每包具 UPSTREAM_FIXED、DOWNSTREAM_TO_RESOLVE、DOWNSTREAM_ADAPTABLE、REVISION_TRIGGER、三分空间、外部接口、跨包依赖、来源、期望 L2 图和数据。接收者均为 `minecraft-planner`，下一尺度 `SETTLEMENT`，没有 world-write 或直接 Builder 权限。

固定的是多个共同体、真实资源语义、公共访问／供给依赖、远端条件性。可调整精确地点、分簇、共享与专用服务、容量和季节性。无水或无生计、通道不能局部解决、实存冲突或容量数量级崩塌时，须报 `UPSTREAM_PLANNING_ISSUE`，只修最小受影响链，关联包标记 stale，不修改 Canon 或覆盖已归档父案。
