# MP-P03M｜本轮 Planner 自检

这是本方案的自检，不是回归判定或独立审核。只用本轮输入与产物。

| 检查 | 对本方案的具体检验与结果 |
|---|---|
| Counterfactual / Anchor Removal | 若没有中域日用品与地方产品的重复交换，共储交割院和服务家庭失去主要生计起因，不能只凭平岩台维持原容量。若普通供水无法闭合，常住阶段不得启用。 |
| Historical Validity | 首阶段只需要当前交割与协议，未为远矿或未来24户提前修建道路、保留大道；增长不发生也有当期用途。 |
| Terrain Necessity | 平地不需西侧分段驮运、高低水接口或碎片台面；把该方案搬到平地必须重做来向和服务组织。剖面只是诊断，路线未通过物理验证。 |
| Surface Character | 等高平土与本次岩面不同：后者依赖输入、保留土面、避免农业自给预设；B砂砾与浅空洞改变调查与占地次序，不机械减人口。 |
| Agency | 地方使用者能否允许共院、商旅能否承担运输、服务家庭能否负担供水决定空间；三席议会不自动征地。具体制度仍是假说。 |
| Knowledge | 地下空气为Planner-only；当地形成路径依赖行走、取水与试用。没有用未来矿点优化创建时道路。 |
| Mitigation | 井、蓄水、搬运与路工逐项列明条件、负担和残余；深岩巨井不能当普通工程。未把空洞全填或全禁，也未假设技术一定成功。 |
| Metabolism / Resilience | 粮食批入日耗、水日耗与旅人峰值分别影响储备和空院。储备应闭合补给间隔及可信中断；没有编补給量。共同与家庭库存缓冲单路依赖，不虚构备用通道。 |
| Feedback | 供水/路工吸引家庭与交割，继而增加拥挤、公共院和水压力；错峰与分点可以中止增长。 |
| Capacity | 3,500–8,000为低置信条件假说，首段3,500–5,000；公式、计数排除项与启用条件明示。没有以10,241列调查框证明净容量，也没有把下段当已可建设。 |
| Anti-Zoning / Parcel | 交割、修理、家庭与库存混合；清污接口和公共院不靠四色功能区解释。真实地权未定，不提前划整齐宅地。 |
| Recursive Handoff | 接收者为DISTRICT Planner，图外路线/供给需要区域协调；Q-W/R/S控制常住启动，Q-G/T控制占地冻结，Q-P控制上限。移位选择留给下层。 |
| Kit Clone | 未提供或复制整栋蓝图；只交适应和共享接口要求，Builder仍保留具体建筑工程设计权。 |
