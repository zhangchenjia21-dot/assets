# architecture

保存项目长期使用的数据解释、扫描交付与 Architecture Grammar。

## Current Architecture Authorities

- `地理事实层与空间ID契约.md`：自然地理事实层、空间对象与证据解释；
- `大型扫描数据交付与审核契约.md`：Local Raw Cache / Lightweight Review Bundle；
- `civilizations/CIV-001/Architecture-Grammar.md`：CIV-001 三域联盟第一套可执行建筑 / 聚落 Grammar。

Architecture Grammar 把 Owner-approved World Canon 编译成设计约束，但**不是具体建筑方案，也不是 Minecraft world-write 授权**。

具体建筑仍需：

```text
Architecture Grammar
→ exact Site Context
→ single-target design
→ Plan / Section / Sequence
→ critique / revision
→ explicit world-write authorization
```
