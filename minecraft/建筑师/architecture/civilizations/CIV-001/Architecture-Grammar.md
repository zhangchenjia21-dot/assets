## 1. 核心设计命题

CIV-001 的建筑不能只表现成“中世纪人类城镇”。玩家应能从空间本身读出：

> **这是一个由低岛、坡麓与高山组成，靠生产互补与长期协商维系的三域联盟。**

因此建筑必须同时表现：

1. 同一文明的共同构造传统；
2. 三域因地形、生产和社会组织形成的地方差异；
3. 前现代长期生长，而不是一次规划完成；
4. 真实功能、交通、地形与材料因果；
5. 少量但明确的幻想 / 魔法痕迹，而不是泛滥的奇幻装饰。

# 2. Shared Civilizational DNA｜共同文明 DNA

无论西 / 中 / 东域，都应保留以下共同亲缘。

## 2.1 构造语言

默认采用成熟 **石基 + 木构 / 石构** 体系：

- 建筑有可信地基、承重墙 / 柱、梁架、屋顶关系；
- 木构建筑优先表现石基、防潮基座、木梁 / 桁架与填充墙；
- 石构建筑优先表现墙厚、拱券、扶壁 / 挡土结构、真实开口比例；
- 屋顶不是薄片，应有檐、脊、排水和体量；
- 大体量建筑必须拆成主次体量、增建翼、院落或附属体，不做无原因巨大方盒。

## 2.2 长期生长感

CIV-001 建筑应像经历多年维修、扩建和功能变化：

- 允许不完全对称；
- 允许新旧墙体、附属棚屋、侧翼、院墙产生层次；
- 重要建筑可以有多个建设阶段；
- 不通过纯随机破损制造“历史感”，而通过结构变化与增建逻辑表现时间。

## 2.3 开口与立面

- 普通住宅开窗受结构与气候约束，不做现代大面积玻璃幕墙；
- 首层生产 / 仓储空间可以少窗、重门；
- 上层居住空间开口更灵活；
- 门窗必须与室内功能、楼层和结构对应；
- 装饰集中在入口、檐口、梁端、门楣、公共徽记、祭祀部位，不满墙堆符号。

## 2.4 色彩与材料层级

不要给整个文明一个死板固定 block palette。每个具体 Site 应根据真实地表、地方供应和建筑等级选择 palette。

共同规则：

```text
primary structural material
+ secondary structural material
+ roof material
+ infill / plaster / earth tone
+ restrained accent material
```

通常 2–4 种主材料控制大体量；高饱和、发光、稀有材料只作有限强调。

## 2.5 街道与地表

道路不默认方格化：

- 主路来自长期通行、市场、渡口、山口、神殿和生产节点之间的需求；
- 次路从主路生长；
- 平坦区可以较直，但不得为了整齐形成现代网格；
- 地面应区分主路、巷道、院落、作业面、泥土、碎石、草坡、农地等职责；
- 大片默认 grass_block 不能自动算完成设计。

## 2.6 公共空间

广场不是“留一块空地”。它必须有明确来源：

- 市集；
- 议事；
- 誓约；
- 神圣仪式；
- 装卸；
- 生产集散；
- 节庆。

尺度由实际使用人群与周边建筑决定，不建现代市政广场式超大空白。

## 2.7 宗教与魔法可见度

宗教：**中等可见**。

魔法：**低普及、中影响**。

建筑表现原则：

- 普通住宅不应处处出现魔法装置；
- 神殿、矿井、熔炉、桥梁、议会誓约空间可出现少量仪式 / 符文 / 保护性构件；
- 魔法结构仍应嵌入现实建筑逻辑，而不是漂浮水晶随处堆放；
- 任何特殊魔法设施必须说明功能。

# 3. West Domain Grammar｜西域

自然 / Canon 基础：低平 C 形岛，连续平缓空间多；主要承担农牧、人口、市场、手工业和联盟级公共功能。

## 3.1 Settlement morphology

优先形态：

- 农庄群；
- 沿主路 / 市集生长的村镇；
- 较大市场城镇；
- 联盟公共机构集中区；
- 农地—村落—市场连续景观。

平坦不意味着网格规划。聚落应围绕道路、市场、庄园、神圣空间、渡岸节点和长期地块边界有机增长。

## 3.2 建筑体量

- 普通住宅：低至中层、横向展开；
- 商住混合：临街较密，上住下作 / 下店；
- 农庄：主屋 + 仓房 + 畜舍 + 围院；
- 公共建筑：允许更宽、更高，但需要院落 / 广场 / 道路作为空间支撑；
- 天际线以屋顶群为主，少数公共 / 宗教建筑形成节点，而不是尖塔森林。

## 3.3 材料倾向

- 木石混合；
- 石基；
- 木梁与浅色 / 土色填充墙；
- 沙质 / 砂岩材料可作为地方性补充，但不能机械把整个西域做成沙漠建筑；
- 屋面应适合大面积住宅、仓库和农庄的可重复建造。

## 3.4 生产景观

允许主动建设：

- 农田；
- 牧场；
- 果园；
- 谷仓；
- 磨坊；
- 围栏 / 土墙；
- 小型灌排；
- 手工业院落。

这些是未来 `IMPLEMENTED_VISIBLE_RESOURCE`，不要求天然存档已经存在。

生产景观必须进入聚落布局，而不是镇子造完后在外围随便铺矩形田。

# 4. Middle Domain Grammar｜中域

自然 / Canon 基础：东岛西侧低地—坡麓过渡；跨岛与山地之间的连接层；承担接驳、仓储、商贸与加工。

## 4.1 Settlement morphology

优先形成：

- 水岸接驳聚落；
- 坡麓市场镇；
- 转运 / 加工街区；
- 沿上山通道生长的混合城镇。

具体港口、码头、正式道路必须经过 Site observation；当前 crossing / landing 只提供候选约束。

## 4.2 空间特征

中域应该是三域中**功能最混杂、空间最紧凑**的地方：

```text
岸边装卸
→ 仓储
→ 市场 / 客栈
→ 加工作坊
→ 坡麓道路
→ 山地入口
```

街道应受高差、货物流和岸线共同塑造，而不是复制西域市场镇。

## 4.3 建筑体量

- 石基 + 木构上层较常见；
- 仓库首层高、门洞大、立面更实用；
- 商住 / 客栈可以向上增加层数以节省平地；
- 坡地建筑允许错层、半地下层、挡土墙和后门高差；
- 屋顶群较密，街巷空间更强。

## 4.4 建筑类型

高优先：

- 仓库；
- 商栈；
- 客栈；
- 转运场；
- 金属 / 石材初加工工坊；
- 市场厅；
- 关卡 / 门楼（仅当地形与制度需要）；
- 旅行 / 渡海圣所。

# 5. East Domain Grammar｜东域

自然 / Canon 基础：面积巨大的高起伏山地主岛核心；平地少；富矿；石质材料强；地方共同体强。

## 5.1 Settlement morphology

禁止平原城市模板。

聚落优先依附：

- 山谷；
- 缓坡；
- 天然台地；
- 山腰平台；
- 矿井口；
- 通行鞍部；
- 少量高地防御点。

一个“东域城镇”可以由多个高程层次的建筑簇组成，而不是一个平整地块。

## 5.2 Terrain response

必须充分使用：

- 挡土墙；
- 台阶；
- 顺坡街道；
- switchback / 折返；
- 跨沟桥；
- 石阶；
- 半地下建筑；
- 建筑基座与山体咬合。

大范围推山填谷属于失败模式。

## 5.3 材料与结构

倾向：

- 石材为主；
- granite / basalt / stone / terracotta 等可以按具体 Site 选择地方 palette；
- 木材用于屋顶、楼层、悬挑、门廊和内部结构；
- 厚墙、拱券、挡土、石阶形成结构辨识度。

不要把“山地富矿”翻译成满城裸露矿石方块。

## 5.4 生产建筑

允许形成：

- 矿井口；
- 矿工聚落；
- 选矿 / 堆料场；
- 熔炉与锻造区；
- 石匠工坊；
- 采石场；
- 山地仓库；
- 氏族生产院。

矿业景观应该表现物流：矿井 → 初选 / 堆料 → 冶炼 / 加工 → 仓储 → 外运。

## 5.5 社会建筑

东域地方共同体的重要建筑优先包括：

- 氏族大厅；
- 地方议事厅；
- 祖先 / 山地圣所；
- 矿业祭祀空间；
- 防御性公共仓库。

它们通常比普通住宅更重石构、更长寿，也可能成为聚落地标。

# 6. 三席议会与联盟政治中心 Grammar

Owner referent：**西部平岛的中心岛**。

当前 `COORDINATE_TBD`。在机器映射与 Site observation 前不得擅自定坐标。

## 6.1 核心空间语义

该中心不是王宫，而是**三域共同拥有的联盟政治 / 仪式空间**。

建筑必须表达：

- 三方都有独立身份；
- 中央空间属于联盟本身；
- 没有王座型单一权力轴；
- 进入 / 等候 / 协商 / 宣誓 / 公告 / 接待具有真实流程。

## 6.2 三席议事建筑

默认空间原则：

- 三方席位围绕共同空间，而不是全部朝向一个统治者；
- 三个代表方向在体量 / 门厅 / 徽记上可以辨识，但不要求机械三等分；
- 中央议事空间可采用三向、环绕或围院关系；
- 重要视线应落向联盟象征、共同天井、誓约物或公共中心，而不是王座。

## 6.3 政治中心可长期形成的建筑群

未来可逐目标建设：

1. 三席议事大厅；
2. 联盟誓约 / 仪式空间；
3. 三域代表馆；
4. 档案馆；
5. 联盟金库；
6. 域际裁判 / 仲裁建筑；
7. 外交接待建筑；
8. 市场 / 公告空间；
9. 渡岸 / 到达设施；
10. 历史纪念性构筑物。

**不得一次任务把上述全部粗糙铺满。** 继续遵守 single-target high-quality 原则。

## 6.4 议会岛景观

议会建筑需要整体公共景观，但不要现代“行政园区”：

- 路径来自到岸、市场、代表馆、议事厅之间的真实流线；
- 可有共同誓约广场 / 庭院，但尺度克制；
- 结构性树木、庭院、岸线、坡地应参与构图；
- 不做对称镜像三栋楼 + 大草坪的现代政府园区。

# 7. Settlement Generation Rules｜聚落生成规则

Codex 设计任何 CIV-001 聚落时必须先回答：

1. 为什么在这里形成聚落？
2. 最早的 anchor 是什么：水岸、道路、矿井、市场、庄园、圣所还是防御点？
3. 后续增长往哪里发生，为什么？
4. 生产如何进入聚落？
5. 主路和次路分别服务什么？
6. 哪些空地必须保留，为什么？
7. 地方权力中心在哪里？
8. 普通人如何从住宅到工作 / 市场 / 圣所？

如果回答不了，不应先画街区。

## 7.1 Parcel / 街区

- 地块大小应随功能变化；
- 商业街更密；
- 农庄更宽；
- 工坊需要作业院；
- 山地地块受台地和坡面约束；
- 不做均匀矩形 plots。

## 7.2 Density gradient

聚落内部应有密度梯度：

```text
核心公共 / 市场节点
→ 较密住宅 / 工坊
→ 边缘生产 / 农庄 / 山坡建筑簇
→ 自然地形
```

具体题材可改变顺序，但不得整片均匀散布。

# 9. Plan / Section / Sequence Requirements

AB-001 下的重要建筑 / 聚落必须继承 minecraft-builder v1.2 的三层检查。

## Plan

明确：建筑、道路、生产、水岸、院落、地形和公共空间之间的关系。

## Section

明确：

- 地形高差；
- 基座；
- 楼层 / 檐口 / 屋脊；
- 山地台阶 / 挡土；
- 水岸标高；
- 乔木树冠与天际线。

东域和中域若没有有效 Section 思考，不允许进入施工。

## Sequence

至少定义：

- 主要进入方向；
- 第一视线；
- 收紧 / 开敞；
- 重要建筑逐渐显露方式；
- 高差变化；
- 到达核心空间的体验。

议会建筑尤其需要设计三域代表 / 普通访客的到达与进入序列。

# 10. Landscape / Vegetation

CIV-001 不是园林文明，但植被仍是空间系统。

## 西域

- 农田、果园、防风林、道路树、庄园树群可以形成大尺度人造景观；
- 村镇边缘应有生产—居住—自然的过渡；
- 不把空地全部做成纯草坪。

## 中域

- 岸线、坡麓、道路边缘植被应服务视线、稳定感和空间过渡；
- 商贸核心不需要大量装饰性花园。

## 东域

- 山地植被不能按网格种；
- 建筑与岩体 / 灌木 / 少量树群形成层次；
- 矿业区可因长期使用形成裸地、碎石、稀疏植被，但不能把整座山“工业化清空”。

Structural Vegetation 属于 Macro / Meso；detail vegetation 后置。

# 11. Fantasy Expression Rules

CIV-001 的 Fantasy 感来源优先级：

```text
真实世界逻辑
→ 地方文化差异
→ 神圣 / 魔法功能
→ 少量超现实视觉
```

允许：

- 矿井保护符文；
- 冶炉温控 / 炼金设施；
- 誓约石 / 神圣火盆；
- 受祝福的桥梁节点；
- 少数发光矿物 / 仪式物。

避免：

- 无功能巨型水晶；
- 每座房子都有发光符文；
- 漂浮岛 / 漂浮建筑作为默认；
- 尖塔、紫色、金色、发光方块简单等同“Fantasy”。

---

# 12. Explicit Anti-patterns

以下默认视为 CIV-001 设计失败警报：

1. 方格化道路 + 等宽矩形地块；
2. 西 / 中 / 东域只是换 block palette，空间形态完全相同；
3. 山地城市先铲平再复制平原镇；
4. 住宅、仓库、工坊只有外壳，没有可达入口和功能空间；
5. 巨大无意义广场 / 草坪；
6. 每隔固定距离复制同一棵树 / 同一房型；
7. 建筑间距均匀，像现代郊区；
8. 用裸露 ore blocks 把“富矿”写在山体表面；
9. 议会大厅出现明显唯一王座轴；
10. 三席议会建筑机械 120° 镜像，只为了象征“三”；
11. 把中域自动称港口，把 corridor 自动铺成道路；
12. 一次 world-write 粗糙建设整个文明核心区。

# 13. Site-specific Compile Contract

任何后续具体建筑 Task 都必须在本 Grammar 之上增加 `Site Context`。

最低输入：

```text
target building / settlement type
+ domain: West | Middle | East | Alliance Center
+ exact site / bounds
+ local terrain observation
+ water relation
+ existing vegetation / artificial content
+ intended function / users
+ historical or real-world reference research when relevant
+ world-write authorization status
```

然后 Codex 才能把 Grammar 编译成具体方案。

不得从本文件直接生成“万能 CIV-001 房屋模板”无限复制。

# 14. First Canon Build Recommendation

AB-001 建议的第一批候选目标按项目价值排序：

1. **三席议事大厅**——最能测试 CIV-001 政治制度是否真正转化为空间；
2. 西域典型农庄 / 小型村落核心——测试普通生活尺度；
3. 中域商栈 / 仓储复合体——测试过渡型物质文化；
