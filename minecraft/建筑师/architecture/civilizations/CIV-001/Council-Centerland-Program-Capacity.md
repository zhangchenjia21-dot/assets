# Council Centerland｜Program / Capacity Plan

状态：**GPT PLANNING BASELINE / AWAITING OWNER CONFIRMATION**

适用对象：AB-001P1 Candidate A｜湾内中心低地 / Council Centerland。

本文件只做长期容量与空间预留，不是详细总图，不是 Build authorization。

## 1. 已知场地容量

AB-001P1 当前有效事实：

- Candidate A actual land columns：约 **105,785 blocks²**；
- actual bounds：X=-349..240，Z=1664..1982；
- median Y≈68；
- largest connected FLAT patch：约 **51,129 blocks²**；
- largest axis-aligned all-FLAT diagnostic square：**79×79 = 6,241 blocks²**；
- A 是东岛西伸低地的一部分，向东继续连接主岛；西 / 北 / 南面与湾水形成强空间关系。

这些值是容量依据，不等于可全部施工面积。

## 2. 规划原则

Council Centerland 不应被建成现代行政园区，也不应被第一座大厅占满。

长期目标：

> **形成一个前现代、逐步生长的联盟政治核心，建筑密度有限，保留大量开放地表、岸线、植被、路径与未来扩建余量。**

建议把整个 A 的使用分成三种尺度：

1. **Political Precinct Reserve**：长期政治核心可规划 / 管理的总范围；
2. **Built Footprint**：真正由建筑物占据的地面；
3. **Open / Buffer / Future**：广场、院落、路径、绿地、岸线、未开发与扩建余量。

## 3. 建议长期容量

### Political Precinct Reserve

建议长期联盟政治核心控制在：

> **约 22,000–32,000 blocks²**

约占 Candidate A 当前陆地面积的 **21%–30%**。

这不是连续方形地块，也不要求一次规划成规则边界；应随岸线、地形、进入关系和未来建筑逐步形成。

### 建筑总 footprint

建议成熟期全部联盟级建筑的合计 ground footprint 控制在：

> **约 6,000–9,500 blocks²**

即约占 A 陆地面积 **6%–9%**。

这样即使政治中心最终成熟，也不会把湾内中心低地建筑化到失去地形与景观特征。

### 开放空间 / 通行 / 景观

在 Political Precinct Reserve 内建议保留：

- **8,000–12,000 blocks²**：议事前场、仪式 / 集会空间、院落、步行连接、有限市场 / 等候空间；
- **4,000–7,000 blocks²**：结构性植被、地形缓冲、岸线过渡、视线与水边空间；
- **3,000–6,000 blocks²**：长期扩建与未定功能余量。

不要求把这些面积做成互不重叠的规则地块；它们是容量预算。

## 5. 三席议事大厅尺度推导

不再使用 `45×45` 方形 guard。

现实前现代大型公共厅堂提供的只是量级参考：

- Westminster Hall：约 73×20m；
- Palazzo Ducale Great Council Chamber：约 53×25m；
- Palazzo della Ragione 的 Salone：约 81×27m。

CIV-001 三席议事大厅无需复制这些建筑，也未必达到同等规模，但它作为整个三域联盟最核心的政治公共建筑，不应被预设成普通 town hall 尺度。

### 当前建议设计搜索区间

主体 ground footprint：

> **约 1,800–3,200 blocks²**

形态可优先探索：

- 长轴约 **50–75 blocks**；
- 短轴约 **26–42 blocks**；
- 可因三席围合、门廊 / 边厅、地形关系形成 L / U / 多翼或非规则外轮廓；
- 不要求落在单一全 FLAT 矩形内，可通过克制基座、台阶、挡土墙适应微地形。

这只是设计搜索范围，不是最终尺寸。

### 为什么这个量级合理

- 占 A 总陆地约 **1.7%–3.0%**；
- 占 largest connected flat patch 约 **3.5%–6.3%**；
- 即使加建筑自身的最小前场 / 基座，也不会吞掉整个中心低地；
- 规模足以让三席政治结构在 Minecraft 玩家尺度下被读懂，而不是挤成普通会议室；
- 仍为未来代表馆、誓约空间、档案、公共前场与岸线关系留下大量空间。

## 6. 第一施工批次原则

“小批次”继续严格执行，但第一批施工范围应**由最终大厅方案反推**。

建议未来 world-write 时使用：

- 一个主体建筑；
- 主体实际 footprint；
- 必需基座 / 台阶 / 门廊；
- 仅直接接入建筑的短距离地表处理；
- 紧邻建筑且必须调整的结构性植被。

建议第一批 surface intervention area 大致控制在：

> **约 4,500–6,500 blocks²**

而不是固定 `64×64` 方框。

如果最终大厅方案确实需要超出，应由 GPT + Owner 在 world-write Task 前重新审核。
