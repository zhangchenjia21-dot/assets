## 2. 总体定位｜政治园区 → 前现代联盟政治小城

此前把成熟期建筑 footprint 压到一两万格，会使 9.2 万格共同领土在 Minecraft 中显得过度空旷，也不足以表达这是三域联盟长期使用、不断生长的共同政治中心。

当前总体定位调整为：

> **一个规模有限但真实有城市密度的前现代联盟政治小城 / 共同领地。**

它不是现代首都 CBD，也不是宫殿园林；应包含核心政治建筑、三域驻馆、书记司法机构、誓约空间、接待 / 警卫 / 后勤，以及随长期使用自然形成的前场、院落、短街、服务巷、岸线活动和结构性植被。

## 3. 成熟期土地使用基线

### 3.1 Mature Built Footprint

建议成熟期全部地面建筑 footprint：

> **约 30,000–38,000 blocks²**

约占联盟公地：

> **约 33%–41%**

这不是要求一次建完，而是长期饱和前的总体量级。

### 3.2 非建筑空间

建议长期参考构成：

| 空间类型 | 工作量级 | 作用 |
|---|---:|---|
| 建筑 ground footprint | **30k–38k** | 联盟公共机构、驻馆、服务与支持建筑 |
| 公共 / 仪式前场、院落 | **16k–20k** | 集会、等候、宣誓、公开事务、建筑间空间 |
| 短街 / 巷道 / 服务通行 | **10k–13k** | 人员、车马、货物、建筑间连接 |
| 岸线 / 结构性植被 / 地形缓冲 | **18k–24k** | 保留湾水关系、视线、树群、地形过渡 |
| 未定 / 扩建余量 | **8k–12k** | Just-in-time 后续演化 |

这些是相互协调的容量范围，不是要求划成规则功能地块。

一个便于后续设计理解的**中值参考**可近似看作：

```text
92k Commons
≈ 32k 建筑
+ 18k 公共院落 / 前场
+ 12k 短街 / 服务通行
+ 21k 岸线 / 景观 / 地形
+ 9k 扩建余量
```

目标是让玩家感受到一个真实使用中的政治小城，而不是巨大空地中孤零零几栋建筑。

## 4. 长期建筑 Program

下面是成熟期容量预算，不是一次性 Codex 施工清单。

| 功能 | 建议 ground footprint | 说明 |
|---|---:|---|
| 三席议事大厅 | **4,500–7,000** | 最核心公共建筑；议事、三席、公众旁听、前厅、书记 / 等候等最低必要辅助空间 |
| 三域代表馆 / 驻馆 | 合计 **6,000–9,000** | 每域可约2k–3k；可各自形成院落 / 分期扩建 |
| 档案 / 书记 / 裁判 / 金库 | **4,000–6,000** | 可为一组复合公共机构，不要求单一巨楼 |
| 联盟誓约 / 神圣仪式建筑 | **2,000–3,500** | 宗教中等可见；服务共同誓约，不形成神权中心 |
| 外交 / 贵宾 / 公共接待 | **2,500–4,000** | 外使、跨域代表、重要访客 |
| 警卫 / 马厩 / 后勤 / 储藏 | **4,000–6,000** | 可分散，不要求一座完整大楼 |
| 覆盖式公共 / 服务建筑与后续功能 | **2,000–4,000** | 可包括公共廊厅、服务棚馆、后续 Just-in-time 功能 |

上述 program 总量约 **25,000–39,500 blocks²**，与成熟期 built-footprint `30k–38k` 基线相容；具体功能可合并、拆分和分期，不要求把所有上限同时取满。

### 所有权 ≠ 纯行政用途

联盟公地全部属于共同政治领土，但其中未来允许存在：

- 对代表 / 书记 / 来访者服务的住宿；
- 联盟管理或许可的工匠 / 服务设施；
- 市场日、临时摊位与公共交易空间；
- 马厩、仓储、厨房等日常支持功能。

因此不应把 92k 公地理解成只有“政府办公楼 + 大草坪”的现代行政区。

## 5. 三席议事大厅尺度搜索基线

### 5.1 功能地位

三席议事大厅是三域联盟最高等级的共同政治建筑，但它不是整座政治中心，也不是王宫。

设计必须足够大，使玩家能读懂：

- 三个永久席位；
- 联盟共同中心；
- 公众 / 代表 / 书记等不同层级；
- 仪式与议事双重功能；
- 成熟石木公共建筑的大跨与耐久感。

### 5.2 当前建议搜索区间

主体建筑 ground footprint：

> **约 4,500–7,000 blocks²**

约占整个 Commons：

> **约 5%–8%**

这仍只是设计搜索范围，不是最终尺寸。

可探索但不强制：

- 主要长轴约 **80–110 blocks**；
- 主要短轴约 **45–70 blocks**；
- 长条主厅 + 辅助翼；
- U / 多翼围合共同空间；
- 非规则、顺应微地形的石木公共建筑。

建筑可以跨出单一 79×79 全 FLAT 诊断方块，但不得因此大面积推平；应利用基座、台阶、挡土墙和局部高差适应真实 Site。

### 5.3 历史量级校准

现实前现代大型公共厅堂表明，单个核心大厅本身就可以达到约 1,300–2,200m² 级别，例如：

- Westminster Hall 大厅约 73×20m；
- Palazzo Ducale Great Council Chamber 约 53×25m；
- Palazzo della Ragione Salone 约 81×27m。

CIV-001 的 4.5k–7k 指的是**整座议事建筑 ground footprint**，不仅是核心议事厅净面积，因此该量级对联盟最高公共建筑并不夸张。

P2 必须根据真实功能和 Site 自行收敛，禁止为了“用足区间”而无意义做大。

## 6. 空间组织原则

联盟公地自身近似椭圆 / 卵形来自自然主体形态，但内部不得因此变成：

- 现代椭圆行政园区；
- 严格放射路网；
- 巨型对称轴；
- 规则等距机构建筑。

长期生长逻辑应更接近：

```text
第一核心：三席议事大厅
→ 公共前场 / 必要短街形成
→ 三域驻馆与书记司法功能逐步依附
→ 誓约 / 接待 / 后勤建筑补齐
→ 院落、巷道和岸线活动在长期使用中成熟
```

建筑间应形成前现代的短街、院落、转折、窄口与开敞公共空间，而不是孤岛式建筑散落在草坪上。

## 7. 第一施工批次原则

“小批次”继续严格有效：

> **一次 world-write 只承担一个主要建筑 / 主要空间目标 + 必需最小接口。**

对第一批三席议事大厅：

- 只做最终批准的大厅主体；
- 必需基座 / 台阶 / 门廊；
- 极短的入口连接；
- 紧邻建筑必须调整的地表与结构性植被。

不得同批施工三域驻馆、档案建筑、誓约建筑、大广场、码头、跨岛桥、道路网或整片政治中心。

第一批实际 intervention area 必须由 P2 最终设计反推，不预设固定方框。
