## 1. Site

Owner 已确认：**Candidate A｜湾内中心低地 / Council Centerland**。

必须保持事实：

- 视觉上处于西部 C 形低岛怀抱的湾内中心；
- 自然拓扑属于东部山地主岛 component 2 的西伸低地；
- 不是独立岛；
- 西 / 北 / 南主要面对湾水，东侧陆连山地主岛；
- 东方山地可作为背景。

## 2. Core Design Thesis

建筑应让玩家无需说明牌也能读出：

> **这里没有王座。三种区域权力从不同方向进入同一个联盟空间，在共同誓约下协商。**

三席政治尊严相等，但禁止用几何完全相等表达平等。

## 3. Arrival Logic

P2 在单体设计中至少预留并解释三种代表到达关系：

- **West Seat**：来自西岛 / 湾水方向；跨水接近是重要视觉序列，但本轮不建码头、桥或正式航线。
- **Middle Seat**：来自本地低地 / 坡麓交换区；可以与日常城镇 / 商贸环境形成较自然的陆地接近。
- **East Seat**：来自东部山地方向，通过 A 向东的陆连通进入；应利用“由山地走向湾内共同空间”的体验。

Public / petitioners 需要清晰公共入口与等候位置，但不要求额外制造第四个纪念性门厅。

三种到达可以共享部分外部路径，不得为了象征“三”机械设置三条等价大道。

## 4. Minimum Functional Program

除正式 TASK 已要求的 Plan / Section / Sequence 外，设计至少应解决：

1. **Shared Council Chamber**：共同议事核心；无王座端头。
2. **West / Middle / East Seat Sectors**：可辨认但不镜像复制。
3. **Common Oath Element**：誓约石、共同火盆、中央桌 / 地面构件等；它是共同制度中心，不是隐藏王座。
4. **Representative preparation / waiting**：代表进入议事前的基本准备 / 等候。
5. **Public / petition / witness area**：普通访客、宣告、见证的位置。
6. **Scribes / short-term records support**：会议书记与临时文书；大型档案馆留给未来独立建筑。
7. **Guard / porter / service**：最低限度入口与后勤。
8. **Real circulation**：所有主要门、楼梯、层级、席位可达。

## 5. Massing / Scale

严格服从正式 D-016 / TASK：

- 主体 footprint **目标 `<=45×45 blocks`**；
- 单方向超过约 `52 blocks` 必须说明必要性；
- 第一批未来 world-write 总 intervention envelope **目标 `<=64×64 blocks`**；
- 不得因 A 有约 79×79 FLAT 诊断区就占满它。

形态倾向：**宽体、耐久、可从湾水识别的前现代公共地标**，而不是高塔宫殿。主议事空间可以双层通高，附属空间应低于主厅；具体高度由 P2 Section 决定。

## 6. Material / Symbolic Direction

应体现同一 CIV-001 的融合，而不是把三域各做一套皮肤：

```text
East-derived durable masonry
+ West / Middle timber craft
+ restrained highland metalwork
+ limited oath / protective magical detail
```

禁止裸露 ore block 表达“富矿”。魔法只在有明确功能的誓约、保护或工艺节点出现。

## 7. Landscape Interface

本轮只允许设计为单体成立所必需的近场关系：

- 小型前庭 / 誓约庭（若有真实功能）；
- 建筑基座、排水、地表；
- 结构性树木保留 / 重构策略；
- 少量未来路径接口；
- 湾水与建筑之间的缓冲。

不做行政大草坪，不展开完整议会区。

## 8. Preview Review Focus

Revision 后 Preview 除正式 TASK 要求外，应特别能检查：

- west-water approach；
- east-land approach；
- council chamber interior；
- 三席是否平衡而不机械对称；
- 建筑是否利用东部山地背景；
- footprint 是否服从 A 的真实地形而不是把地形抹掉。

本 Addendum 不授权 world write。
