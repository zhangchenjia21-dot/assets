# AB-001P2｜Three-seat Council Hall Design Brief

状态：**OWNER SITE CONFIRMED / GPT ARCHITECTURE BRIEF / WORLD WRITES = 0**

Site Authority：`decisions/D-016_AB-001P1候选A场地确认与P2设计进入.md`

Base Grammar：`Architecture-Grammar.md`

目标：在 **Candidate A｜湾内中心低地 / Council Centerland** 上，为 CIV-001 设计第一座 Canon 建筑 Pilot：**三席议事大厅**。

本 Brief 冻结设计问题与验收，不替代 Codex 的具体空间推演。

---

## 1. Design Thesis｜设计命题

建筑必须让玩家在不读说明书的情况下感受到：

> **这里没有王座。三个来源不同的区域权力从不同方向来到同一座大厅，在共同的中央空间内协商并向同一联盟宣誓。**

它不是王宫、现代议会大厦，也不是三栋镜像办公楼。

核心空间语义：

```text
three distinct arrivals
→ common threshold / oath space
→ shared council chamber
→ three recognizable but non-mechanical seat sectors
→ public / clerical / ritual support
```

三席政治尊严相等，不要求几何面积、门厅或体量完全相等。

---

## 2. Site-specific Causality

Candidate A 当前已知：

- 实际低地范围约 `X=-349..240, Z=1664..1982`；
- median Y≈68；
- 西 / 北 / 南主要面对 C 形湾水面；
- 东侧连接东部山地主岛；
- 东方 / 东南方向有明显升高山地背景；
- 存在大尺度连续平缓地，但不等于整地授权；
- 当前未发现明确人工表层材料旗标，但仍需在 world-write 前再次局部确认；
- 当前植被不是空白画布，应在设计中决定保留 / 重构关系。

建筑应利用，而不是抹平这些关系。

### Arrival logic to reserve

- **West-seat arrival**：来自西岛方向，优先保留跨水到达的空间可能；P2 不建设码头 / 桥。
- **Middle-seat arrival**：来自本地西伸低地 / 坡麓交换区，可从低地道路或岸侧进入；P2 只保留入口方向。
- **East-seat arrival**：来自东部山地主体，利用东侧陆连通作为最自然的陆路方向。
- **Public / petitioners**：需要独立于三席代表私密准备空间的合理公共进入流程，但不必增加第四个纪念性门厅。

三种 arrival 可以共享部分外部路径，禁止为了象征“三”机械造三条完全等价道路。

---

## 3. Program｜最低功能空间

P2 至少解决：

1. **Shared Council Chamber**：三席共同议事的核心大厅；无王座端头。
2. **Three Seat Sectors**：西 / 中 / 东三席可辨认的座区或席厅关系；不得机械 120° 镜像。
3. **Common Oath Element / Oath Space**：共同誓约石、火盆、天井、中央桌 / 地面构件等，作为视觉与制度中心；不得变成王座替代物。
4. **Representative Preparation / Waiting**：三方代表进入议事空间前至少有合理等候 / 准备空间，可共享但须解释。
5. **Public / Petition / Witness Area**：普通来访、宣告、见证或听审的位置，与代表席不互相穿行失控。
6. **Scribes / Records Support**：书记、文件、短期档案与会议支撑空间；大型联盟档案馆属于未来独立建筑，不塞进本建筑。
7. **Guard / Porter / Service**：入口管理、储物、基本后勤。
8. **Real circulation**：所有楼层、门、楼梯、廊道和席位真实可达。

完整办公体系、外交馆、金库、代表馆、市场等不属于本次单目标。

---

## 4. Massing / Scale Envelope

目标是**湾内可识别的宽体公共地标**，不是压过东部山地的巨型宫殿。

建议设计尺度区间（可在 Site 推演后合理调整并说明）：

- 主建筑 / 紧邻庭院整体：约 `45–65 × 35–55 blocks`；
- Site design envelope 原则上控制在约 `70 × 65 blocks` 内；
- 主议事空间可双层通高；
- 主檐口相对完成地坪约 `+9..+13`；
- 主屋脊 / 最高主体约 `+17..+23`；
- 附属体量低于主议事空间；
- 不以高塔作为权力象征。

若 Codex 有充分结构 / 视线理由超出范围，必须在 Design Review 中说明，而不是静默放大。

---

## 5. Plan Requirements

Plan 必须明确：

- 精确 footprint / design envelope；
- 三席所在方向与理由；
- 公共入口、代表入口、服务入口；
- shared chamber、oath element、等候、书记、公共见证区之间的关系；
- 外部 forecourt / small oath court 如需要，其具体功能；
- 与湾水、东侧陆连通和未来外部路径的关系；
- 不把整个 A 场地都规划成政治园区。

禁止：

- 单一王座长轴；
- 机械等边三角 / 120° 三翼；
- 完全镜像的三门三厅；
- 巨大现代行政广场；
- 为了对称无视岸线和真实到达方向。

---

## 6. Section Requirements

Section 至少说明：

- 原地形与完成地坪关系；
- 基座 / 排水 / 防潮；
- 主厅与附属空间高度；
- 屋架 / 屋脊体量；
- 若有庭院 / 天井，其开敞与排水逻辑；
- 水岸标高与建筑之间保留的空间；
- 东部山地背景与建筑天际线关系；
- 结构性树木 / 树冠与建筑轮廓关系。

原则：优先微调地基、台阶、基座和有限整地；不大面积推平成完全单一 Y。

---

## 7. Sequence Requirements

必须分别模拟至少四类人：

### West delegation

从西岛 / 湾水方向接近，建筑应先以屋顶 / 公共立面成为跨水地标，再经历岸—陆—门厅—共同空间的转换。

### Middle delegation

从本地低地 / 坡麓环境到达，体验应更接近日常城镇与联盟中心之间的过渡。

### East delegation

从东部山地方向沿陆地接近；建筑前景与西侧湾水应逐渐展开，形成“从山地进入共同联盟空间”的反向体验。

### Public / petitioners

必须能清楚找到公共入口、等候和见证空间，不无意闯入代表准备区。

Sequence 不要求未来道路已经存在，但必须为未来路径保留合理接口。

---

## 8. Material / Structural Direction

建筑应体现三域共同文明而非拼贴三种风格。

优先逻辑：

```text
East-derived durable stone base / masonry
+ West/Middle timber framing and roof craft
+ restrained metalwork from mineral-rich highlands
+ earth / plaster / terracotta tones where appropriate
```

具体 block palette 由 P2 结合 Minecraft 运行时与视觉测试确定。

要求：

- 2–4 种主材料控制大体量；
- 金属与特殊材料用于门件、连接、誓约构件、屋顶细节等；
- 禁止用裸露 ore block 表达东域富矿；
- 魔法表现低普及：最多以誓约石 / 火盆 / 少量保护符文等明确功能节点出现。

---

## 9. Landscape / Ground Plane

本次只设计**服务单体建筑成立所必需的近场景观**：

- 小尺度到达前庭 / 誓约庭；
- 必要的岸—陆缓冲；
- 结构性树木保留 / 重构策略；
- 基座周边排水与地表；
- 少量路径接口。

不建设完整议会区，不铺大草坪，不做现代行政园林。

已有随机植被未来可在授权施工范围内清理并重新设计，但 P2 只能规划，不能 world write。

---

## 10. Reference Research

设计前至少研究 3 类真实前现代 precedent，重点提取空间机制而不是复制立面：

- medieval / late-medieval town or council halls；
- guild / merchant assembly halls；
- thing / communal oath / civic assembly traditions；
- 其它能够解释“无王座、多方协商、公共见证、誓约”的前现代空间。

研究应回答：

- 人们怎样进入与等待；
- 权力怎样通过座位 / 高差 / 房间组织表达；
- 公共与代表空间怎样分离；
- 大厅为什么采用对应结构与尺度；
- 哪些机制适合 CIV-001，哪些不适合。

---

## 11. Design Mode

本建筑属于 CIV-001 首个重要 Canon Pilot，采用：

> **Architect → Critic → Revision**

默认只形成一个主方案，不做三个平行方案消耗注意力。

Critic 至少审计：

- political semantics；
- functional circulation；
- terrain fit；
- Plan / Section / Sequence；
- scale；
- roof / structure；
- anti-symmetry / anti-throne-axis；
- shoreline / mountain backdrop；
- player-scale experience；
- Minecraft 可实施性。

只有 Revision 后版本进入 Preview。

---

## 12. Preview / Stop Gate

P2 可以生成**离线 Blueprint / 3D Preview**，用于 Owner + GPT 审核；不得写入真实 `建筑师` 存档。

Preview 至少提供：

- top / plan view；
- 2 个以上 exterior perspective；
- 1 个 interior council-chamber view；
- section / cutaway 或足以检查层高与屋架的视图；
- 从 west-water approach 与 east-land approach 的体验视图；
- footprint / terrain relation。

P2 完成后停止于：

> **DESIGN READY FOR GPT + OWNER REVIEW / WORLD WRITE NOT AUTHORIZED**

只有 Owner 审核设计并明确批准施工后，才能创建后续 Build Task。
