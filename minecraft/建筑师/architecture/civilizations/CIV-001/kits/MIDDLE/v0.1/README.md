# CIV-001 / Middle Architecture Kit v0.1

**PROPOSED，部分选定实例 PREVIEW_VALIDATED；等待 GPT + Owner 审核。**

本版把 Architecture Grammar 和 D-025/D-028 编译成可重新适配场地的规则。包含5条 Shared DNA、16条 Middle规则、15个模块、6类 typology skeleton、4组材料族和6条变化规则。

- [使用契约](KIT.md) · [禁止组合](forbidden-combinations.md)
- `KIT.json`：Shared/Regional DNA、成熟度和编译顺序。
- `typologies.json`：必需核心、可选模块、尺寸/比例、地形适配与冲突。
- `modules.json`：输入、维度、输出不变量、禁配与成熟度。
- `palette-families.json`：按构件/用途组织的候选材料，不是资源库存证明。
- `variation-rules.json`：用途、年代、地块、地形、等级/工匠产生的受控变化。
- [设计原型与预览](../../../../../../planning/CIV-001/MIDDLE/G1/MD-001U1/README.md)

没有固定整栋复制件，没有正式资产注册，没有 `BUILT_AND_OWNER_ACCEPTED`。每次新场地必须重做 Site Context、功能图、平剖面、净空/支承/雨水核查与预览。`world writes = 0`。
