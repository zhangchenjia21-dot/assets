# Middle v0.1｜禁止组合

下列禁配条目均为 **PROPOSED** Kit规则；其中世界写入/边界限制直接继承既有Authority，不由本Kit重新授权。

1. 等宽同高五栋房屋 + 同脊向 + 同窗节奏 + 同退界；不能用换色掩盖复制。
2. 高土地利用率 + 删除公共净带/排水/消防维护/采光间隙。
3. 仓库营业门 = 全体居民唯一入口；货堆/装卸位压住家门和楼梯。
4. 木构睡房正下方无隔离热锻/冶炼；木楼板直接穿入烟道预留。
5. 石重屋顶或悬挑平台 + 无承重梁架；墙脚下意外空气缝。
6. 只有起终点可达 + 未检查踏步、头部、洞口、landing和护栏。
7. 1:1陡坡屋面 + 相邻条带不相接的薄半格屋面。
8. 围合院墙 + 无收水/溢流/维护出口；干污物接入雨水沟。
9. 海岸/邻近水体 = 已确认饮水；模型里的储水点 = 已具备入住条件。
10. 公共通行路线 + 收费门楼/海关/强制查验；普通消息屋变成主权机构。
11. shore/lowland/foothill 同一巨台；为同一模板重做大范围地形。
12. PREVIEW_VALIDATED + 声称建成、实机通过、Owner接受或正式资产注册。

发生禁配时回到相应空间/结构/场地设计，不用装饰遮住缺陷。真实碰撞、流体、方块模型不足的地方明确留作未验证，不用其它检查替代。
