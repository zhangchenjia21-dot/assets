# 世界构建原则｜建筑师

## 1. 先读世界，再写世界

存档已有地形是自然地理的硬事实。国家、文明、首都、边界、道路和历史应在理解地形之后形成，而不是先写一套完整世界观再强迫地图适配。

## 2. 分层，不混淆

```text
Minecraft Natural Geography
→ Regional Reconnaissance
→ Human Geography Hypothesis
→ Owner-approved World Canon
→ Architecture / Settlement Grammar
→ Site-specific Build
```

自然地理调查不能自动生成政治事实；宏观 Atlas 也不能直接承担文明 / 种族落位。

## 3. 证据等级永久保留

- **Observed**：直接读取世界；
- **Observed-by-Owner**：Owner 在真实 Minecraft 世界中的直接实地观察；
- **Derived**：从 Observed 计算；
- **Interpretive**：规划线索与潜力判断；
- **Canon**：Owner 明确批准的世界事实。

低一级证据可以启发高一级，但不能静默升级。

## 4. 发现式世界构建

优先采用：

```text
实际地形 / biome / 水系 / 高程 / 可利用空间 / 已验证资源
→ 生计、移动与风险约束
→ 生活方式与聚落逻辑
→ 社会 / 部族 / 文明候选
→ 魔法 / 技术实践
→ 历史与制度
→ 建筑语言
```

山脉、河谷、海峡、群岛、森林、荒地和天然走廊应该能够成为文明形成的原因，而不是文明设定完成后的背景板。

## 5. Regional Reconnaissance Gate

Current Natural Atlas 用于宏观筛选“哪里值得继续看”，不用于直接决定“谁住这里”。

任何文明 / 种族在具体 Minecraft 区域落位前，必须至少完成：

```text
Current Natural Atlas macro query
→ regional in-game / high-resolution reconnaissance
→ regional natural profile
→ terrain / biome / water / elevation / flatland / accessibility evidence
→ civilization / species hypotheses
→ GPT + Owner discussion
→ Owner explicit approval
→ World Canon
```

如果某项资源、农业潜力、航运条件或战略通道没有实际证据，就保持 unknown，不得由地貌标签代推。

## 6. Biome 不是文明标签

禁止默认：

- 沙漠 = 沙漠帝国；
- 森林 = 精灵；
- 雪地 = 北境王国；
- 多山 = 矮人 / 矿业文明；
- 热带雨林 = 自然种族。

Biome 只是环境证据的一部分，必须与地形、水系、高程、资源、交通和历史共同解释。

同样禁止反向操作：先决定“这里必须住某个种族”，再挑选几个 biome / 地貌特征为既定结论找理由。

## 7. 区域内部差异优先于整块着色

一个 Atlas region、岛屿或大陆不自动等于一个文明或国家。

在文明设计前，应主动检查区域内部是否存在：

- 高低差；
- 不同 biome / 植被环境；
- 平原、山地、岸线、岛片等空间分异；
- 不同交通条件；
- 足以形成不同部族 / 聚落适应方式的自然分区。

如果存在明显内部差异，优先从这些差异中提出多个生活区 / 部族区 hypotheses，而不是把整个区域涂成一种文化。

## 8. 名称与政治地图后置

GEO / HYD / FEAT / SITE 以及 NGEO / NHYD / NFEAT / NSITE 首先是机器空间 ID。正式地名、文化区、国家边界与行政归属只有在 World Canon 阶段经 Owner 批准后才建立。

## 9. Canon Promotion Gate

重大世界事实默认：

```text
Research / Terrain Evidence
→ Regional Reconnaissance
→ GPT + Owner Discussion
→ Hypothesis / Options
→ Owner explicit approval
→ world/ Promotion
```

Owner 未明确批准时，不得标记为 CANON / DECIDED。

## 10. 经验基线：D-007

南部大岛第一次文明试点证明：只依据宏观 Atlas 把 `NGEO-009` 直接指定为林地长生种文明属于过早 promotion。

Owner 真实存档考察发现当地以温带 / 枯树环境、多山少平原、西低东高等条件为主，并存在明显区域内部差异。

因此以后坚持：

> **先实地考察区域，再让文明从当地自然条件中生长出来。**
