### NG-3｜Natural Atlas Consolidation

状态：**AUTHORIZED / DISPATCH READY**

Authorization：`../decisions/D-004_NG-3自然地理图册收敛授权.md`

Executable Task：`../tasks/NG-003/TASK.md`

目标：把：

1. V1 global coarse baseline；
2. NG-2 local calibration / counterexamples；
3. 必要且受限的 targeted refinement；

收敛成更可靠、可长期被 Codex 查询的 Consolidated Natural Atlas，为 Human Geography 与后续 World Canon 提供自然地理底图。

核心成果：

- `NGEO / NHYD / NFEAT / NSITE` Proposed stable IDs；
- lineage / evidence status / uncertainty；
- consolidated SQLite（或等价 machine store）；
- coordinate / object / neighbors / search / context 查询接口；
- 派生 Atlas / hydrology / uncertainty maps。

约束：

- 不采用整个预生成世界全部 1-block 重扫；
- targeted refinement 默认最多 12 处，允许 0 处；
- 结构化机器事实层优先，不复制已有海量 raw evidence；
- 保留 Observed / Derived / Interpretive / Consolidated Atlas 证据层级；
- 利用 NG-2 反例修正或限制 V1 detector 语义；
- 未充分验证的完整山脉 / 河流 / 流域 / 海湾边界允许保持 provisional / unresolved；
- `SITE-002` 不得升级为战略山口；
- `SITE-011` 不得升级为 natural harbor；
- 不在 NG-3 创建国家、文明、宗教、历史、正式地名或建筑规划；
- `world writes = 0`。

Codex 完成后只可机械记录 implementation completed / awaiting review；必须由 GPT 独立审核后决定 Proposed Atlas 是否 promotion。
