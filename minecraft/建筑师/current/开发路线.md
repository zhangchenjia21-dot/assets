## WB｜World Building

状态：**NEXT / READY FOR OWNER AUTHORIZATION / NOT AUTHORIZED**

下一任务建议：

### WB-001｜Global / Non-spatial Fantasy Canon

先建立**不绑定具体地图位置**的世界底层规则，避免还没做 Human Geography 就强行把国家钉到地图上。

建议至少收敛：

1. world tone / fantasy intensity；
2. cosmology；
3. magic existence / accessibility / cost / limits；
4. gods / religion baseline；
5. intelligent species baseline；
6. technology / material culture；
7. historical depth / ages / catastrophe model；
8. monster / supernatural ecology；
9. knowledge reliability / myth vs history；
10. 世界设定哪些部分必须保持 open / TBD。

WB-001 不创建政治地图，不决定哪个文明具体位于哪个 NGEO。

### 后续 World Building 候选顺序

```text
WB-001 Global / Non-spatial Canon
→ Human Geography hypotheses using Current Natural Atlas
→ Owner-approved cultural / political spatial Canon
→ civilizations / religions / economies / history
→ regional historical layering
```

原则：

`terrain → resources / transport → economy → institutions / power → history → culture → architecture`

Research / hypothesis 不自动 promotion；空间 Canon 需要 Owner 明确批准。
