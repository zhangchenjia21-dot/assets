# 项目总纲｜建筑师

## Primary Purpose

以已经存在的 Minecraft 存档 **`建筑师`** 为物理世界基础，让 GPT 与 Codex 逐步完成：

1. 读取并理解真实地形；
2. 建立与地形相容的奇幻世界设定；
3. 从历史、环境、经济、社会与技术因果关系推导建筑语言；
4. 在具体 SITE 上进行高质量单目标设计；
5. 经复核后把建筑 / 聚落持续落地到同一存档；
6. 让长期累积的建筑看起来属于同一个世界，而不是互不相关的展示作品。

## 当前硬事实

- 目标存档名称：`建筑师`。
- 当前自然地理必须从该存档实际数据出发，而不是先画一张理想政治地图再强迫地形服从。
- 目标世界使用 Minecraft 26.2 / DataVersion 4903；当前调查发现启用了 Terralith、Tectonic、Towns and Towers 等数据包 / 模组内容，因此不得假定原版地形语义。

## 协作模型

### Owner

- 最终审美与世界观裁定者；
- 决定哪些假设升级为 Canon；
- 决定何时允许真实 world writes。

### GPT

- 世界构建、历史 / 建筑研究、设计讨论、任务成形与独立审核；
- 区分事实、推导、假设与 Canon；
- 不用聊天记忆代替 GitHub current source。

### Codex

- 读取世界 / 结构化数据；
- 开发调查与规划工具；
- 形成可查询的地理 / 建造事实层；
- 按批准的规则做设计和施工；
- 完成并验证后把成果 push 到本项目目录。

### GitHub

- 长期项目事实、研究证据、World Canon、建造记录与可复现材料的持久层。
- Prompt 只传本轮增量，不重复整个项目背景。
