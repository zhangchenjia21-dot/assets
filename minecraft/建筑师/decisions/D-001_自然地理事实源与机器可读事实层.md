# D-001｜自然地理事实源与机器可读事实层

状态：**DECIDED**

日期：2026-09-09

## Decision

1. `建筑师` Minecraft 存档是本项目自然地理的原始事实源。
2. 在创建空间化世界 Canon 前，先由 Codex 对现有已生成世界做自然地理调查。
3. 调查成果优先保存为最便于 Codex 后续查询、组合和规划的机器可读结构化事实层。
4. Markdown 报告、图片与地图主要作为派生的人类阅读视图，不取代结构化事实源。
5. 粗调查产生的算法地貌 / SITE 候选不得自动升级为国家、文明、历史或建筑 Canon。

## Consequence

后续规划应先查询已接受的自然地理数据；需要具体落点时，再做局部高分辨率 / 现场观察，而不是反复从零扫描或依赖聊天记忆。
