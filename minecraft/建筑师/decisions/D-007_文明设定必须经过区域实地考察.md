# D-007｜文明设定必须经过区域实地考察

状态：**OWNER APPROVED / ACTIVE DECISION**

日期：2026-09-09

## 决策背景

此前 `D-006` 将 Current Natural Atlas 中的南部大岛 `NGEO-009` 直接指定为 `CIV-001` 林地长生种文明试点区域。

Owner 随后亲自进入真实 Minecraft 存档考察，发现该区域的实际自然条件与此前基于宏观 Atlas 标签形成的“圣林 / 自然型文明”想象并不匹配：

- 区域整体更偏温带 / 枯树环境，而非适合高密自然魔法森林文明的热带雨林；
- 整体多山、平原较少；
- 地势总体呈西低东高；
- 可用平原主要集中在西侧两个岛屿；
- 从 Owner 实地观察看，区域可进一步分为三个具有不同自然条件的潜在部族区域。

这些观察说明：宏观 Natural Atlas 足以用于选择“值得进一步研究的区域”，但不足以直接承担文明 / 种族空间分配。

## 正式决策

### 1. `D-006` 的文明空间指定被撤销

`D-006` 保留为历史决策，但其中：

> `南部大岛 = 林地长生种 CIV-001 文明核心试点区域`

不再具有 Current Canon authority。

南部大岛重新回到：

> **REGIONAL RECONNAISSANCE / HUMAN-GEOGRAPHY HYPOTHESIS PENDING**

状态。

`CIV-001` 工作 ID 可以保留，但在新的区域推导完成前，不绑定正式种族、文明或政治实体。

### 2. 新增 Regional Reconnaissance Gate

今后任何文明 / 种族在具体 Minecraft 区域落位前，必须经过：

```text
Current Natural Atlas macro query
→ regional in-game / high-resolution reconnaissance
→ regional natural profile
→ terrain / biome / water / elevation / flatland / resources* / accessibility evidence
→ civilization / species hypotheses
→ GPT + Owner discussion
→ Owner explicit approval
→ World Canon promotion
```

`* resources` 只有实际调查支持时才能使用，不能从地貌标签推测矿产、农业潜力或航运条件。

### 3. “从自然条件中长出文明”成为强约束

禁止：

- 先决定“这里是精灵 / 矮人 / 蒸汽族”，再反向寻找环境理由；
- 从 biome 名称一对一映射文明；
- 仅凭宏观 Atlas 类型决定社会、经济、聚落和建筑；
- 仅凭美学偏好把某一文明硬贴到看起来合适的区域。

优先流程：

```text
实际自然条件
→ 可利用空间 / 生计 / 移动 / 风险 / 资源约束
→ 适应这些条件的生活方式
→ 社会 / 部族 / 文明形态
→ 魔法 / 技术实践
→ 建筑与聚落
```

### 4. Owner 实地观察属于重要证据，但边界仍需结构化

Owner 的真实游戏内考察可作为高价值 `Observed-by-Owner` evidence。

如果后续要把“三个部族区域”等空间结论写入 Canon，应进一步形成：

- 可追溯坐标范围；
- biome / 高程 / 水系 / 平地分布；
- 必要的截图 / 地图 / 机器数据；
- 哪些是 Observation、哪些是 Interpretation。

## 对下一步的影响

暂停继续设计 `CIV-001` 林地长生种文明。

下一步应先对南部大岛做一次 Regional Natural / Human-Geography Reconnaissance，验证并结构化 Owner 已观察到的：

- 温带 / 枯树环境；
- 多山少平原；
- 西低东高；
- 西侧两个岛屿平原集中；
- 三个潜在部族区域。

调查完成后，再从这些真实条件中提出文明 / 部族候选，而不是继续沿用原先“圣林城邦”方向。
