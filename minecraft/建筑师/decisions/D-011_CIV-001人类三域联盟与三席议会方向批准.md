# D-011｜CIV-001 人类三域联盟与三席议会方向批准

状态：**OWNER APPROVED / ACTIVE WORLD-CANON DIRECTION**

日期：2026-09-10

## 背景

WB-002R-R1 已完成南部岛屿群 whole-scope Regional Natural Profile，并被独立审核接受为当前 Human Geography planning evidence。

关键自然事实包括：

- 西部为独立 C 形低岛，平地比例高、整体低平；
- 东部为面积更大的独立山地主岛，整体高起伏、平地稀少；
- 东部主岛西侧存在较低的伸出地带 / 坡麓过渡；
- 自然地理本身没有证明唯一、稳定、恰好三分的硬边界，但允许 Human Geography 因历史、交通、制度和聚落网络形成三个人文区域。

Owner 接受以此为基础继续 CIV-001 设计，并批准“三席议会相关建筑优先安排在西部平岛的中心岛”这一空间方向。

## 正式批准

### 1. CIV-001 的主要智慧种

`CIV-001` 当前采用 **人类文明** 作为第一文明 Pilot 的主要智慧种。

本决定不代表整个南部岛屿群永久只能存在人类，也不排除未来少数异族、迁徙人口或历史遗存。

### 2. 三域联盟作为文明骨架

CIV-001 采用工作性高层结构：

```text
西域｜西部 C 形低岛
中域｜东部主岛西侧低地 / 坡麓过渡带
东域｜东部山地核心
```

三域是 **Human Geography / cultural-political regions**，不是把 `SIRZ-R1-001/002` 或算法聚类直接升格为政治边界。

具体边界、正式地名、行政层级和内部数量保持 TBD。

### 3. 政体方向

CIV-001 采用**前现代松散联盟 / 邦联式结构**作为当前政体骨架。

核心逻辑：

- 三域属于同一大文化与政治共同体；
- 跨域事务需要共同协调；
- 东部山地的高起伏、聚落分散和地方共同体结构提高长期中央直接统治成本；
- 因此联盟层与地方层并存，而不是默认形成高度中央集权王国。

具体历史起源、法权、军事义务、税收和继承制度保持 TBD。

### 4. 三席议会

批准“三席议会”作为 CIV-001 的核心共同治理机构方向。

当前只冻结：

- 它代表三域共同政治协商；
- 是联盟层的重要制度与公共建筑来源；
- 具体三席由谁担任、如何产生、是否等权、任期 / 世袭 / 选举方式、否决权等全部保持 TBD。

### 5. 三席议会建筑空间锚点

Owner 批准：

> **三席议会相关代表性建筑优先安排在 Owner 所称“西部平岛的中心岛”。**

当前这是 **OWNER-APPROVED PLANNING ANCHOR**，不是具体施工坐标。

由于“中心岛”尚未与机器拓扑中的精确 component / polygon / coordinate 一一映射：

- 不得由 Agent 擅自猜测具体坐标；
- 后续正式 Build site 选择前必须进行 local observation / Owner 视点对应；
- 当前只把它理解为西部低地政治中心的优先空间方向。

### 6. 互相依赖仍需事实支撑

“三域彼此需要、但不完全统一”继续作为文明机制方向，但具体互补关系不得凭空写死。

下一步需要调查：

- 可耕 / 低平生产空间 proxy；
- 木材 / 石材 / 黏土 / 砂砾等建设材料；
- 关键矿物 / 矿产存在与空间差异；
- 内水 / 岸线 / 跨岛距离；
- 地形约束下的陆路 movement cost；
- 其它足以影响交换网络的自然条件。

未调查资源只能写 hypothesis。
