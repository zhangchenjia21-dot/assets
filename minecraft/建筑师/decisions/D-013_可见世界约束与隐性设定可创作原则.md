# D-013｜可见世界约束与隐性设定可创作原则

状态：**OWNER APPROVED / ACTIVE DECISION**

日期：2026-09-10

## 背景

前序 Region-first 方法强调：文明必须从真实 Minecraft 自然条件中生长，而不能先写设定再强迫地图适配。

WB-003R 的资源调查进一步暴露一个需要修正的边界：如果把“没有机器证据”一律理解为“不能写入设定”，会把本项目误导成对所有世界事实做考古式验证，而不是创作一个可见、可信、可持续建设的幻想世界。

Owner 明确指出：

- 森林、河流、山脉等大尺度自然条件直接暴露在玩家视野中，若与既有存档冲突，修正成本高；
- 地下矿藏等隐性资源通常不可直接观察，且本项目不是生存玩法模拟，没有真实玩家需要逐块采矿验证；
- 因此只要与地表自然条件不矛盾、未来实现成本低，就可以由世界构建主动创作，而不必要求现有存档先证明其丰富度。

## 正式决策

### 1. 严谨性目标不是“所有设定都必须被原存档证明”

本项目的严谨性定义为：

> **重要世界设定必须与玩家实际可见的 Minecraft 世界相容，并控制把设定落实到可见世界中的改造成本。**

Research 的职责是发现硬约束、风险与灵感，不是成为所有 Canon 创作的许可门。

### 2. 世界事实按可见性 / 改造成本分层

#### A. 高可见、高改造成本｜强现实约束

例如：

- 山脉、峡谷、海岸线、岛屿拓扑；
- 大河、湖泊、大型水系；
- 大尺度森林 / 雨林 / 荒漠 / 雪原；
- 区域整体高程、坡度、天际线；
- 大范围既有植被环境。

原则：优先服从真实存档。若 Canon 想与其不同，必须把显著 terraform / landscape rewrite 视为明确建设任务，不得静默假装已经存在。

#### B. 可见但可通过建设逐步形成｜可创作、后落实

例如：

- 农田、果园、牧场；
- 道路、桥梁、码头；
- 采石场、矿井入口；
- 人工林、防风林、水利；
- 聚落、城墙、工业设施。

原则：可以根据文明需要设计，但必须在未来真正进入玩家视野时通过 Build / landscape task 合理实现。

#### C. 低可见 / 隐性、低冲突成本｜允许主动创作

例如：

- 地下矿藏总体丰富度；
- 深层地质与矿脉；
- 地下遗迹或未暴露结构；
- 其它不会直接与现有地表景观冲突的隐性资源事实。

原则：只要不与已知证据明显矛盾，可以由 GPT + Owner 直接作为 World Canon 创作，不要求先用全域扫描证明。

如果未来某隐性设定被建筑、矿井、地下城或玩法暴露到玩家视野，再按需要局部实现或校正。

### 3. Evidence constrains; creation fills

今后采用：

```text
Visible Minecraft evidence
→ 决定哪些东西不能乱写
→ 提供环境与空间基础
→ GPT + Owner 在兼容范围内主动创作缺失世界事实
→ 未来只在真正可见 / 可交互时落实必要细节
```

禁止两种极端：

- 无视可见存档，强贴不匹配的文明 / 环境；
- 把项目变成“存档里没测到就不能创作”的纯调查工程。

### 4. 对资源设定的影响

资源必须区分：

- `OBSERVED_RESOURCE_FACT`：存档直接支持；
- `CANON_AUTHORED_RESOURCE`：Owner / GPT 在环境相容基础上主动创作；
- `IMPLEMENTED_VISIBLE_RESOURCE`：已经通过 Minecraft Build / world edit 进入可见世界。

三者不得混淆，但 `CANON_AUTHORED_RESOURCE` 完全可以成为合法 World Canon。

### 5. CIV-001 东域应用

Owner 批准：

> **CIV-001 东域可以设定为矿产总体丰富的山地区域。**

当前只冻结“富矿山地”这一文明资源方向。

保持 TBD：

- 具体优势矿种；
- 矿脉分布；
- 储量数字；
- 主要矿城 / 矿井位置；
- 是否存在特殊幻想矿物；
- 是否与其它文明形成特定矿产贸易。

WB-003R 的 144 柱样本仍只具有 research presence 价值；它“不足以证明富矿”这一结论不与本 Canon 冲突，因为富矿在此属于 `CANON_AUTHORED_RESOURCE`，不是伪装成机器观测事实。
