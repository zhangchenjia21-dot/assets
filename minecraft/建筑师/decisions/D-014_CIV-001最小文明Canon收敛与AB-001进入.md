## 1. 决策目的

CIV-001 已完成区域自然画像、经济与通达性最小调查，并经过 Owner + GPT 多轮讨论。当前不再继续扩写文明百科，而是冻结足以支撑 Minecraft 建筑与聚落设计的最小文明 Canon，并进入 `AB-001｜CIV-001 First Architecture Grammar`。

## 2. CIV-001 最小文明身份

CIV-001 是南部岛屿群的人类三域联盟文明。

### 三域

- **西域**：西部 C 形低岛。承担主要低平生产空间、人口集中、农牧景观、市场、手工业与联盟级公共功能。
- **中域**：东岛西侧低地 / 坡麓过渡。承担跨岛接驳、仓储、商贸、加工以及低地—山地之间的转换功能。
- **东域**：东部山地核心。是 Owner-approved `CANON_AUTHORED_RESOURCE` 富矿山地，形成矿业、冶金、石工与山地地方共同体。

上述经济角色是文明 Canon 的方向性结构，不是现实人口、产量或贸易流量统计。

## 3. 三域互补

当前联盟的结构性互补冻结为：

```text
西域
低平生产 / 农牧 / 人口 / 市场
        ↓ ↑
中域
接驳 / 仓储 / 商贸 / 加工
        ↓ ↑
东域
矿产 / 冶金 / 石材 / 山地生产
```

三域互相依赖，但这种互补不等于现代统一市场，也不要求每项货物都跨域运输。

## 4. 政治与三席议会

CIV-001 是前现代松散联盟 / 邦联式共同体，不是中央集权王国。

三席议会冻结为三种区域权力的永久联盟席位：

- **西席**：代表西部低岛的主要城镇、庄园与市场权力；
- **中席**：代表海峡、接驳与坡麓城镇；
- **东席**：代表多个山地氏族 / 地方共同体形成的联合席位。

联盟层处理跨域事务，例如对外战争、跨域争端、共同公共工程与重要交换规则；土地、地方治理、继承、普通司法、地方武装、矿山 / 农牧组织与地方祭祀仍主要由地方掌握。

制度原则：普通联盟事务可以通过多方妥协推进；涉及三域根本权利的重大事项要求三域共同同意。具体投票程序、任期、选举制度不冻结，避免现代议会化。

### 联盟政治中心

Owner 已批准：三席议会相关建筑优先位于其所称 **“西部平岛的中心岛”**。

该地点作为联盟共同政治 / 仪式中心的候选锚点，可以设定为不属于普通地方领主的联盟共同空间；精确坐标、边界与建筑布局仍需 site-specific observation 后确定。

## 5. 文化气质

CIV-001 的共同文化基调：

- 务实；
- 重承诺、契约、协商与履责；
- 地方自治传统强；
- 商人、地主、氏族首领、工匠领袖均可能拥有真实社会权力；
- 荣誉更多来自守约、守土、履责与共同体贡献，而不仅是血统。

不同地区可以有明显地方文化差异，但必须保留同一文明的共同制度与物质文化亲缘。

## 6. 宗教

宗教强度为 **中等**：神祇 / 神圣存在真实，但 CIV-001 不是神权国家。

允许的主要表现：

- 地方守护神 / 地方圣所；
- 山地、海渡、矿业、冶炼、祖先等相关祭祀；
- 旅途 / 航渡前仪式；
- 联盟级共同誓约与祭典空间。

不同域可拥有不同地方传统，但存在少量能够支撑联盟共同身份的仪式与神圣场所。

## 7. 魔法

CIV-001 处于中魔世界，但自身不是高普及魔法文明。

魔法为 **低普及、中影响**：主要掌握在少数祭司、学者、医者、炼金师、专业工匠与特定传统家系中。

优先应用于：

- 冶炼与工艺；
- 矿井安全与加固；
- 建筑 / 测量；
- 医疗；
- 航渡与保护；
- 仪式和少量炼金。

魔法不得廉价替代农业、道路、矿工、运输、传统建筑工程或社会组织。

## 8. 建筑技术基准

整体属于成熟前现代石木建筑体系，具备：

- 石砌与成熟木构；
- 木桁架；
- 石拱；
- 瓦 / 石板等硬质屋面；
- 桥梁、挡土墙、城防与水利；
- 矿山、冶炼与工坊工程。

三域物质文化差异：

- **西域**：木石混合、横向展开、院落 / 仓房 / 市场 / 农庄体系明显；
- **中域**：石基 + 木构上层、仓库 / 商栈 / 客栈 / 加工作坊密度较高，强调街道、转运与岸—陆过渡；
- **东域**：重石构、厚墙、石拱、挡土墙、台地、矿井、锻炉与氏族大厅，建筑强烈依附山体并垂直发展。

统一审美不依赖单一“奇幻风格标签”，而应由长期使用、反复扩建、地形适应和功能因果产生。
