# D-018｜Council Centerland 联盟公地与中域交割

状态：**OWNER APPROVED / ACTIVE DECISION**

日期：2026-09-10

## 1. 背景

AB-001P1 已确认 Candidate A 为三席议会政治中心的视觉 / 空间锚点。A 是东部山地主岛向西伸入 C 形海湾的低地陆体，实际干陆约 105,785 blocks²，不是独立岛。

此前 Council Centerland Program / Capacity Plan 将联盟政治核心仅按约 22,000–32,000 blocks² 预留。Owner 认为这一占用相对于整个视觉中心陆体明显过小，并进一步明确了政治土地分配原则。

## 2. Owner 决策

Owner 明确：

1. 图中“中间岛 / 中心陆体”与右侧山地主岛的连接部分，全部划归 **中域**；
2. 联盟共同土地应位于中心陆体的主体核心，边界大致呈 **椭圆 / 卵形**；
3. 椭圆联盟公地之外的 A 剩余陆地进行交割，不继续作为联盟共同领土。

为避免在同一自然陆体上制造不必要的西域飞地，当前采用最简洁政治地理解释：

> **A 内联盟公地之外的剩余陆地全部归中域。**

西域仍位于湾对岸的西部 C 形低岛，通过三席议会制度、联盟公共建筑与未来代表馆参与共同政治中心，而不是通过在 A 上拥有一块西域主权飞地来参与。

东域的直接领土仍以东部山地核心为主；中域承担联盟公地到山地主体之间的连续陆地过渡。

## 3. 新的政治空间结构

```text
西域（湾对岸 C 形低岛）
        ↕ 水面联系
联盟公地｜Council Commons
（A 视觉中心的椭圆 / 卵形共同领土）
        ↔
中域（A 剩余低地 + 东向陆颈 / 坡麓）
        →
东域（东部山地核心）
```

联盟公地不是自然地理意义的独立岛，而是**人为划定的共同政治 / 仪式领土**。

## 4. 联盟公地容量方向

为了使联盟公地在 Minecraft 中具有明确、可见的政治中心尺度，而不是一个小型行政院落，当前 Architecture Planning Baseline 调整为：

- A 总陆地：约 105,785 blocks²；
- 联盟公地目标量级：约 **55,000–65,000 blocks²**；
- 约占 A 总陆地 **52%–61%**；
- 形态：大致椭圆 / 卵形，长轴优先顺应 A 的横向主体；
- 初步长轴量级：约 **340–370 blocks**；
- 初步短轴量级：约 **210–230 blocks**。

这些是规划量级，不是精确地籍坐标或强制几何公式。

最终边界必须：

- 服从 A 的真实干陆 geometry；
- 不把海水或明显断裂地形硬算入公地；
- 允许沿岸线、局部起伏、未来主要入口和道路做有限自然化修边；
- 视觉上仍保持明显的椭圆 / 卵形整体轮廓；
- 东向连接主岛的陆颈必须明确落在中域，而不是联盟公地无限向东延伸。

## 5. 建筑容量影响

联盟公地扩大后，不意味着一次性施工扩大。

成熟期联盟级建筑总 footprint 可提高到约 **14,000–20,000 blocks²** 的规划量级，约占联盟公地 22%–36%；其余仍用于：

- 议事 / 仪式前场；
- 院落；
- 步行与车马通行；
- 岸线空间；
- 结构性植被；
- 视线与景观缓冲；
- 后续扩建余量。

三席议事大厅作为最核心单体，当前建议设计搜索量级调整为：

> **约 3,000–5,000 blocks² ground footprint**

具体长宽高由 AB-001P2 根据真实参考、三席空间、结构跨度、Site 地形与 Minecraft 可读性最终推导，不预设固定矩形。

## 6. 小批次施工原则继续有效

本决策扩大的是**长期政治中心的合理规划容量**，不是单次 Codex 施工范围。

继续执行：

> **一个 world-write Task = 一个主要建筑 / 一个主要空间目标 + 必需最小接口。**

因此即使联盟公地最终约 5.5–6.5 万格²，第一批真实施工仍只允许三席议事大厅主体及直接成立所需的最小地表 / 基座 / 入口处理。

代表馆、档案 / 裁判建筑、誓约设施、码头、道路、广场、景观等必须后续独立推进。

## 7. Canon / Planning 边界

已成为 Owner-approved World / Human Geography Canon：

- A 视觉中心陆体存在一块联盟共同政治领土；
- 联盟公地大致为椭圆 / 卵形核心；
- A 东向主岛连接部分归中域；
- A 中联盟公地之外的剩余陆地当前全部归中域；
- 西域不在 A 上建立主权飞地。

仍属于 Architecture Planning、未冻结为 World Canon：

- 椭圆精确坐标 / RLE 边界；
- 长短轴精确长度；
- 各建筑精确位置；
- 道路 / 码头 / 广场形态；
- 中域与东域更深处的精确政治边界。

`world writes = 0`。
