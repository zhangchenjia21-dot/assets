# D-019｜AB-001P1R 联盟公地东侧连接带边界拟合授权

状态：**OWNER APPROVED / ACTIVE AUTHORIZATION**

## 1. 目的

Owner 已通过 D-018 明确：

> **Candidate A 除最东侧与右侧主岛相连的陆颈 / 连接带之外，其余主体陆地全部属于 Alliance Commons / 联盟公地。**

当前唯一未精确化的问题是：

> **A 主体与东侧连接带应在哪里切开。**

本任务只负责把这一政治 / Architecture Planning 边界拟合成机器可用 geometry，并计算联盟公地真实面积。

## 2. 允许范围

允许：

- 读取 AB-001P1 已有 A geometry / R1 terrain / topology cache；

- 如存在真实歧义，可给最多 2 个候选；
- 计算 Alliance Commons = A − connector 的 actual geometry / area / bounds；
- 输出轻量地图供 GPT / Owner 审核。

原则上不需要重新读取世界方块。

## 4. 边界判定原则

目标不是寻找完美几何椭圆，而是找出：

```text
visual centerland body
↔
east connector / neck
```

最合理的自然分界。

优先考虑：

- A 主体向东明显收窄的位置；
- 两侧岸线共同形成的 neck；
- 横截宽度明显降低；
- 切割后西侧 Commons 保持单一连续主体；
- 切割后东侧 connector 与东岛主陆连续；
- 不制造细碎飞地 / 孤立残片。

地形高差可作为辅助证据，但不能为了政治边界强行追求等高线。
