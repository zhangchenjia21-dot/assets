# D-021｜先完成中域区域调查与总体规划，再进入首栋建筑

状态：**OWNER APPROVED / ACTIVE DECISION**

日期：2026-09-12

## 1. 背景

CIV-001 已建立三域联盟与 AB-001 Architecture Grammar。此前讨论第一座实际地方建筑时，GPT 推荐从中域的商旅 / 转运型建筑开始，因为中域同时体现水陆接驳、仓储商贸、坡麓转换和 CIV-001 共同石木技术，适合作为第一座地方建筑样板。

随后 Owner 明确纠正：

> **不能先找一块地直接做中域单体建筑。应当先利用 Codex 已有地理信息完成中域区域调查，再做中域总体规划，单体建筑必须从总体规划中产生。**

该纠正有效。

## 2. 正式顺序

当前采用：

```text
Middle Domain regional reconnaissance
→ Middle Domain planning profile
→ GPT + Owner overall regional master planning
→ settlement / exchange / production structure
→ first building type + site selection
→ site-local observation
→ single-building architecture design
→ bounded world-write
→ Owner in-game review
```

不得跳过 Regional Planning 直接选择第一栋建筑坐标。

## 3. 本轮调查的目标

中域调查不是重新扫描整个南部岛屿群，也不是重新证明 CIV-001 Canon。

它只补足总体规划需要的空间事实，重点回答：

- 中域西侧与 Alliance Commons / 海峡的真实连接关系；
- 哪些岸线、低地、坡麓和谷地适合形成聚落与交换节点；
- 从水岸向东部山地内部有哪些自然 movement corridor / terrain transition；
- 大型连续 FLAT / GENTLE 空间在哪里，哪些区域应避免高密开发；
- 内水、岸线、植被、岩质地表、危险 / 洞口和既有人工痕迹如何分布；
- 中域内部是否自然形成 2–4 个功能不同的 planning subareas；
- 哪些位置适合未来形成商旅 / 仓储 / 加工 / 居住 / 市场等区域；
- 第一座中域建筑未来应该从哪一类节点中选择，而不是现在就定坐标。

## 4. Evidence 与 Creation 的边界

继续遵守 D-013：

- 可见地形、水系、岸线、植被和真实高差必须服从存档；
- 道路、码头、建筑、居民区等可以在后续总体规划中主动设计；
- 调查结果用于约束总体规划，不要求所有未来功能在当前世界中已经存在。

## 5. 调查尺度

优先复用：

- WB-002R-R1 whole-scope terrain / topology；
- WB-003R 的 M research mask、water/crossing/corridor evidence；
- AB-001P1R 已确认的 Alliance Commons / Middle Domain connector：A 中 `X>=89` 的 13,661 blocks² connector；
- 现有 R1 local raw cache。

只对“中域总体规划真正缺失”的信息做 targeted refinement。

不得因为需要总体规划而重新做整个东岛 / 整个南部岛群的 1-block broad scan。

大型 raw 继续遵守 D-010：Local-only + Lightweight Review Bundle。

## 6. 当前建筑状态

此前设想的“中域商旅转运会馆”仅保留为**可能的首栋建筑类型**，不是已批准 Build。

在中域区域调查和总体规划完成前：

- 不确定其 Site；
- 不冻结其尺寸；
- 不进入建筑设计；
- 不 world write。

三席议事大厅 AB-001P2 同样保持 HOLD；联盟公地现有 Canon / boundary 不受本决策影响。

## 7. 总原则

> **先让建筑在区域结构中获得位置，再让建筑本身获得形态。**

区域总体规划不是一次性施工授权。未来仍执行“小批次施工”：一个 world-write Task 只做一个主要目标 + 必需最小接口。

`world writes = 0`。
