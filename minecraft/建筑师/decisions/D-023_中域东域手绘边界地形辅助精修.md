## 2. 决策

基本原则：

> **Owner 手绘 = 政治意图先验；真实地形 = 边界精修依据。**

Codex 不得重新自动分整个三域，只能围绕 Owner 已画出的 Middle ↔ East 主边界局部吸附、修正和去噪。

## 3. 锁定区域

以下内容本轮不得改动：

- accepted Alliance Commons geometry；
- accepted Alliance Commons ↔ Middle connector 边界；
- West Domain 主体；
- Owner 在 Middle / East 主边界以外的大范围领土判断；
- CIV-001 Canon / Architecture Grammar。

不得把海岛、小离岛、内部水洞或天然断裂自动当作“误涂”删除。

## 4. 地形语义

当前文明设定：

- Middle Domain：西侧低地 / 坡麓 / 接驳 / 仓储 / 商贸 / 加工 / 山海转换；
- East Domain：东部高山核心 / 富矿山地 / 冶金 / 石工 / 山地地方共同体。

因此边界应优先体现**持续的地貌过渡**，而不是直线行政切割。

允许的精修逻辑：

- 连续低地、谷地、坡麓走廊可让 Middle 向东伸；
- 明显山脊、陡坡、强起伏带可让 East 向西压；
- 尽量避免边界横穿一个完整连续谷底；
- 尽量避免把一个连续山脊 / 山体核心机械切成两半；
- 边界可弯折，不要求光滑；
- 不追求等高线、数学曲线或单一阈值。

## 6. 精修尺度

默认只在现有 Middle ↔ East 共享边界周围进行：

- **核心编辑带：距离 Owner boundary ±64 blocks**；

通常改动应落在 ±64 内。

如果某段要偏移超过 64 blocks，必须在报告中给出连续谷地 / 山脊 / 坡折等具体地形证据；超过 128 blocks 默认禁止，除非停止并交 GPT / Owner 重新授权。
