# D-026｜P1 连接带升级为中域门户聚落并修订 MD-001P

## 决策

### 1. P1 从“通行前庭”升级为“门户型聚落区”

P1 仍完整属于 Middle Domain，政治边界与 accepted connector geometry 不变。

新的规划定位：

> **P1 = Middle Gateway District / 中域门户聚落区**

它承担：

- Commons ↔ Middle 的直接跨域门户；
- 短途交易与货物交接；
- 小型短仓与临时周转；
- 车马 / 驮运停驻与修理；
- 旅客服务、饮食与短住；
- 消息 / 告示 / 向导 / 地方服务；
- 常住居民社区；
- 与 N1 主镇之间的高频日常联系。

但不得自动推导：

- 强制关卡；
- 收费站；
- 军事门城；
- 独占贸易制度；
- Commons 一侧主权控制。

### 2. 不把整个 P1 建满

P1 内部至少应区分三类空间：

1. **政治 / 通行阈值带**：靠近 X=89 accepted cut，保持高通行与视线、避让、集散空间；建筑覆盖应谨慎。
2. **门户街市 / 常住生活带**：在 connector 向东扩宽、地势平坦的段落形成紧凑混合社区。
3. **岸线 / 排水 / 结构性开放地**：保留水岸、排水、植被与必要维护空间。

因此“门户聚落”不等于把窄颈堵满建筑。

### 3. P1 与 N1 的关系

P1 不取代 N1 principal hub。

建议功能分工：

- **P1 门户聚落**：即时跨界流动、短驻、短仓、车马、旅宿、小交易、维修、门户居民生活；
- **N1 主镇**：更完整的市场、较大规模仓储、加工、公共服务、长期商业网络和更复杂的居民生活。

两者应形成**门户—主镇双节点连续体**，而不是两个互相竞争的独立大城。

### 4. MD-001P 需要 R1 修订

原 MD-001P 的整体骨架仍有效：

- revision 154 territory；
- P2–P5；
- N1–N4；
- 交通网络框架；
- D-025 密度梯度；
- East / Commons 接口规则。

但以下内容必须修订：

- P1 intensity / land-use；
- 聚落层级，加入门户节点；
- resident-life system；
- human-use-density；
- land-use masterplan；
- movement network 中 P1↔N1 的城市化关系；
- phasing；
- first-build recommendation 必须重新评估。

因此原 MD-001P：
