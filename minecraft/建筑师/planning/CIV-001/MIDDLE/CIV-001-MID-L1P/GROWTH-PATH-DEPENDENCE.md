# 中域区域生长模型

PLANNING_ASSUMPTION；EXISTING_EVOLUTION / MATURE。当前Minecraft实存未刷新，不把下面阶段写成已观察道路，也不是建造批次。

|阶段|当时可知条件和行动|空间响应|反馈与独立存续理由|
|---|---|---|---|
|G-A 地方日常网络|住户知道身边地形、水/取料与邻里，未必知道全山资源|低地、高位与谷地可有地方生活，小范围交换；不提前按现代界线建关卡|即使后续无联盟，人仍要生活和近邻协作；没有让所有小聚落从主城分殖|
|G-B 重复交换|地方运输者逐渐知道可用岸侧窗口与上升路径，协商使用地面|低地多种服务合并，反复等待/交易促使更稳定存留与常住|服务可靠→更多使用→拥堵/供水/地价压力；尚不预留终局城市边界|
|G-C Commons稳定|政治共同体形成后，三席和地方住户面对额外周期访问|connector产生近界即时服务，计入低地中心网络但不自动另建完整门户城|同通道更有价值，也更易冲突；公共访问约定抑制私占与无限收费|
|G-D 山地交换增强|已发现/已使用生产点逐渐进入更广网络，不能由Planner预知未发现矿点|高位地组因就近日常服务、物料整备与反复升降成本强化为第二中心|减轻低地负担；石质地面/水/燃料仍限制扩张，不能无止境专业化|
|G-E 成熟制衡|居民、货主和地方权利人处理拥堵、季节波动、火险与断路|台地/谷地保持地方支持，存留分散；南岸接驳按收益/许可增减|不是每个需求独立一镇；条件改变可合并、缩小或另开分支，历史不必全局最优|

移除高位地方需求或全部专业交换，MID-B可降级，ALT-A重开；移除有效跨水关系，低地峰值/仓储缩减而地方生活仍可存在；移除Commons共同性会改变政治访问关系而非只改标注。保留真实后发现的旧路/地权必须有当前证据与转换成本，不能根据会话里的旧设计填入历史。
