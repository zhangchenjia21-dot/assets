# Middle L1 Regional System / r1

推荐 **两个主要中心 + 两个较小地方服务聚落**：低地综合中心MID-A为主要日常市场和综合服务重心；高位交换中心MID-B承担山地侧交换及其自己的常住生活；MID-T台地与MID-V南谷只作地方支持，不复制区域市场。没有独立证明需要另建一座门户城或南岸港镇。

这是ALT-C，已经与单强中心和多专门中心逐项比较。选择依据不是旧规划或平地排名：两大片平缓组的地理接近、72格量级反复升降、地方日常需求和权利/供给负担共同支持两主要中心；小台地和谷地只有较小支持空间与尚未证实的专门吞吐，不升级为大中心。

Commons东侧连接地带具备即时交易、停留、经营家庭等门户活动理由；本案把它纳入西侧综合服务体系，**既不把整带压成低覆盖通道，也不先分出一座独立次城**。L2须比较核心具体位置及其与近界服务关系，不能在本L1画连续街墙或两个冻结城址。

West食品/生活品可以通过协商的湾内关系与本域陆路分批进入；南岸R-WM作为有条件直接分支，水隙短但背岸升降显著。East物料先比较近源处理，高位中心承担适合的交换/存留，复杂或日常综合交易可向低地流动；不要求所有原矿全部跨水或穿公地。政治访问部分共享低地服务，重大商业存留不得自动占住共同地切口。

两个主要中心都有水、日常采购、居民与过路者、污物/火险/通行负荷，不能只画物流节点。跨域权利、地方土地和公共工程成本必须协商；成熟工程可局部改变坡地/水条件，但不能把海岸视为饮水或权利自动取得。

全域建成工作量级29k–47k（仅聚落fabric，非建筑footprint），约7.42%–12.02%。搜索面积与这组数量分开。以少数混合紧凑核心而非沿路铺房体现D-025；坡面、岸缘和低强度生产/植被/通行空间仍保留。兄弟域覆盖率未知，跨域密度排序为硬条件待同口径核对，不自称实证PASS。

下一步建议MID-A进入L2，因为它能验证connector与主综合服务应如何合并、公共访问和居民生活如何兼容，以及最大一组容量的供水/权利假说。MID-B先发最小East北向依赖请求，不需本轮执行兄弟域。优先顺序是降低规划不确定性，不是指定首栋或施工顺序。

四份L2包仅递归交付。不得执行L2、Builder或world-write。Primary在Critic与机械验证后封存，之后Legacy比较另存，不回填。
