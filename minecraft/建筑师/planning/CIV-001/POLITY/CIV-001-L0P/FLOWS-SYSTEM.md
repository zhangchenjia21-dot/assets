# Flows / stocks / rhythms

方向是Canon支持下的规划需求，不是观测贸易量或现代统一供应链。各域仍可自产自用。需求不等于建筑清单。

## F-FOOD｜食物、牲畜与普通生活品

WEST_DOMAIN → MIDDLE_DOMAIN / EAST_DOMAIN / ALLIANCE_COMMONS

日常消费，收获季补入；牲畜/集市周期峰值

生产户+地方市场+运输者

产地、转换处和山地消费侧分散储备；不将库存全塞Commons

停航或山路断会压迫非农居民；局部自给与分散储备减速而非完全替代

保持West生产开敞；Middle兼具生活与周转，East消费侧有缓冲

产量、消费人数、实际季节均未测；方向来自Canon而非扫描产能

## F-METAL｜矿料、金属、石材与成品

EAST_DOMAIN → MIDDLE_DOMAIN / WEST_DOMAIN / ALLIANCE_COMMONS

采运与加工分批，重货峰值不等于常住人口峰值

山地地方共同体+工匠+货主

产地先行处理与分批下运为方案；允许近用石材避免全跨岛

原料/燃料/道路中断可停工；不要依赖唯一长距离原矿线

山地专业节点、转换服务、低地消费市场；烟尘与生活存在权衡

富矿为Canon；具体矿种、矿点、产量未决；不因样本贫富而改Canon

## F-FUEL｜木材、燃料与一般建设材料

LOCAL_SOURCES_IN_ALL_DOMAINS → LOCAL_USERS_AND_CONDITIONAL_INTERDOMAIN_EXCHANGE

分批补给、加工期峰值；日常燃用持续

地方使用者/权利人+工匠+运输者

分散燃料库存需火险间隔；取用范围与持续性L1再查

冶炼若依赖未经确认燃料会虚增规模；优先检验近用与加工模式

不建立West木材垄断；East冶炼容量与燃料通达联动

三样区均见树干和矿物接触，但不证明可持续木材或煤炭产能

## 运输与生活的共同负荷

联盟服务不是只有出口货物。装卸、驻留、修整与常住家庭共用有通达性的地面；Middle因此有紧凑混合的持续需求。货流峰值需要弹性缓冲，但不能将所有低平地用于存货而没有饮水、生活通行和公共接近。West市场可局部紧凑，生产地不能因贸易收益被整片吞没。East重货应比较产地处理、分段驮运与近用，不能把所有石材假设为跨岛输出。

F-FUEL是材料约束，不是已知贸易线路；F-DEF是紧急联系，不是划定军事区。货运可以分布在不同季节/权利网络，无须都经过Commons。
