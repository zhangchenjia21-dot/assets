# Resilience / failure dependencies

|依赖|受影响者与后果|有界响应|下游责任及限制|
|---|---|---|---|
|West→非农消费者的季节食品|Middle常住/周转、East专业生产、Commons事件；日耗不能等待下批|产地/转换/消费端分散库存；局部自给；必要时减少专业峰值|三L1共同核实补给频率与替代；不虚构无限库存或农业产量|
|湾内水侧接近|停渡影响政治访问与货运|比较R-WC/R-WM与岸点、普通渡运/短桥选项；缓冲等待|不同岸点同受水况，未证独立冗余；不自动修两桥|
|X=89陆侧界面|Commons东侧访问依赖中域；封闭可能破坏共同性|共同访问协议、局部稳路/排水/错峰；水侧替代访问比较|Commons共享对象+A-M，不能把政治地变私有封闭院地|
|山地共用路径|WB三实验线共享段，不是三条独立交通线|比较多接近方向、近源处理、分段运送、消费侧储备|East统筹全域，Middle验证交接；严禁沿示意线直接修路|
|燃料/水与专业生产|矿/冶炼规模可能被供给卡住，居民与工艺争用|先确认近源取用、分散供水/库存、控制峰值与外部性|East/Middle在容量收敛前补证；魔法不能默认补洞|
|公共规则信任|单域征用共同通道或强迫贸易易引发绕行/拒运|地方同意、共同争端救济、收益与负担协商|根本权利三域共同同意为Canon；具体费率/投票不编造|

核心策略是“有地方日常支撑的互赖”，不是完全自给或唯一干线。远端East节点被纳入供给/消息关系，而非为了防故障撤回到西缘。没有敌国证据，不设永久前线；防务重在自治响应与联盟协调。
