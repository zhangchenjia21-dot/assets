## 2. 为什么认为 L0 因果模型成立

### 2.1 多中心联盟，而不是现代功能分区

L0 将 CIV-001 建模为“保有地方日常生活支撑的多中心互赖网络”。West 的低平生产与市场、Middle 的转换 / 加工 / 混合服务、East 的分散专业共同体都同时具有本地生活与跨域关系；没有把三域简化为农业区 / 商业区 / 工业区。

三席议会与 Commons 的存在由跨域争端、共同工程、防务、外交与互赖成本解释；地方自治、土地权和治理成本又限制廉价集中统一。这与已接受 Canon 一致，同时产生了空间后果。

### 2.2 Middle 高密度第一次得到机制解释

Middle 的最高 territory-wide 平均利用强度不再只是 Owner 结论的重复。L0 给出的因果链为：

`Commons / 跨水 / 山地交换 + 居民日常 + 加工 / 等待 / 仓储需求`

与

`有限可达低地 / 谷地 + 地权 / 外部性 / 通行冲突`

叠加，导致共享、混合和紧凑利用具有持续收益。L1-MIDDLE 同时被要求比较“合并式中心”与“分工式转换网络”，没有提前把旧 N1 / G1 双节点重新锁死。

### 2.3 政治访问与商业货流被正确拆开

R-WC / R-CM 关注 Commons 的共同政治访问；R-WM 则作为直接生活品 / 货运交换的比较分支。这样可以避免 Alliance Commons 被错误设计成全联盟唯一商业漏斗，也避免 Middle 利用 connector 自动取得对政治访问的单方控制。
