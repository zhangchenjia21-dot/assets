## 2. 设计目标

设计一座能够真实表达“三域联盟 / 三席议会”政治结构的前现代公共建筑。

核心语义：

- 没有国王 / 单一统治者主位；
- 西席、中席、东席三种区域权力永久存在；
- 三方围绕联盟共同空间协商；
- 共同文明具有务实、守约、履责、地方自治传统；
- 宗教中等可见、魔法低普及中影响；
- 建筑属于同一 CIV-001 石木体系，但可克制表达三域材料 / 工艺亲缘。

建筑应让玩家通过空间而不是说明牌理解：

> **三方彼此独立，但必须进入同一个共同空间。**

## 3. Scope Guard

Owner 明确要求 Codex 不要一次承担过多建筑或过大范围。

### 本轮只允许一个主要建筑

允许设计：

- 三席议事大厅主体；
- 建筑自身必需的门廊 / 小型前场 / 基座 / 台阶；
- 极少量直接服务主体的近邻地表与结构性植被关系。

只允许“预留关系”，不得同时详细设计或形成可施工方案：

- 三域代表馆；
- 联盟大广场；
- 档案馆 / 金库 / 裁判庭；
- 码头；
- 跨岛桥；
- 道路网；
- 城区；
- 大型园林；
- 第二座主要建筑。

### 尺度

- 主体 footprint 目标 `<=45×45 blocks`；
- 建筑不要求方形；
- 单方向如确有空间逻辑可适度延长，但超过约 52 blocks 必须在设计报告中说明必要性；
- 未来第一批总 site intervention envelope 目标 `<=64×64 blocks`；
- 不得因为 Site A 有约 79×79 FLAT 诊断区就把它全部占满。

## 4. 先研究，再设计

本建筑是幻想公共建筑，但其制度与技术基准属于前现代人类社会。

设计前做**有限、针对性的真实参考研究**，优先研究 3–5 个与以下机制相关的真实案例：

- 中世纪 / 前现代 council hall / town hall / guild hall / assembly hall；
- 多方协商而非王座式权力空间；
- 大跨木屋架 / 石木公共大厅；
- 公共仪式、宣誓、议事与旁听的空间关系。

研究重点是：

- 平面与权力关系；
- 入口与公共 / 半公共层级；
- 大厅尺度和结构；
- 采光；
- 屋架 / 墙体；
- 集会动线；
- 建筑如何表达制度。

不得直接复制某一现实建筑外观。

把参考机制记录到设计成果中，并说明哪些被采用、哪些因 CIV-001 / Minecraft 条件被修改。

## 5. 必须完成 Plan / Section / Sequence

### Plan

至少明确：

- 三席在空间中的关系；
- 联盟共同中心；
- 主入口 / 次入口；
- 公众、代表、工作人员的基本动线；
- 议事空间与前厅 / 等候 / 记录等最低限度辅助空间；
- 不得出现一个席位天然成为王座端头；
- 不得机械做成三个完全一样的方盒子。

### Section

至少明确：

- 基座与当地微地形关系；
- 大厅净高；
- 屋架 / 屋顶体量；
- 三席与共同中心的高差关系；
- 主要采光；
- 从湾水与东部山地背景看建筑的 skyline。

不得大面积推平 Site。

### Sequence

至少描述：

1. 从西岛 / 水面方向接近；
2. 到达建筑前；
3. 进入前厅 / 门廊；
4. 进入共同议事空间；
5. 三席如何逐步显现；
6. 离开 / 回望时如何感知湾水和东部高地。

## 6. Architectural Character

必须遵守 AB-001 Grammar。

允许自由设计，但应体现：

- CIV-001 成熟石木体系；
- 公共建筑的耐久、长期扩建感；
- 西域木石、东域石工、中域加工 / 商贸工艺可以形成克制融合；
- 不是哥特大教堂；
- 不是国王宫殿；
- 不是现代议会大楼；
- 不靠大量奇幻尖塔 / 发光方块制造“Fantasy”；
- 魔法只作为少量工艺或仪式性细节，不替代结构逻辑。

### 三席政治空间硬约束

禁止：

- 单一王座轴；
- 一席居高临下统治另外两席；
- 三个完全镜像复制席区；
- 为了“三”而把建筑机械切成三等份。

应该体现：

> 平等存在不等于形状完全相同；共同议事不等于消除三域差异。

## 7. Architect → Critic → Revision

由于这是第一座 Canon 建筑，必须进行一次内部设计审查：

1. `Architect`：形成完整单方案；
2. `Critic`：从功能、制度表达、体量、地形适应、Minecraft 可读性、施工范围、玩家动线检查问题；
3. `Revision`：只保留最终修订方案。

不要生成三套方案让 Owner 选。默认只交一个经过修订的方案。

## 10. Design Acceptance

完成方案必须能够回答：

- 为什么它属于 CIV-001，而不是通用中世纪大厅？
- 为什么它表达三席议会而不是王权？
- 为什么建筑放在 A Site，而不是随便一块平地？
- 三席怎样既平衡又不机械对称？
- 玩家怎样进入、看见并理解核心空间？
- 建筑怎样面对湾水与东部高地？
- 未来如何添加其它政治中心建筑而不要求本轮先建？
- 第一施工批次怎样保持 bounded？

必须检查：

- 门 / 楼梯 / 楼层可达；
- 不出现结构互穿；
- 不无理由占满 Site；
- 不把大广场或道路网偷偷算进大厅；
- 不把 Preview 成功等同设计成功。
