## 1. 文明身份

`CIV-001` 是南部岛屿群的人类三域联盟，也是本项目第一个完整进入 Architecture Grammar 的文明 Pilot。

当前 Canon：

- 主要智慧种：**人类**；
- 核心空间：南部岛屿群两大主体岛及其人文过渡空间；
- 文明结构：**三域联盟**；
- 政体：前现代松散联盟 / 邦联式共同体；
- 核心共同治理机构：**三席议会**；
- 共同文化：务实、重承诺 / 契约 / 协商 / 履责、强地方自治；
- 宗教：中等强度，神圣真实但不形成神权国家；
- 魔法：低普及、中影响，以专业化工艺 / 矿业 / 建筑 / 医疗 / 仪式应用为主；
- 技术：成熟前现代石木建筑、桥梁、水利、矿山、冶炼与手工业工程。

正式文明名与三域正式地名继续 TBD，不阻塞建筑设计。

## 3. 三域生产 / 交换结构

### 西域｜低岛人口与低平生产核心

空间基础：西部 C 形低岛。

Canon 方向：

- 主要低平生产空间；
- 农牧景观；
- 人口集中；
- 市场；
- 常见手工业；
- 联盟级公共功能。

农田、牧场、果园、粮仓、磨坊等属于未来可通过建设真实形成的 `IMPLEMENTED_VISIBLE_RESOURCE`，不要求天然存档已经存在。

### 中域｜跨岛与山地过渡枢纽

空间基础：东部主岛西侧低地 / 坡麓。

Canon 方向：

- 接驳；
- 仓储；
- 商贸；
- 加工；
- 低地与山地产品 / 人员转换。

它不是自动成立的“天然港口”。具体渡点、码头、道路和城镇位置仍需要 Site observation。

### 东域｜富矿山地、冶金与石工核心

空间基础：东部山地核心。

Canon：

> **东域是矿产总体丰富的山地区域。**

证据类型：`CANON_AUTHORED_RESOURCE`。

文明方向：

- 矿业；
- 冶炼；
- 金属加工；
- 石材 / 石工；
- 山地生产；
- 强地方共同体。

具体优势矿种、储量、矿脉和矿城保持 TBD。

## 4. 三域互补

当前结构：

```text
西域
低平生产 / 农牧 / 人口 / 市场
        ↓ ↑
中域
接驳 / 仓储 / 商贸 / 加工
        ↓ ↑
东域
矿产 / 冶金 / 石材 / 山地生产
```

这是联盟长期存在的重要结构性原因，但不表示所有生产都严格垄断在某一域，也不是现代统一市场模型。

## 5. 政治骨架

三席议会是三种区域权力的永久联盟席位：

- **西席**：主要城镇、庄园与市场权力；
- **中席**：海峡接驳、商贸与坡麓城镇；
- **东席**：多个山地氏族 / 地方共同体的联合席位。

联盟层重点处理：

- 对外战争；
- 跨域争端；
- 共同公共工程；
- 重要交换规则；
- 与整个联盟相关的重大外交事务。

地方主要保留：

- 土地；
- 地方治理；
- 继承；
- 普通司法；
- 地方武装；
- 农牧 / 矿山组织；
- 地方祭祀。

普通事务允许多方妥协推进；涉及三域根本权利的重大事项要求三域共同同意。精确投票 / 任期机制保持 TBD。

## 7. 文化、宗教与魔法

### 文化

共同气质：务实、重守约、守土、履责、协商与共同体贡献；商人、地主、氏族首领、工匠领袖都可拥有社会权力。

### 宗教

宗教中等可见。允许地方守护神、祖先、山地、海渡、矿业 / 冶炼等祭祀，并保留少量联盟级共同誓约与祭典。

### 魔法

低普及、中影响。主要掌握于少数祭司、学者、医者、炼金师、专业工匠和传统家系；优先用于冶炼、矿井安全、建筑 / 测量、医疗、航渡保护、仪式等。

魔法不能廉价替代普通生产和工程。

## 8. 建筑技术与地方差异

共同技术：成熟石砌、木构、桁架、石拱、硬质屋面、桥梁、挡土墙、城防、水利、矿山与工坊工程。

地方差异：

- **西域**：木石混合、横向展开、农庄 / 仓房 / 市场 / 院落明显；
- **中域**：石基 + 木构上层、较密的仓储 / 商栈 / 客栈 / 加工空间，强调岸—陆—坡麓转换；
- **东域**：重石构、厚墙 / 拱券 / 挡土 / 台地、矿井 / 锻炉 / 氏族大厅，建筑贴山并垂直发展。

详细可执行规则以 AB-001 为准。
