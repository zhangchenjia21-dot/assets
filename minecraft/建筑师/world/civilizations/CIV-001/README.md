## 2. 当前自然地理事实

`NGEO-009` 是 NG-2 逐列水陆拓扑验证后被 NG-3 收敛的南部低岛。

已接受证据支持：

- 表层陆体被同一外围真实水体分量包围；
- 岛内存在与外围水体分离的内部池塘；
- 真实岛体陆柱面积约 575,385 blocks²；
- 已验证岛体范围约 999 × 1100 blocks；
- 在对应 NG-2 ROI 内不触边，因此“表层岛体”身份较可靠。

但仍不得从此自动推出：

- 整岛政治统一；
- 具体森林覆盖；
- 可航行港口；
- 矿产 / 农业资源；
- 人口容量；
- 聚落位置；
- 建筑位置。

具体建设仍必须按需 local observation / refinement。
