# Fantasy Foundation｜全局最小 Canon

状态：**OWNER APPROVED / WORLD CANON**

批准决策：`../../decisions/D-005_WB-001最小幻想世界基础Canon批准.md`

## 1. 世界基调

这是一个**古老的中魔、多文明奇幻世界**。

世界本身具有真实超自然性：魔法、神祇 / 高等神圣存在、超自然地点与非人智慧种都是真实世界的一部分。但本项目不把奇幻理解为“现实约束全部失效”。

后续文明、聚落与建筑仍必须受到地理、资源、交通、经济、社会制度、工程和历史的共同塑造。

## 2. 魔法

魔法真实存在，并且是世界自然规律的一部分。

魔法可以与地点、生物、植物、矿物、血脉、仪式、知识或神圣力量相关；具体体系按文明需要继续定义。

当前硬约束：

- 真正能够主动、稳定操纵魔法的人或组织不是无限普及的；
- 魔法受到稀缺性、知识、条件、代价或其它限制；
- 魔法不能廉价、普遍地替代农业、道路、船舶、矿业、传统工程和传统建筑；
- 如果未来某项魔法足以改变运输、战争、农业或建筑，则相应社会与空间必须真实发生变化，不能只把魔法作为装饰效果。

## 3. 神祇与宗教基线

神祇或其它高等神圣存在真实存在。

它们可以通过神迹、圣地、神圣生物、祭司力量或其它方式留下真实影响，但不会持续、直接地管理凡人社会，也不会为所有宗教争议提供即时且唯一的公开答案。

因此不同文明仍可以拥有不同的：

- 神学解释；
- 宗教组织；
- 仪式；
- 圣地；
- 神圣建筑；
- 对同一超自然事实的不同文化理解。

具体神系与宗教保持 TBD，按文明需要创建。

## 4. 技术与物质文化

世界主体社会的技术基准约为现实的**中世纪盛期～晚期**。

这意味着传统农业、石木建筑、城堡与城墙、冶金、航海、水利、道路、商业城市和大型宗教建筑等可以普遍存在。

不同文明不要求处于同一条科技树。

### 幻想蒸汽工业

世界中已经存在**局部、非均质的幻想蒸汽工业**。

蒸汽、压力、齿轮、泵、起重机械、锅炉、锻造设备以及魔法能源与机械的结合可以在特定文明或地区出现。

当前不默认：

- 全世界已进入现代工业革命；
- 铁路和自动化工厂全球普及；
- 传统城镇、农业、城堡和手工业已被淘汰。

幻想蒸汽工业将主要与第四智慧种族的文明方向关联，具体实现后续定义。

## 5. 智慧种族基线

当前只冻结四个一级槽位，不提前写完整种族百科。

### 人类

存在。具体人口规模、文明分布与政治结构尚未定义。

### 林地长生种

存在。

“林地长生种”目前是描述性占位称呼，不是正式族名。其具体寿命、生理、繁殖、文化和魔法能力将在 `CIV-001` 设计中逐步定义。

### 山地 / 地下种

存在。

当前同样只是描述性占位称呼；具体生理与文明保持 TBD。

### 第四智慧种族

存在槽位已保留，但正式设定 TBD。

已批准方向：其文明与**幻想蒸汽工业**高度关联，但不能简单成为“更会造机器的山地种 / 矮人换皮”。

## 6. 历史深度

这是一个已经经历漫长历史的世界。

未来允许存在：

- 古代文明遗址；
- 旧道路；
- 废弃城镇；
- 被后世复用或改建的建筑；
- 多个建设年代叠加形成的城市和聚落；
- 已经失落或被重新解释的历史。

目前不建立完整纪元年表，也不预设某场全球灾变。具体历史只在其能够解释某个文明、遗迹、建筑或区域时再创建。

## 7. Just-in-time Worldbuilding

本项目不是小说世界观百科工程。

后续只在 Minecraft 建造真正需要时补充设定：

```text
Global Foundation
→ 一个真实区域
→ 一个文明
→ 足够的区域 / 文化规则
→ Architecture Grammar
→ Canon Build
→ 真人进入 Minecraft 验证
→ 再按缺口补 Canon
```

除非 Owner 明确要求，不提前填满宇宙论、完整神系、完整种族谱系、完整政治地图或数千年年表。
