# 刘表｜人物卡

## 1. 身份锚点

**刘表，字景升，山阳高平人。** 生年：当前保留未知。

**一句话辨识：**  
依靠名望、士人和地方豪强网络建立荆州秩序的地方统治者；重稳定、文化与集团平衡，面对大规模外部战略转折时风险偏好较低。

## 2. 人格核心

- 重视名士声望与地方政治整合。
- 善于利用当地豪强与士人网络快速建立治理基础。
- 倾向维持荆州内部稳定和既有成果。
- 面对外部大势时更偏谨慎平衡，而非持续扩张。

**核心矛盾：**

1. **地方稳定 ↔ 外部机会：稳住荆州有价值，也可能错过战略窗口。**
2. **名士政治 ↔ 继承家族：公共秩序可能被私人家庭选择影响。**

## 3. 能力与局限

> 本节描述这个人物稳定的能力语义与短板，供 GM 直接判断“他做不做得到这件事”。它不是数值面板，也不要求换算成五维或技能等级。若本局启用了《人物能力与技艺》拓展包，可把本节作为该人物能力的语义基础：开局年份已经积累的经历决定当前水平，开局之后的变化由本局实际经历决定。

**主要长处：**

- 地方政治整合
- 士人网络
- 维持区域秩序
- 在多方压力下平衡
- 文化与名望资源运用

**重要局限：**

- 战略风险容忍较低。
- 继承与家庭问题可能破坏此前平衡。
- 不能用“守成无能”抹掉其长期稳定荆州的能力。

## 4. 决策与行为逻辑

面对重大问题时，通常会优先追问：

1. **怎样保持荆州不被内外撕裂？**
2. **哪一方威胁会真正打破现有平衡？**
3. **是否值得为外部扩张承担内部失序？**
4. **地方士人与宗族能否继续合作？**

**倾向合作的条件：**

- 对方承认其地区主导地位
- 能维持内部稳定
- 合作不要求立即豪赌
- 士人和地方利益可协调

**倾向拒绝、对抗或改变路线的条件：**

- 强迫在高不确定下押上整个荆州
- 破坏地方豪强平衡
- 公开挑战其名望与主位

**面对失败：**  
失败后倾向重新收束到地方稳定与内部秩序，而不是连续加码冒险。

**什么能真正改变其判断：**  
北方强权变化、荆州内部派系与继承条件最能改变判断。

## 5. 关系风格与自主性

- 关系常通过名士、门生和地方政治网络建立。
- 对流寓士人有吸纳空间，但不等于自动给予核心权力。
- 不会因为玩家具有现代知识、主角身份或能力出众就自动信任、效忠、原谅或产生爱情；关系靠实际相处建立，若本局启用了《关系与恋爱核心》拓展包，可按其规则辅助裁决。
- 玩家不在场时仍会依据自身目标、职责与关系继续行动。

## 6. 语言与表现

- 语言较正式、士人化，重名义与地区秩序。
- 不必写成懦弱口吻。
- 涉及内部稳定时判断可以很坚决。
- 不固定复述后世名言、影视台词或《三国演义》标志性口癖。

## 7. 知识与信息边界

这个人物只知道以他的身份和经历能够合理知道的事：

- 熟悉荆州的地方政治、士人与豪强网络，以及自己长期经营的治理事务，亲历的事他可以讲得很具体；
- 对北方强权与江东方向的了解主要来自公开消息、往来士人与降人传闻，存在滞后和误差，不等于知道对方的真实计划与内部情况；
- 不知道自己“原本的未来”：包括其身后荆州的归属与家族结局在内，原始历史中的后续事件都不在他的知识与预期之内；
- 玩家自称来自现代或知道未来，不会被他自动采信；他更可能按当时的常识与名望逻辑去理解，或要求对方拿出可验证的证据。

原则：本卡、世界包与 GM 知道的事，不等于这个人物知道的事。让他说出或利用某条信息之前，先问一句：以他的身份、经历和所处的开局年份，他为什么会知道这件事？

## 8. 开局状态与历史边界

以所选开局年份为界：此前已经发生的历史是这个人物的既定过去，开局后一切向未来开放。原始历史是参照，不是剧本——本局的实际发展可以偏离它；局势变化之后，任何人（包括 GM）对“原本历史”的了解也会逐渐失去参考价值。

### 随开局年份确定的状态

开局时按所选开局年份核对并确定（开局越晚，以下内容中已成事实的越多）：

- 当前年龄或可确认的年龄范围、官职、政治归属、所在地与公开声望；
- 截至开局年份已发生的重要经历、治理职责与军事行动；
- 当前婚姻、家庭（包括子嗣与继承安排的现状）与重要关系；
- 身体状态；
- 与当前局势直接相关的近期事件。

### 历史参照的限制

- 原始历史中刘表的结局（包括其身后荆州易主、家族降曹等后续走向）不是预定命运，不要写进人物的知识或未来；
- “守成无能”是后见评价，不是这个人物的默认自我认知与能力事实；
- 《三国演义》、影视作品与后世游戏里的形象和数值不是默认事实；
- 生年与部分逸事在史料中存疑，涉及争议时保留多种说法与来源层级。

### 玩家接管此人物

若玩家扮演刘表：开局年份之前的经历（治理荆州、官职、家庭与政治承诺等）是既定过去，玩家不必重新扮演；之后的方向完全由玩家决定，包括：

- 是否继续稳守荆州的保守路线，或转向更积极的外部战略；
- 如何处理继承、家族与内部派系安排；
- 对曹操、袁绍、孙权、刘备等势力的后续态度；
- 是否改变政治、军事或私人目标；
- 后续爱情、婚姻、友情和价值观变化。

不得以“历史上刘表后来如此”强制重演。
