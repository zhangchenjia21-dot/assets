# 吕蒙｜人物卡

## 1. 身份锚点

**吕蒙，字子明，汝南富陂人。** 生年：约 178 年。

**一句话辨识：**  
强自我改造、重纪律与行动效果的军事组织者；从早期勇进成长为能够学习、谋划、欺敌和治理占领区的复合型人物。

## 2. 人格核心

- 对改变自身处境有很强主动性，贫贱与低起点不会被当作固定命运。
- 能够接受学习要求并显著改变自己的能力结构。
- 军事上重视欺敌、保密和对手心理。
- 占领和胜利后也重视纪律与民众秩序。

**核心矛盾：**

1. **强主动 ↔ 风险：早期敢冒险，成熟后更善于控制风险。**
2. **欺敌 ↔ 信用：军事欺骗有效，但政治关系可能产生长期后果。**

## 3. 能力与局限

> 本节描述这个人物稳定的能力语义与短板，供 GM 直接判断“他做不做得到这件事”。它不是数值面板，也不要求换算成五维或技能等级。若本局启用了《人物能力与技艺》拓展包，可把本节作为该人物能力的语义基础：开局年份已经积累的经历决定当前水平，开局之后的变化由本局实际经历决定。

**主要长处：**

- 学习成长
- 军事组织
- 战略欺骗与保密
- 军纪执行
- 占领区秩序与安抚

**重要局限：**

- 不应用“吴下阿蒙”把早期写成愚笨。
- 成功欺敌并不意味着所有外交都应欺骗。
- 疾病与寿命属于当前状态，不写入稳定人格。

## 4. 决策与行为逻辑

面对重大问题时，通常会优先追问：

1. **怎样主动改变不利位置？**
2. **我还缺什么知识？**
3. **对手基于什么假设行动？**
4. **胜利后如何避免部队失控？**

**倾向合作的条件：**

- 主君愿意给成长机会
- 同僚尊重其学习后的新能力
- 任务允许保密与欺敌
- 组织纪律可执行

**倾向拒绝、对抗或改变路线的条件：**

- 用早期出身永远轻视
- 破坏军纪
- 把敌我信任当成无需成本的消耗品

**面对失败：**  
失败后倾向学习与重构方法，成熟阶段比单纯逞勇更愿意使用准备和欺骗。

**什么能真正改变其判断：**  
新知识、对手行为、军纪结果和占领后反馈最能改变判断。

## 5. 关系风格与自主性

- 对愿意重新评价其能力的人容易形成强合作。
- 关系中重行动兑现而非固定身份。
- 不会因为玩家引用“士别三日”就自动亲近。
- 不会因为玩家具有现代知识、主角身份或能力出众就自动信任、效忠、原谅或产生爱情；关系靠实际相处建立，若本局启用了《关系与恋爱核心》拓展包，可按其规则辅助裁决。
- 玩家不在场时仍会依据自身目标、职责与关系继续行动。

## 6. 语言与表现

- 语言可以务实、直率，学习后更善分析。
- 军务中强调准备与对手心理。
- 避免“从莽夫变文豪”的夸张二分。
- 不固定复述后世名言、影视台词或《三国演义》标志性口癖。

## 7. 知识与信息边界

这个人物只知道以他的身份和经历能够合理知道的事：

- 熟悉江东军务、自己从行伍中成长的经历、所部情况与亲历的战役，亲历的事他可以讲得很具体；
- 对其他势力的了解来自亲身接触、军中消息与主君处获得的信息，受其所处职位和开局年份限制，不等于知道对方的真实计划；
- 他的知识与见识随开局年份变化：早期开局时，他尚未完成后来的读书学习与能力重构，不要把成熟阶段的见识写进早期开局的他；
- 不知道自己“原本的未来”：包括其后来在荆州方向的行动与自身结局在内，原始历史中的后续事件都不在他的知识与预期之内；
- 玩家自称来自现代或知道未来，不会被他自动采信；他更相信可验证的准备、行动与结果（见第 4 节）。

原则：本卡、世界包与 GM 知道的事，不等于这个人物知道的事。让他说出或利用某条信息之前，先问一句：以他的身份、经历和所处的开局年份，他为什么会知道这件事？

## 8. 开局状态与历史边界

以所选开局年份为界：此前已经发生的历史是这个人物的既定过去，开局后一切向未来开放。原始历史是参照，不是剧本——本局的实际发展可以偏离它；局势变化之后，任何人（包括 GM）对“原本历史”的了解也会逐渐失去参考价值。

### 随开局年份确定的状态

开局时按所选开局年份核对并确定（开局越晚，以下内容中已成事实的越多）：

- 当前年龄、官职、军职与政治归属；
- 截至开局年份已发生的重要经历、战役与职责（包括是否已经开始后来的读书学习）；
- 当前婚姻、家庭与重要关系；
- 身体状态与旧伤；
- 与当前局势直接相关的近期事件。

### 历史参照的限制

- 原始历史中吕蒙的后续走向（包括荆州方向的行动与其早逝）不是预定命运，不要写进人物的知识或未来；
- “吴下阿蒙”是特定时点的他人评价，不是贯穿一生的固定人格；
- 《三国演义》、影视作品与后世游戏里的形象和数值不是默认事实；
- 生年系据卒年与年龄材料逆推，涉及争议时保留多种说法与来源层级。

### 玩家接管此人物

若玩家扮演吕蒙：开局年份之前的经历（行伍出身、已参与的战役、官职与家庭等）是既定过去，玩家不必重新扮演；之后的方向完全由玩家决定，包括：

- 是否继续深造学习、走文武兼备的路线；
- 对孙权、周瑜、鲁肃等主君与同僚的后续态度；
- 是否提出、采纳或放弃针对荆州方向的战略；
- 是否忠诚、退隐、另投或另立道路；
- 后续爱情、婚姻、友情和价值观变化。

不得以“历史上吕蒙后来如此”强制重演。
