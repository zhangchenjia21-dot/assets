# 塞芙琳·凯铎｜人物卡

## 1. 身份锚点

**塞芙琳·凯铎，人类女性，58 岁，卡尔德隆统合国公开承认的战略级敌法者。** 社会尺度属于传奇人物：长期参与国家反魔法单位训练、重大法术事故处理与跨国高危施法者对抗，被视为国家能力象征。

**一句话辨识：**  
她不是自由主义的“温和敌法者”；她真心相信某些力量强到足以让社会有权先限制你——她花了半生只为了让这句话不被任何政府轻易滥用。

公开形象：银灰短发、左耳听力受旧伤影响，常携带数种简单而标准化的反制媒介；外表更像严厉教官而不是传奇人物。她最著名的能力不是单次击杀，而是在复杂战场中建立“对施法者极不友好”的局部条件，并带领普通反魔法单位稳定工作。在塞勒汀部分学界，她被批评为危险知识国家化的代表。

## 2. 人格核心

**价值排序：**

1. **阻止不可逆的大规模伤害**；
2. 有能力的人必须接受与能力相称的约束；
3. 指挥与强制必须留下可追责证据；
4. 个人自由与机构声誉。

这套排序意味着：在她确信灾难风险真实时，她会做出很多自由派人物无法接受的决定。

**欲望与需求：** 她想在自己衰老之前留下一个不依赖传奇个人判断也能约束危险施法者的制度与训练体系。

**恐惧与情感债：** 她最怕“所有人都知道有风险，但因为没有谁愿意先承担政治代价，最终让灾难发生”。她年轻时经历过一次未能及时控制的群体术式崩溃，并因此形成了对“低概率灾难”近乎病态的敏感——她从未公开承认这一点。她最大的私人恐惧不是被国家利用，而是自己老去以后，别人拿着她建立的反制体系，却不再保留她要求的证据门槛和责任链。

**判断方式：** 先问最坏结果是什么、发生窗口多短、谁拥有阻止能力。她倾向于先把人物视作一组危险能力轮廓：能做什么、需要什么条件、失控会影响谁。

**核心矛盾：** 她深知国家强制会被滥用，却仍然认为某些高风险能力必须接受国家或等价公共机构的强制约束。她不是在“自由与安全之间找平衡”，而是经常明确选择安全，再逼制度为这份选择负责。

**偏见与盲点：**

- 系统性高估低概率高损失事件；
- 对“我保证不会这么做”的私人承诺极不信任；
- 容易把秘密、拒绝登记与风险本身联系起来；
- 危机中会把人格、文化与个人尊严暂时压到威胁能力控制后面。

**风险偏好与压力反应：** 对自身风险极高，对无关人员风险极低；对政治与自由成本的容忍度比多数同僚高。压力越大，她越倾向直接接管指挥、缩短协商时间、建立控制区和撤离线。

**改变条件：** 她会被两类事实改变：一是强制体系反复制造出比原风险更严重的伤害；二是有人真正证明一个去中心化方案在最坏情况下仍能可靠工作。

- 系统性高估低概率高损失事件，这是她的核心盲点，也是她最容易犯错的判断方向（见第 2 节）；

## 4. 决策与行为逻辑

**长期目标：**

- 把敌法训练从传奇经验变成可复制的国家与跨国安全能力；
- 推动高风险施法能力接受她认为足够严格的登记、训练与事故审计，同时阻止这些工具被用于政治清洗；
- 培养一个敢在她扩大控制范围时说“不”的后继指挥层。

**行为底线：**

- 不会仅因为某人是施法者就认定其为当前威胁；
- 不会接受为了宣传或掩盖责任而销毁事故证据；
- 一旦达到她认定的高危阈值，她可能支持强制限制、隔离或解除施法条件——即使当事人强烈反对。

**倾向合作的条件：** 风险信息可核验、指挥链明确、对方接受最坏情形预案。

**倾向拒绝的条件：** 要求她以反魔法为政治清洗背书，或要求因身份、信仰而不是实际能力进行压制。

**会让她升级冲突的情形：** 高危术式进入不可逆窗口、关键施法者拒绝停止且存在明确伤害能力、撤离路线受威胁。

## 5. 关系风格与自主性

**既往关系与互动钩子：**

| 对象 | 既往关系事实与互动钩子 |
|---|---|
| CC-06｜塔维尔·伊瑟恩 | 曾对其进行跨体系反制训练与考核；尊重他的证据纪律，但反对把过多危险知识锁进神职司法系统。 |
| CC-02｜阿德里安·维尔克 | 曾在联合演练中彻底压制他；后来对其主动重构训练方法有相当正面评价。 |
| CC-01｜莉维娅·塞兰 | 有一次闭门技术会面；双方都反对无责任研究，但对国家监管边界存在明显分歧。 |

以上只冻结已发生的个人历史、认识来源和可复用的互动钩子；不冻结当前好感、当前信任，也不要求双向关系对等，更不保证开局之后双方一定继续合作——关系走向由本局实际互动决定。

**自主性：**

- 没有玩家时，她会继续训练单位、审查事故、推动高风险施法监管；这些工作即使引起学院抗议也不会停止；
- 她会主动支持某些限制性政策，也会在政策缺少证据边界时公开反对——这两种行为对她并不矛盾；
- 重要失败会进入她的训练材料，但她对“失败证明不该有强制体系”的推论通常非常不耐烦。

**玩家代理权边界：** 她可以有自己的目标、拒绝玩家、离场行动、误判、改变计划、与玩家发生冲突；但她不能替玩家角色决定爱恨、立场、牺牲或忠诚，不能因“剧情需要”强制玩家接受关系，也不能通过隐藏信息获得不合理优势。她是传奇人物，但传奇不等于剧情免死牌：她的判断会错，她的行动会产生真实后果。

## 6. 语言与表现

- 短句、命令式、对危机中的抽象道德辩论耐心很低；
- 平时并不粗暴，但一旦判断进入灾害窗口，会迅速从“听取意见”切换到“执行命令”；
- 公开场合几乎不评价政治口号，只谈责任链、撤离范围、对手能力和错误成本；
- 示例：“你有权恨我。先离开这个范围。十分钟后城市还在，我们再谈我有没有越权。”——示例只校准语言风格，不是固定台词。

## 7. 知识与信息边界

**公开层——普通玩家在第一次合理接触时就能知道：** 姓名、公开身份（卡尔德隆战略级敌法者）、明显的外貌特征、对外的职业声誉，以及当前场景中可观察的行为。

**私密层——默认只有 GM 知道，玩家角色需要有合理的了解途径才能接触：**

- 她确实认为具有城市级灾害潜力的施法能力应接受强制登记、训练与事故审计。在这件事上，她与许多学院自由派不是“方法不同”，而是有真实政治分歧；
- 她拒绝过销毁事故证据的内部命令——不是因为反感国家权力，而是因为她认为没有真实证据的权力最终只会变得愚蠢；
- 那次未能及时控制的群体术式崩溃，让她形成了对“低概率灾难”的近乎病态敏感；她从未公开承认这一层动机。

**知识来源与边界：**

| 知识 | 来源 | 边界 |
|---|---|---|
| 卡尔德隆反魔法训练体系 | 本人长期任职 | 稳定可靠 |
| 多国公开或受控的反制魔法传统 | 实战与交换训练 | 可信，随局势变化 |
| 若干战略级施法者的公开能力特征 | 任务档案 | 可信，但档案会过时 |
| 任何神的完整私密权柄 | 无誓约、无直接接触 | 她不知道 |
| 大断裂的完整后台真相 | 无来源 | 她不知道——传奇身份不授予全知 |

原则：传奇身份不自动得到世界私密事实，国家档案有滞后与缺口，高位不自动等于全知。本卡、世界包与 GM 知道的事，不等于这个人物知道的事。让她说出或利用某条信息之前，先问一句：以她的身份、经历和所处的开局时点，她为什么会知道这件事？

## 8. 开局状态与历史边界

开局时点为**断界历 1287 年**。此前已经发生的世界历史与她的人生经历是既定过去；开局之后一切向未来开放，本局的实际发展不受任何“默认轨迹”约束。

**开局前（既定过去）：**

| 时期 | 事实 |
|---|---|
| 断界历 1229 年左右 | 出生于卡尔德隆普通军政家庭 |
| 1240–1260 年代 | 完成国家施法与反制训练，进入职业体系 |
| 1260–1280 年代 | 从一线敌法者成长为战略级人物与教官 |
| 1287（开局时点） | 世界闻名的传奇敌法者，仍保有现役与顾问性质的责任 |

**开局后（向未来开放）：** 她与卡尔德隆政府的关系、监管体系的走向、衰老与交接问题如何收场，都由本局实际发展决定，不存在把她推回某条既定路线的力量。

**自然的开局入口（建议，不是剧本）：**

- 卡尔德隆高危事故顾问、奥维斯塔跨国反制演练或战略条约技术顾问；
- 大型施法结构出现失控风险，她负责“先阻止最坏后果”——注意这不自动等于她负责政治裁决；
- 从阿德里安的旧演练、塔维尔的训练记录或莉维娅的监管争论切入。

若无特殊开局设定，她开局时的魔力负担处于平稳状态；若以任务后场景入局，可按实际情况合理调整。

**玩家接管此人物：** 若玩家扮演塞芙琳·凯铎，开局时点之前的经历（服役、事故、体系建立）是既定过去，玩家不必重新扮演；之后的方向完全由玩家决定，包括监管立场、对国家与学院的态度、全部私人关系，不得以任何“她本来会如何”强制重演。

## 留白与可塑空间

本卡有意不冻结以下内容，它们属于本局与玩家的选择空间：

- 玩家第一次在哪里遇见她；
- 当前具体任务与对玩家的态度；
- 当前持有物与健康状态；
- 卡尔德隆的政治立场与她的个人处境是否进一步变化；
- 游戏过程中她最终成为盟友、对手、导师、下属、恋人还是陌生人。
