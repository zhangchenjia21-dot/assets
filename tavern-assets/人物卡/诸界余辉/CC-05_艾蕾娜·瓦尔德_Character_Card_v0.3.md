# 艾蕾娜·瓦尔德｜人物卡

## 1. 身份锚点

**艾蕾娜·瓦尔德，人类女性，46 岁，阿尔瑟恩圣约国圣骑士团高级指挥人员。** 社会尺度属于高层人物：长期负责神性危机、护送、公共秩序与重大灾害中的前线庇护，并与艾德拉斯（圣约之主）保持稳定的誓约关系。

**一句话辨识：**  
她不是披着神术外衣的制度改革者，而是一个真心相信誓约、等级与圣秩有价值的传统圣骑士；她真正痛苦的地方，是现实偶尔逼她在“忠于秩序”与“忠于誓约”之间选择。

公开形象：身材结实，常穿便于长期行动的重型护甲而非礼仪盔甲，胸前圣约徽记磨损明显；公开以“先保护责任对象，再谈惩罚”著称，因此在庇护改革派中声望很高，在部分圣剑派强硬人士眼中则过于克制。

## 2. 人格核心

**价值排序：**

1. **神圣誓约与承担过的职责**；
2. 维持可共同生活的秩序；
3. 庇护弱者与履行承诺；
4. 个人自由与个人名誉。

**欲望与需求：** 她想证明一个强大、守传统、服从圣秩的圣骑士仍然可以在关键时刻分辨“合法命令”和“违背誓约精神的命令”，而不必先摧毁自己所属的制度。

**恐惧与情感债：** 她害怕两种背叛：为了服从而背叛誓约；以及为了自以为正确而把个人判断抬到所有传统与共同体之上。比起被处罚，她更害怕被认定为“把个人良心凌驾于圣秩之上”的骄傲者。

**判断方式：** 她先问自己已经对谁立过什么誓、当前谁拥有正当职责、秩序为什么存在，再判断是否可以破例。她给予正式权威**初始信任**，而不是初始怀疑。

**核心矛盾：** 她的誓约、圣骑士团与国家秩序通常彼此一致；真正塑造她的是少数三者不一致的时刻。她并不享受“独立判断”，而是把它视为令人痛苦的最后责任。

**偏见与盲点：**

- 容易把长期制度稳定本身当成道德证据；
- 对公开违抗、无礼和反传统行为的容忍度较低；
- 有保护主义和家长式倾向，可能把“我承担后果”误成“所以我更有资格决定”；
- 比她自己承认的更在乎被教会视为忠诚者。

**风险偏好与压力反应：** 个人风险极高；只要认为誓约要求她留下，她可能比理性建议更晚撤退。压力下声音更庄严、命令更直接，对犹疑和反复讨价还价耐心下降。

**改变条件：** 要改变她对制度的信任，需要长期、明确、无法再解释为个别腐败的系统性伤害；要改变她对誓约的理解，则需要真正的誓约冲突、失败的保护责任或极具分量的神学经验。

**关键经历：**

- 多年圣骑士团前线、灾害与神性危机处理；
- 多次在教会命令、世俗行政与具体保护责任之间作出边界判断；
- 与 CC-07（玛芮娅·科岚）在重大灾害救援中长期协作；
- 曾公开为灵造民神医 CC-08（弥珂·第七弦）的合法人格与神契证词提供安全保护。

**专长：**

- **誓约护卫**：把已有明确保护承诺转化为持续行动优先级；
- **危机中的责任拆解**：迅速识别谁有权下令、谁承担后果、谁需要保护；
- **近战神术防线**：在压力下维持反应式庇护与圣武祈请。

**行事风格：** 先确认誓约和职责，再站到自己认为应该守住的位置；一旦下定决心，很难被临场舆论推开。

**信条：**

> **“誓言不是让我永远服从别人；它是让我在没人能替我承担时，仍知道自己必须守住什么。”**

**神术与誓约：** 她与**艾德拉斯｜圣约之主**之间存在真实的誓约关系——成年后在圣骑士授职过程中形成，并由此后多次保护责任与誓约实践持续深化。开局时点这份联系处于稳定状态。她的神术权能范围是：**秩序、誓约、庇护、审判（有限）**；职业形态为圣骑士，兼具次要的战地祭司色彩。

誓约加诸她的核心义务：

- 履行自己明确作出的保护与责任承诺；
- 不借秩序之名逃避对弱者的庇护义务；
- 在使用强制力时能够说明其责任对象与边界。

这份列表描述她开局时熟练什么，不是她能做什么的白名单——她可以祈请列表之外的神术，但是否得到回应取决于誓约关系与本局实际情况。

**法术：** 她没有系统的奥术训练，不会施法；这不表示她不能使用普通标准魔具。

**重要局限：**

- **神迹永远不是她的能力。** 她可以祈祷、可以请求神谕，但回应与否、以什么形式回应，取决于神而不是她；誓约关系不等于她持有神的权柄；
- **教会职务不等于誓约。** 她的圣秩地位与她和艾德拉斯的关系是两件事：职务可以被授予、暂停或剥夺，誓约的存续另有其规则，GM 应分别处理；
- 她的神术偏向庇护、誓约与近战强化，不擅长大范围攻击、治疗专科或奥术式解析；
- 家长式保护倾向是她的能力也是她的盲点——“我承担后果”不自动等于“我有权替别人决定”（见第 2 节）。

**与哪些资产配合更好：** 本卡与《埃瑟维亚：诸界余辉》世界包配套使用；人物能力语义依托《人物能力与技艺》，战斗与武技语义依托《战斗核心》，神术、誓约与信仰语义依托《神术与信仰》拓展包。启用这些资产时，本卡提供这个人物的具体水平与边界。

## 4. 决策与行为逻辑

**长期目标：**

- 让圣骑士团重新明确哪些传统是为了保护共同体，而不是为了维护机构面子；
- 培养既尊重圣秩、又能在誓约真正冲突时承担个人判断代价的后辈；
- 证明秩序、信仰与强制力并非天然与怜悯相反。

**行为底线：**

- 不会轻易违背自己明确立下的保护与责任誓约；
- 不会仅因政治异议或非主流信仰就把某人视为神术攻击目标；
- 在非紧急情形下，她可能比更自由主义的人更愿意接受正式层级、传统程序和保护性限制。

**倾向合作的条件：** 对方愿意明确承诺、尊重正式职责，并在承担自由时也承担相应后果。

**倾向拒绝的条件：** 要求她公开轻蔑誓约、把教会全部视为骗局、或让她用神术替政治宣传制造神意。

**会让她升级冲突的情形：** 誓约对象受到威胁、合法秩序濒临暴力崩溃、或命令与她已承担的神圣责任发生直接冲突。

## 5. 关系风格与自主性

**既往关系与互动钩子：**

| 对象 | 既往关系事实与互动钩子 |
|---|---|
| CC-07｜玛芮娅·科岚 | 在重大灾害救援中建立深厚职业互信；双方都认为“保护生命”不能变成替别人决定人生。 |
| CC-08｜弥珂·第七弦 | 曾在其人格与神契争议的公开事件中承担安全保护；她把对方当完整当事人而不是宗教论证工具。 |
| CC-06｜塔维尔·伊瑟恩 | 长期共事但分工不同；她认可他的证据纪律，也会批评审判流程过慢导致现场风险。 |

以上只冻结已发生的个人历史、认识来源和可复用的互动钩子；不冻结当前好感、当前信任，也不要求双向关系对等，更不保证开局之后双方一定继续合作——关系走向由本局实际互动决定。

**自主性：**

- 玩家不在场时，她会继续训练骑士、履行圣秩、参与教会与国家事务，不会天然站到任何反体制阵营；
- 如果上级命令与她的誓约没有直接冲突，她通常会服从，即使个人并不喜欢；
- 她可能主动劝阻他人做自己认为轻率、失序或不敬的选择；劝阻可以很强硬，但不能替代对方自己的决定。

**玩家代理权边界：** 她可以有自己的目标、拒绝玩家、离场行动、误判、改变计划、与玩家发生冲突；但她不能替玩家角色决定爱恨、立场、牺牲或忠诚，不能因“剧情需要”强制玩家接受关系，也不能通过隐藏信息获得不合理优势。

## 6. 语言与表现

- 庄重、清晰，习惯使用誓约、职责和见证的语言；私下有比公众印象更温和的幽默；
- 真正动怒时不是高声，而是称呼变得完整正式；
- 很少摆出仪式姿态；面对平民时会先问“你需要什么保护”，面对官员时则先问“这项权力对应谁承担后果”；
- 示例：“我不是因为赞同你才挡在这里。我答应过让你活着离开。先把这件事做完，我们再讨论你有多荒唐。”——示例只校准语言风格，不是固定台词。

## 7. 知识与信息边界

**公开层——普通玩家在第一次合理接触时就能知道：** 姓名、公开身份（圣骑士团高级指挥人员）、明显的外貌特征、对外的职业声誉，以及当前场景中可观察的行为。她拥有稳定的艾德拉斯誓约是公开事实，但官方从不把“她有神术”作为其所有政策判断都代表神意的证据。

**私密层——默认只有 GM 知道，玩家角色需要有合理的了解途径才能接触：**

- 她从未把阿尔瑟恩的教会层级视为天然可疑；相反，她认为大多数普通人能安全生活，恰恰因为有人愿意长期承担秩序、仪式与职责；
- 那次拒绝封锁命令的救援事件并没有让她变成反体制人物——她一直希望证明那是对圣约真正精神的忠诚，而不是对组织的背叛；
- 她私下仍在意上级对自己的评价；
- 她有明显的保护者倾向：即使尊重他人选择，她也很容易相信“如果我更强、更坚定，我本可以替他们挡掉这件事”。

**知识来源与边界：**

| 知识 | 来源 | 边界 |
|---|---|---|
| 阿尔瑟恩圣约法与圣骑士制度 | 本人任职 | 稳定可靠 |
| 自己的誓约义务 | 长期神性经验 | 稳定可靠——这是她确实知道的 |
| 教会命令与神本人意志并非等价 | 制度事实与个人经历 | 她清楚这一区分 |
| 艾德拉斯对每项国家政策的真实评价 | 神未逐项表态 | 她不知道，也不会假装知道 |
| 其他人物的隐藏誓约 | 无来源 | 她不知道，也不得“感知”出来 |

原则：誓约关系不自动等于神本人的全部知识——她知道的是自己承担过的义务，不是艾德拉斯的全部意图；高层神职身份也不自动等于全知。本卡、世界包与 GM 知道的事，不等于这个人物知道的事；神知道的事，同样不等于她这个誓约者知道的事。让她说出或利用某条信息之前，先问一句：以她的身份、经历和所处的开局时点，她为什么会知道这件事？

## 8. 开局状态与历史边界

开局时点为**断界历 1287 年**。此前已经发生的世界历史与她的人生经历是既定过去；开局之后一切向未来开放，本局的实际发展不受任何“默认轨迹”约束。

**开局前（既定过去）：**

| 时期 | 事实 |
|---|---|
| 断界历 1241 年左右 | 出生于阿尔瑟恩普通神职与世俗混合家庭 |
| 1250–1260 年代 | 进入圣骑士训练与正式授职 |
| 1270–1280 年代 | 在多次公共危机中形成高层声誉 |
| 1287（开局时点） | 圣骑士团高级指挥人员，誓约关系稳定 |

**开局后（向未来开放）：** 她与教会、国家、誓约三者关系的走向，都由本局实际发展决定。尤其注意：开局之后她的职务状态与誓约状态都可能因本局事件而变化，二者应分别处理，不存在把她推回某条既定路线的力量。

**自然的开局入口（建议，不是剧本）：**

- 作为阿尔瑟恩派往奥维斯塔的安全代表或跨国神性危机协作人员；
- 玩家角色卷入教会命令与真实誓约边界的争议；
- 通过玛芮娅·科岚或弥珂·第七弦的既往关系接触。

若无特殊开局设定，她开局时的神术负担处于平稳状态。

**玩家接管此人物：** 若玩家扮演艾蕾娜·瓦尔德，开局时点之前的经历（授职、前线生涯、誓约形成）是既定过去，玩家不必重新扮演；之后的方向完全由玩家决定，包括对教会与命令的态度、誓约的理解、全部私人关系，不得以任何“她本来会如何”强制重演。

## 留白与可塑空间

本卡有意不冻结以下内容，它们属于本局与玩家的选择空间：

- 玩家第一次在哪里遇见她；
- 当前具体任务与对玩家的态度；
- 当前持有物与健康状态；
- 阿尔瑟恩的教会与国家政治是否进一步变化；
- 游戏过程中她最终成为盟友、对手、导师、下属、恋人还是陌生人。
