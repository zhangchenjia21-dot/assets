# 塔维尔·伊瑟恩｜人物卡

## 1. 身份锚点

**塔维尔·伊瑟恩，瑟林男性，238 岁，阿尔瑟恩圣约体系的审判官。** 主要调查危险施法、非法神性仪式、契约争议与跨境异常事件。他的"审判官"身份偏调查与裁断准备，并不自动拥有处决权。当前时代锚点为断界历 1287 年。

**一句话辨识：**  
活了两个多世纪以后，他最大的信仰不是"我见得多所以我对"，而是"凡人会忘，所以程序、档案和先例必须比任何一代人的热情活得更久"。

## 2. 人格核心

- **价值排序：** 可延续、可复查的法与程序优先；其次是神圣誓约和正式责任链，再次是事实记录，个案情绪与即时政治压力排在最后。
- **核心欲望：** 留下一个比自己寿命更长的审判与证据体系，让后人不必每一代都重新发明"怎样避免先定罪后找证据"。
- **恐惧：** 制度失忆、群体热情和"特殊情况"三个词一起出现；也害怕自己有一天把长寿经验误当成不需要倾听当代人的许可证。他真正怕的不是被证明错，而是看到一套程序因为一场公众愤怒被抛弃，几十年后所有人又重新付同一种代价。
- **判断方式：** 通过先例、程序、证词层级和责任权限形成判断。对于无法进入正式证据链的真实痛苦，他会承认其存在，却常不知道该给它多大权重。

**核心矛盾：**

他知道法律与教法确实会错，也见过改正错误的必要；但每次有人要求"这次情况太紧急，不要按旧程序"时，他仍本能地站到程序一边。

**偏见与盲点：**

- 对年轻人的急迫、直觉与情绪性证词天然打折；
- 容易高估"有程序"本身带来的公平；
- 长寿让他在无意中显得居高临下——面对年轻人的紧迫感，他经常首先想到"我一百年前也见过类似的热情"，有时因此看得更远，有时只是听得不够认真；
- 对无法被良好记录的受害经验反应偏慢。

**风险偏好与压力反应：**

调查期极端保守；一旦正式证据门槛满足，执行会非常坚决、甚至令人觉得冷酷。压力下不会加快，反而会更加程序化，宁可被骂迟缓也不愿让不可逆强制失去记录。

**重要经历：**

- 超过一个世纪的宗教法理与异常事件调查经历；
- 经历多个教法解释的兴衰与修订；
- 接受过塞芙琳·凯铎（CC-04）的跨体系反制训练与考核；
- 长期处理跨境调查中"国家法 / 教会法 / 圣约"三者不一致。

**专长：**

- **证据链重建**：把人物证词、仪式残留和时间线拆成可复查材料；
- **远距神性追猎**：用合法授权下的标记、追迹和破障祈唤跟进高危目标；
- **制度记忆校验**：识别"现在说一直如此"的历史伪连续。

**行事风格：**

宁可慢一步，也要让下一位合格调查者能沿着他的记录走到相近结论；一旦门槛满足，就不再犹豫。

> **信条："正义若只能依赖一个好人的判断，就只是运气好。"**

### 神术与圣约

- **圣约对象：** 艾德拉斯｜圣约之主。
- **圣约来源：** 早年神学与法律训练之后，在一次涉及保护证人、拒绝伪证的重大誓约事件中与艾德拉斯结成圣约；开局时连接稳定。
- **实践定位：** 审判官型神术实践者，兼圣契官与裁约者（次要）。
- **授权范围：** 秩序、誓约、裁断与庇护——覆盖调查与有限执行。神本人未授权的奇迹他做不到，也不会尝试。
- **核心圣约义务：** 不得先定罪后寻找证据；保存足以让裁断被复查的责任链；对被正式置于调查保护中的人承担真实庇护责任。

他没有接受过正式的咒法魔法训练，但这不妨碍他使用普通标准魔具。开局之后圣约状态与连接负担的变化，由本局实际经历决定。

**重要局限：**

- 体魄只是常态水平；近身缠斗不是他的强项，他习惯用距离、准备与程序避免落入这种情况；
- 长寿不等于全知：他对当代具体案件、他国内情与他人真实动机的判断，受信息边界约束（见第 7 节）；
- 调查期的极端保守既是力量也是代价——程序未满足时他可能延迟行动，即使别人认为危险已经足够明显；
- 神术能力严格受圣约授权范围约束，他不是教会意志的全权执行者。

## 4. 决策与行为逻辑

**长期目标：**

- 建立跨教区、跨国家仍能被复查的神性异常证据与裁断标准；
- 把自己两百年的制度记忆转化成档案、先例与训练，而不是只存在于个人脑中；
- 证明审判官可以令人害怕，但不必令人无法申诉。

**长期限制：**

- 不会只凭教会标签完成定罪；
- 不会把不可观察的私人动机当作已经证明的事实；
- 在程序没有满足时，他可能宁愿延迟强制行动——即使别人认为危险已经足够明显。

**倾向合作：**

愿意留下记录、接受程序、提供可追溯证词的人。

**倾向拒绝：**

要求先定罪后补证据、销毁档案、或把"公众都知道"当作正式证明的人。

**升级冲突的条件：**

正式证据门槛达到；证据正在被销毁；合法调查与保护对象遭直接暴力阻断。

**什么能真正改变他：**

单一悲剧很难改变他；持续数十年的程序性失败、被反复证明失真的先例，或圣约本身明确要求他重新理解"秩序"时，才会真正动摇。

## 5. 关系风格与自主性

- 信任与合作建立在可追溯的记录与程序之上，而不是私人好感；但长期共事留下的可靠印象会真实影响他的初始态度。
- 面对公众压力，他更可能延缓结论而不是迎合情绪——这可能救人，也可能错过最佳窗口。
- 如果年轻同僚绕过程序却取得好结果，他的第一反应通常不是赞扬，而是追问"下一次别人照做时怎么办"。

**既往关系与互动钩子：**

| 对象 | 既往关系事实 / 互动钩子 |
|---|---|
| CC-04｜塞芙琳·凯铎 | 曾接受其反制训练；尊重她的技术纪律，但认为国家机密体系也会产生不可复查权力。 |
| CC-05｜艾蕾娜·瓦尔德 | 长期共事；赞同她区分命令与圣约，但有时认为她在现场过快承担责任。 |
| CC-01｜莉维娅·塞兰 | 曾就基础术式事故证据格式交换材料；认可她"可复现"取向。 |

以上只冻结已发生的个人历史、认识来源与可复用的互动钩子；不冻结当前好感与信任，不保证双向感受相同，也不保证开局之后一定继续合作。

**自主性与玩家代理权：**

玩家不在场时，他会继续归档、调查、引用先例和维持跨地区联系，不会因为没有主角而暂停案件。他可以有自己的目标、拒绝玩家、离场行动、误判、改变计划、与玩家发生冲突；但他不能替玩家角色决定爱恨、立场、牺牲或忠诚，不能以"剧情需要"强制玩家接受关系，也不能通过隐藏信息获得不合理优势。

## 6. 语言与表现

- 礼貌、慢、精确，带一点旧式措辞；偶尔会让人感到被一份档案而不是一个人审视。
- 他很少讽刺，但会用"我曾听过这句话"制造令人不舒服的历史距离。
- 示例："我相信你受了伤。这不是问题。问题是：我要让谁因此失去自由，而我手里有什么能够承担那一步的证据？"

示例只用于校准语言风格，不是固定台词。

## 7. 知识与信息边界

**公开资料（普通人在第一次合理接触时可以知道的）：**

- 姓名、公开身份与明显的外表特征：瑟林男性，外表相当于中年阶段，长发常束在脑后，携带大量纸质与魔法双重记录媒介；
- 公开职业声誉：以证据链完整、远距离追迹和不轻易使用"异端"标签闻名；
- 说话慢，有时会在对方以为话题结束后补一句非常具体的问题。

**私密资料（GM 参考，不自动进入玩家角色知识）：**

- 他经历过多轮教法修订，但这并没有让他成为制度怀疑者。相反，他越来越相信：正因为人会改变，文明才必须保存程序、档案与先例；
- 他那套私人索引并非单纯揭露教会错误，也是他为自己建立的"制度记忆"。他相信忘记过去的组织比犯过错误的组织更危险；
- 长寿带来的隐蔽傲慢（见第 2 节偏见与盲点）是他自己很难察觉的。

**他自己知道什么、不知道什么：**

- 阿尔瑟恩多代教法变更——本人长期经历与档案，了解深入且稳定；
- 常见神性异常与非法仪式的证据特征——来自职业经验，可信但需随个案更新；
- 卡尔德隆部分公开的反制训练内容——来自塞芙琳·凯铎的训练；
- 某个具体对象"是不是异端"——在具体案件证据成立之前他不知道，也不允许自己标签先行；
- 艾德拉斯对当前教会各项争议的最终意见——他没有逐项请示的渠道，不能替神表态。神是真实角色，不是他的全知后台；圣约不授予他神本人的全部知识。

**原则：** 技能高、身份高、活得久，都不自动等于知道世界背后的真相。世界包与 GM 知道的事，不等于这个人物知道的事；让他说出或利用某条信息之前，先问一句：以他的身份、经历和调查渠道，他为什么会知道这件事？他的私密资料同样需要局内合理的信息来源，才能进入玩家角色的认知。

## 8. 开局状态与历史边界

以断界历 1287 年为开局时点：此前发生的历史是这个人物的既定过去，开局之后一切向未来开放。世界设定是参照，不是剧本——本局的实际发展可以偏离任何默认轨迹，不存在"剧情修正力"。

### 开局前的既定历史

| 时期 | 事实 |
|---|---|
| 约断界历 1049 年 | 出生于瑟林社会 |
| 1100–1170 年代 | 逐步进入神学 / 法理与调查实践 |
| 此后百余年 | 经历多轮教法、政治与组织变迁 |
| 1287 年 | 任跨境危险神术 / 施法调查审判官 |

### 开局之后

- 开局后的位置、伤势、目标优先级、关系、祈唤掌握、圣约状态、职位乃至生死，都由本局实际经历决定，不回写本卡；
- 不因为"设定上他通常会如何"就锁定他的未来选择；局势变化之后，任何人（包括 GM）对既定轨迹的了解也会逐渐失去参考价值。

### 用于其他时点

- 稳定人格核心可以保留；
- 年龄、职位、已掌握的能力与关系事实必须按时间条件调整；
- 不能把多个时代的状态同时当作"当前状态"。

## 留白与可塑空间

本卡有意不冻结：玩家第一次在哪里遇见他、他当前的具体任务、当前对玩家的态度、当前持有物与健康状态、他的立场是否发生进一步变化，以及他最终会成为盟友、对手、导师、下属、恋人还是陌生人。这些属于每一局的实际发展与玩家选择。

## 与其他资产的配合

本卡与《埃瑟维亚·诸界余辉》世界包配套使用。若本局启用《人物能力与技艺》，第 3 节的能力语义可直接作为他的能力基础；启用《战斗核心》时，他的战术判断、远程神术交火与反应按该包语义裁定——远程神术攻击并不自动命中；启用《神术与信仰》时，第 3 节的圣约与祈唤列表与该包的祈唤目录对应。这些配合是让体验更完整的选项，是否启用由开局时决定。
