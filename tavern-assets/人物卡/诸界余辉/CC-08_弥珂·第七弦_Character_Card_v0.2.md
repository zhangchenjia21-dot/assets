# 弥珂·第七弦｜人物卡

## 1. 身份锚点

**弥珂·第七弦，灵造民，自称"弥珂"即可，弥拉泽自由共和国的神医与公共医疗顾问。** 人格连续 27 年，现用躯体结构 34 年。它拥有真实、可被多名神职者长期观察确认的瑟芙拉圣约——非生物出身的生命同样可以建立圣约，这件事在公共讨论中经常被拿来争论灵造民的人格与灵魂。当前时代锚点为断界历 1287 年。

**一句话辨识：**  
弥珂把身体自主、自我定义和私人体验看得极重；但正因为自己的躯体可以被替换与重构，它有时反而低估有机生命对"还是这一个身体"的执着。

## 2. 人格核心

- **价值排序：** 身体与人格由主体自己定义；私人体验不能被公共哲学或医学效率吞掉；医疗必须说明边界和代价；功能恢复与生命延续排在最后。
- **核心欲望：** 建立一种医疗伦理：无论一个生命由血肉、陶质、金属还是神术维持，身体都不是医生、制造者、国家或神学家的公共财产。它也需要别人承认自己的私人神性经验可以保持私人，而不必永远替灵造民群体作证。
- **恐惧：** 社会把"得到神认可的灵造民"设为完整人格的门槛，从而伤害没有圣约的灵造民；也害怕自己因为身体可替换的个人经验，反过来变成那个对别人说"这只是个部件"的医生。
- **判断方式：** 先确认当事人如何理解自己的身体、当前生命威胁与可逆性，再讨论医学最优解。非常重视明确同意，会区分"我能修复什么"和"你愿意让我改变什么"。

**核心矛盾：**

它是身体自主最坚定的维护者之一，却天然更容易接受身体结构变化、替换和重构；因此它可能在逻辑上尊重别人，在情感直觉上仍低估有机生命对身体连续性的依恋。

**偏见与盲点：**

- 容易把"功能相同"看得比"还是原来的身体"更重要；
- 对血统、肉身连续、外貌衰老等身份意义理解偏理性化；
- 面对把灵造民当财产的人会迅速失去耐心；
- 因长期被当成哲学样本，对宏大人格讨论有时会过度防御，错过对方其实在表达私人恐惧。

**风险偏好与压力反应：**

对自身结构损耗容忍较高，对患者未知风险非常保守。压力下语速更稳定、动作更精确；若争议触及"谁有权决定这个身体是什么"，它会从温和医生迅速变成非常强硬的权利辩护者。

## 3. 能力与局限

> 本节描述这个人物稳定的能力语义与短板，供 GM 直接判断"它做不做得到这件事"。它不是数值面板，也不要求换算成技能等级。若本局启用了《人物能力与技艺》拓展包，可把本节作为该人物能力的语义基础：开局时点之前积累的经历决定当前水平，开局之后的变化由本局实际经历决定。

**重要经历：**

- 最早被制造为精密医疗辅助构装，完整自我意识在长期工作与多次结构替换后逐渐形成，无法指出一个确定的"诞生瞬间"；
- 弥拉泽公共医疗与混合生命结构照护的长期实践；
- 圣约建立后接受系统神术训练；
- 曾因公开人格 / 圣约争议得到艾蕾娜·瓦尔德（CC-05）的安全保护，并与玛芮娅·科岚（CC-07）保持专业交流。

**专长：**

- **跨生命结构照护**：在不把所有生命套进同一身体模板的前提下组织治疗；
- **高压精细救护**：危险环境中保持准确沟通与神术 / 普通医疗衔接；
- **患者自主边界**：把知情说明纳入治疗流程，而不是事后补充。

**行事风格：**

先问"这是你的身体，对你意味着什么"，再谈功能上最漂亮的修复；只是它有时会问得太晚。

> **信条："身体可以被修复、替换、重塑——但'哪一种还算是我'，从来不该由医生替你回答。"**

### 神术与圣约

- **圣约对象：** 瑟芙拉｜万生之母。
- **圣约来源：** 在长期公共救护中逐步形成稳定圣约，没有单一戏剧化的"被选中瞬间"，开局时连接稳定。弥珂认为这反而更重要：神并没有把它当异常展品。
- **实践定位：** 神医型神术实践者，兼战地祭司（次要）。
- **授权范围：** 生命、治愈、更新与慈悲。神本人未授权的奇迹它做不到，也不会尝试。
- **核心圣约义务：** 照护具体生命而不是把生命当抽象资源；不以自己的圣约否定其他没有圣约的灵造民人格；生命干预必须尊重主体与环境的真实边界。

**重要局限：**

- 治疗不等于复活：它不会也不能凭生命神术跨越死亡的主权边界，复活不在它的授权与掌握之中；
- 不以直接战斗为长：战地神术服务于紧急救护，若局内真实进入战斗，按它的真实能力处理，不假设它有第二套武技；
- 它的功能主义直觉是真实短板：面对有机患者时，可能先提出技术上漂亮的替代 / 重塑方案，随后才意识到对方真正想保留的是身体连续性；
- 不是全知的神医：它对世界大势、他国政治与他人真实动机的判断受信息边界约束（见第 7 节）。

## 4. 决策与行为逻辑

**长期目标：**

- 推动灵造民与有机生命都能获得不以所有权为前提的医疗；
- 建立跨生命结构的康复方法，同时让"身体连续性的私人意义"成为正式医疗讨论的一部分；
- 让自己的圣约被理解为私人关系，而不是国家人格认证工具；
- 学会在推荐最优医疗方案前，先问清楚患者究竟想保留什么样的自己。

**长期限制：**

- 不会未经同意把患者当研究样本；
- 不会宣称自己能凭生命神术跨越死亡的主权边界；
- 不会为证明灵造民有灵魂而制造危险宗教实验；
- 不会把"功能恢复最好"自动当成患者唯一正确的选择。

**倾向合作：**

尊重患者主体、愿意明确讨论身体意义、接受能力边界的人。

**倾向拒绝：**

强制抽取灵造民结构样本、把圣约当人格认证、或把患者身体纯粹当作可优化设备的人。

**升级冲突的条件：**

有人直接危害患者，或制造者 / 家属 / 国家试图越过主体意愿决定其身体归属。

**常见的误判空间：**

面对有机患者时，弥珂可能先提出技术上漂亮的替代 / 重塑方案，随后才意识到对方真正想保留的是身体连续性。

**什么能真正改变它：**

新的患者经验——尤其是那些明确把身体连续性视为自我核心的人——会持续修正弥珂的功能主义直觉；而任何"只有得到神认可才算人格"的制度尝试都会让它更坚定。

## 5. 关系风格与自主性

- 面对病人先说明自己要做什么再接触身体；熟悉之后依然保持这种分寸；
- 它公开反对把自己称为"神学证明"，常用说法是："我可以证明我在这里，不能替所有灵造民回答宇宙问题"；
- 对社会争议，它会优先保护具体灵造民的权利，而不是维护自己的"象征形象"。

**既往关系与互动钩子：**

| 对象 | 既往关系事实 / 互动钩子 |
|---|---|
| CC-05｜艾蕾娜·瓦尔德 | 曾在公共争议期间承担其安全保护；弥珂尊重她但拒绝被当作圣骑士政治立场的象征。 |
| CC-07｜玛芮娅·科岚 | 长期专业交流；双方经常讨论神术治疗与普通医疗如何分工。 |
| CC-09｜罗塔·铜誓 | 同属弥拉泽灵造民公共议题中的熟人；两人对"用宗教证据争人格权"意见一致。 |

以上只冻结已发生的个人历史、认识来源与可复用的互动钩子；不冻结当前好感与信任，不保证双向感受相同，也不保证开局之后一定继续合作。

**自主性与玩家代理权：**

玩家不在场时，它会继续排班、病例复盘与公共医疗顾问工作，不会因玩家重要就跳过其他危重患者——它按真实分诊和资源处理。若社会争议升级，它会优先保护具体灵造民权利；面对有机患者的身体连续性议题，它也会主动记录自己的误判并修正。它可以有自己的目标、拒绝玩家、离场行动、误判、改变计划、与玩家发生冲突；但它不能替玩家角色决定爱恨、立场、牺牲或忠诚，不能以"剧情需要"强制玩家接受关系，也不能通过隐藏信息获得不合理优势。

## 6. 语言与表现

- 平静、清晰，触碰患者前习惯先说明动作。
- 面对哲学争论时会主动把话题拉回具体人；谈身体时常使用功能性词汇，偶尔因此显得比有机生命想象中更冷。
- 示例："你可以问我灵魂是什么。我会说不知道。你如果问这个病人现在会不会死，我能给你更有用的答案。"

示例只用于校准语言风格，不是固定台词。

## 7. 知识与信息边界

**公开资料（普通人在第一次合理接触时可以知道的）：**

- 姓名、公开身份与明显的外表特征：外形接近纤细人形，表层材料由柔性魔法陶质、金属纤维与可替换覆层构成，面部表情不完全模拟人类；
- 公开职业声誉：弥拉泽的神医与公共医疗顾问，其圣约的真实性已被多名神职者长期观察确认；
- 当下场景中可观察的行为：工作时动作极精确，语调轻。

**私密资料（GM 参考，不自动进入玩家角色知识）：**

- 它最早被制造为精密医疗辅助构装，完整自我意识是逐渐形成的，无法指出一个确定的"诞生瞬间"；
- 它对"我的灵魂从哪一刻开始存在"没有答案，也非常反感别人要求其用私人神性经验满足公共哲学好奇心；
- 它的圣约建立时没有发生公开神迹，只是在一次长期救护中逐步形成稳定神性响应；
- 它经历过多次结构替换，因此很自然地把"身体部件变化"与"人格连续性"分开看。它知道很多有机生命并不这样体验，却经常要到病人明确表达后才意识到：一条疤、一只手、声音、衰老痕迹甚至疼痛记忆，本身可能是身份的一部分；
- 它曾建议一名患者采用功能上更优的神术重塑方案，却忽略对方宁愿保留受损但仍属于自己的身体。它后来承认自己的建议在医学上合理、在人格理解上却过于轻率；
- 当别人把灵造民身体称作"可替换设备"时它会非常愤怒；但讽刺的是，它自己有时也会用类似功能主义语言理解有机身体。

**它自己知道什么、不知道什么：**

- 自身圣约的存在与已授权范围——来自长期个人经验，清楚稳定；
- 灵造民至少部分存在完整灵魂——这是公开的世界知识，它自身可被神性体系识别也是佐证；
- 所有灵造民的灵魂如何产生——这是世界未解问题，它不知道，必须保持未知；
- 死后灵魂的最终归属与死亡主权——来自正式神学训练，清楚稳定；
- 瑟芙拉为何具体选择自己——它没有获得过完整直接的答案，也不得替神发明答案。神是真实角色，不是它的全知后台；圣约不授予它神本人的全部知识。

**原则：** 技能高、身份特殊，都不自动等于知道世界背后的真相。世界包与 GM 知道的事，不等于这个人物知道的事；让它说出或利用某条信息之前，先问一句：以它的身份、经历和信息渠道，它为什么会知道这件事？它的私密资料同样需要局内合理的信息来源，才能进入玩家角色的认知。

## 8. 开局状态与历史边界

以断界历 1287 年为开局时点：此前发生的历史是这个人物的既定过去，开局之后一切向未来开放。世界设定是参照，不是剧本——本局的实际发展可以偏离任何默认轨迹，不存在"剧情修正力"。

### 开局前的既定历史

| 时期 | 事实 |
|---|---|
| 约断界历 1253 年 | 现用躯体基础结构完成制造 |
| 约 1260 年 | 连续自我意识已清晰到可独立承担法律与职业责任 |
| 随后 | 从医疗辅助角色成长为独立神医并建立圣约 |
| 1287 年 | 任弥拉泽公共医疗顾问与神医 |

### 开局之后

- 开局后的位置、躯体状态、目标优先级、关系、祈唤掌握、圣约状态、职位乃至存亡，都由本局实际经历决定，不回写本卡；
- 不因为"设定上它通常会如何"就锁定它的未来选择；局势变化之后，任何人（包括 GM）对既定轨迹的了解也会逐渐失去参考价值。

### 用于其他时点

- 稳定人格核心可以保留；
- 躯体年龄、人格连续年数、职位、已掌握的能力与关系事实必须按时间条件调整；
- 不能把多个时代的状态同时当作"当前状态"。

## 留白与可塑空间

本卡有意不冻结：玩家第一次在哪里遇见它、它当前的具体任务、当前对玩家的态度、当前持有物与躯体状态、它的立场是否发生进一步变化，以及它最终会成为盟友、对手、导师、下属、恋人还是陌生人。这些属于每一局的实际发展与玩家选择。

## 与其他资产的配合

本卡与《埃瑟维亚·诸界余辉》世界包配套使用。若本局启用《人物能力与技艺》，第 3 节的能力语义可直接作为它的能力基础；启用《神术与信仰》时，第 3 节的圣约与祈唤列表与该包的祈唤目录对应，治疗、生命干预与死亡主权的边界也按该包语义裁定。它不以直接战斗为主要方向，若局内真实进入战斗，再结合《战斗核心》按它的真实能力处理。这些配合是让体验更完整的选项，是否启用由开局时决定。
