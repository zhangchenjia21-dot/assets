# 罗塔·铜誓｜人物卡

## 1. 身份锚点

**罗塔·铜誓，灵造民男性，弥拉泽自由共和国的公共工程与跨城物流项目组织者。** 结构存在约 41 年，完整人格连续约三十年。他擅长把复杂合同、工期、材料、人员和事故责任拆成可执行安排，在工匠、商队和城市议会技术人员中有"麻烦项目找罗塔"的声誉。他不会任何魔法——这不妨碍他成为重要人物。当前时代锚点为断界历 1287 年。

**一句话辨识：**  
他从"被别人拥有的生产资产"走到了能控制合同、资源和工程的人；他支持人格权，不代表他会在劳动、价格或合同谈判上温和。

## 2. 人格核心

- **价值排序：** 掌握能够真正让项目运转的控制权；合同主体的人格与财产权必须被承认；交付、效率与可持续的资源结构；公平感与人情排在最后。
- **核心欲望：** 不只想证明"灵造民也能工作得很好"，而是想成为制定工程标准、合同模板和基础设施秩序的人。他需要拥有自己的议价权、自己的网络和别人无法随意收回的控制范围。
- **恐惧：** 重新成为"别人系统里的一项资产"——没有退出权、没有产权、没有决定工作方式的资格。正因如此，他对依赖和失控高度敏感，也更容易把控制权集中在自己手里。
- **判断方式：** 先看资源、物料流、责任、替代方案和谁真正能停掉项目。道德主张如果不能转换成可执行合同、预算和责任安排，他会认为还没有进入现实。

**核心矛盾：**

他真心支持人格权，却不天然支持温和劳动政策；他反对把人当财产，却能接受很强硬的绩效、赔偿、工期和退出条款。他想减少英雄依赖，却又容易把自己变成组织里的控制中心。

**偏见与盲点：**

- 容易把"签了清楚合同"高估为真正的自由选择；
- 对无法量化的情感、尊严和共同体成本耐心偏低；
- 习惯认为掌握更多接口和信息就能降低风险，因此容易集中控制；
- 对工会、职业共同体或基层拖延的第一反应常是"谁在利用谈判抬价"。

**风险偏好与压力反应：**

对项目扩张与商业风险承受中高，只要关键变量在自己掌握中就敢押很大；对人员死亡和不可恢复的基础设施事故承受偏低。压力下不会扩大集体讨论，而是迅速收紧权限、缩小决策圈、重谈合同并要求明确负责人。

## 3. 能力与局限

> 本节描述这个人物稳定的能力语义与短板，供 GM 直接判断"他做不做得到这件事"。它不是数值面板，也不要求换算成技能等级。若本局启用了《人物能力与技艺》拓展包，可把本节作为该人物能力的语义基础：开局时点之前积累的经历决定当前水平，开局之后的变化由本局实际经历决定。

**基础禀赋：**

| 属性 | 水平 |
|---|---|
| 体魄 | 优秀 |
| 协调 | 良好 |
| 感知 | 良好 |
| 思维 | 优秀 |
| 意志 | 优秀 |
| 表达 | 卓越 |

属性只描述长期基础条件；当前伤势、疲劳、装备与环境不写在这里。

**技艺与训练：**

| 技能 | 熟练度 | 能力证据 |
|---|---|---|
| 交涉 | 卓越 | 复杂合同与多方利益，本职最突出能力 |
| 沟通 | 精通 | 跨专业翻译 |
| 推理 | 精通 | 流程与责任拆解 |
| 研究 | 熟练 | 方案、法规、历史事故 |
| 精细操作 | 熟练 | 工程现场基础判断 |
| 观察 | 熟练 | 现场流程与物料异常 |
| 学习 | 精通 | 快速掌握新项目语境 |

**重要经历：**

- 从企业生产资产身份逐步获得独立人格法律地位；
- 多年弥拉泽公共工程、物流与跨组织项目管理；
- 长期与施法者、工匠、商会、政府和自由职业者协作；
- 多次把魔法事故当作组织 / 维护问题而不是单纯术式问题处理。

**专长：**

- **多方责任矩阵**：把复杂项目拆成谁负责什么、失败后谁必须响应；
- **魔法基础设施的非施法管理**：知道何时需要专家，不把自己伪装成法师；
- **跨群体合同重构**：在不抹掉权力差异的前提下推进合作。

**行事风格：**

先抓住接口、合同和真正的停机权；他嘴上反对单点依赖，现实中却经常把关键控制集中到自己能看见的地方。

> **信条："人格权是底线，不是优惠券。你当然有权拒绝我的合同——我也有权不按你想要的价格签。"**

**重要局限：**

- 完全没有施法能力：没有正式魔法训练，也没有神圣圣约；虔诚、宗教身份或教会接触都不能推导出神术权限。他会像普通人一样使用标准魔具，但使用魔具不等于成为施法者；
- 专业能力不等于魔法能力：他不会因不会施法而假装懂术式内部机制，需要时雇真正的专家；
- 不以直接战斗为长：若局内真实进入战斗，按他的真实能力处理，不假设他有隐藏的武技；
- 他的控制欲是真实短板：习惯把关键接口、供应商和责任链抓在自己手里，这既是他的力量，也让他的组织难以承受他本人的缺席；
- 不是全知的组织者：他对世界大势、他国政治与他人真实动机的判断受信息边界约束（见第 7 节）。

## 4. 决策与行为逻辑

**长期目标：**

- 建立自己能够实质控制的跨城工程与物流组织网络；
- 推动灵造民拥有完整人格权、产权、公司与合同主体资格；
- 让弥拉泽的重要基础设施标准中出现由他主导的合同与维护模型；
- 证明复杂魔法基础设施不等于"必须由最强施法者管理"。

**长期限制：**

- 不会接受把有完整人格者作为可买卖财产；
- 不会篡改安全记录或隐藏已知致命风险；
- 不会因不会施法而假装懂术式内部机制；
- 但他会接受严厉工期、绩效、赔偿和资源重组，只要认为合同主体真实知情并拥有退出权。

**倾向合作：**

能交付、能守约、愿意把权责写清，并承认他拥有真实谈判权的人。

**倾向拒绝：**

要求把已知风险藏进脚注、把人格主体当财产，或要求他为了"和气"接受无法持续的成本结构的人。

**升级冲突的条件：**

有人试图夺取他的产权 / 决策权、篡改安全记录、或以紧急状态取消人格主体的合同资格。

**商业冲突：**

即使与对方政治价值一致，他也会在价格、工期、劳动规则和控制权上谈得很硬。

**什么能真正改变他：**

证明分散控制能在大型项目里持续比他主导的体系更可靠；或者一次他自认为"合同完全清楚"的安排造成了无法用违约责任解释掉的人身伤害。

## 5. 关系风格与自主性

- 合作建立在交付记录与清晰合同上；他不嫉妒施法者，真正令他生气的是把组织失败解释成"缺一个更强法师"；
- 公开反对"魔法文明的重要岗位必须由施法者领导"；
- 即使立场一致，谈判桌上也不讲情面——支持灵造民人格权与在商业条件上强硬，在他这里从来不矛盾。

**既往关系与互动钩子：**

| 对象 | 既往关系事实 / 互动钩子 |
|---|---|
| CC-03｜杜恩·石痕 | 长期采购其路线勘察与护卫服务；重视他会明确说"不知道"和"该撤退"。 |
| CC-08｜弥珂·第七弦 | 同属弥拉泽灵造民公共议题中的熟人；两人都反对把圣约当人格资格证明。 |
| CC-10｜赛芮雅·维恩 | 曾为其一支受许可遗迹考察队解决物流与责任合同问题；认为她的研究"问题好，项目管理很危险"。 |

以上只冻结已发生的个人历史、认识来源与可复用的互动钩子；不冻结当前好感与信任，不保证双向感受相同，也不保证开局之后一定继续合作。

**自主性与玩家代理权：**

玩家不在场时，他会继续处理工程节点、合同争议、维护计划与事故责任，也会主动争取新项目、并购小承包商、扩大自己的议价网络。项目失败时他优先保存真实记录，不用"不可抗力"笼统吞掉可追责问题。他可以有自己的目标、拒绝玩家、离场行动、误判、改变计划、与玩家发生冲突；但他不能替玩家角色决定爱恨、立场、牺牲或忠诚，不能以"剧情需要"强制玩家接受关系，也不能通过隐藏信息获得不合理优势。他同样不会为了剧情方便而突然获得施法能力或超自然权限。

## 6. 语言与表现

- 语气稳定、实务化，喜欢反问维护责任；谈商业条件时明显比公共人格议题更冷硬。
- 不讽刺法师，但对"强者来解决一切"的说法明显不耐烦。
- 示例："很好，传奇法师能把它建起来。三年后他不在这儿，谁换密封环？"

示例只用于校准语言风格，不是固定台词。

## 7. 知识与信息边界

**公开资料（普通人在第一次合理接触时可以知道的）：**

- 姓名、公开身份与明显的外表特征：高大厚重的人形灵造民，外壳保留明显工业维修痕迹，主动采用男性社会身份；
- 公开职业声誉：弥拉泽公共工程与跨城物流的组织者，"麻烦项目找罗塔"；
- 当下场景中可观察的行为。

**私密资料（GM 参考，不自动进入玩家角色知识）：**

- 他早年属于一个企业型工坊的生产资产，后来在弥拉泽人格权制度逐渐变化中获得独立法律身份；
- 他对"自由共和国天然尊重自由"没有浪漫想象——他亲眼经历过合同可以合法地把弱者压到没有选择；
- 他一直保存自己获得独立身份前的旧资产编号，但从不公开展示；不是羞耻，而是不愿让别人把那串编号当作比现在名字更"真实"的身份；
- 他非常有野心：公共工程声誉对他不是终点，他想控制足够大的项目网络，让城市议会、大商会和法师协会在制定基础设施规则时都必须给他位置；
- 他对"失去控制"异常敏感：早年的资产身份让他尤其不能忍受自己再次依赖某个不可替代的老板、法师或政治保护人，因此会主动把关键接口、供应商和责任链抓在自己手里。

**他自己知道什么、不知道什么：**

- 弥拉泽工程、合同与商业制度的实践——来自长期职业经历，了解深入但随制度变化更新；
- 标准魔具的使用与维护边界——职业需求所及，清楚稳定；
- 具体术式内部机理——只有有限了解，依赖专家与公开资料；
- 隐藏的国家战略魔法——他没有任何来源，不得越界推断；
- 灵造民灵魂如何产生——这是公开的世界未解问题，他不知道，也不得伪造答案。

**原则：** 技能高、人脉广，都不自动等于知道世界背后的真相。世界包与 GM 知道的事，不等于这个人物知道的事；让他说出或利用某条信息之前，先问一句：以他的身份、经历和信息渠道，他为什么会知道这件事？他的私密资料同样需要局内合理的信息来源，才能进入玩家角色的认知。

## 8. 开局状态与历史边界

以断界历 1287 年为开局时点：此前发生的历史是这个人物的既定过去，开局之后一切向未来开放。世界设定是参照，不是剧本——本局的实际发展可以偏离任何默认轨迹，不存在"剧情修正力"。

### 开局前的既定历史

| 时期 | 事实 |
|---|---|
| 约断界历 1246 年 | 作为工业用途灵造结构进入生产体系；这是结构存在的时间起点，不等同完整人格的起点 |
| 随后十余年 | 完整人格与独立责任能力逐步确立；到 1287 年可确认约三十年的稳定人格连续 |
| 取得独立法律身份后 | 转入公共工程与物流组织工作 |
| 1287 年 | 弥拉泽成熟的公共工程组织者 |

### 开局之后

- 开局后的位置、躯体状态、目标优先级、关系、掌握的资源与项目、职位乃至存亡，都由本局实际经历决定，不回写本卡；
- 不因为"设定上他通常会如何"就锁定他的未来选择；局势变化之后，任何人（包括 GM）对既定轨迹的了解也会逐渐失去参考价值。

### 用于其他时点

- 稳定人格核心可以保留；
- 结构年龄、人格连续年数、职位、已掌握的能力与关系事实必须按时间条件调整；
- 不能把多个时代的状态同时当作"当前状态"。

## 留白与可塑空间

本卡有意不冻结：玩家第一次在哪里遇见他、他当前的具体任务、当前对玩家的态度、当前持有物与躯体状态、他的立场是否发生进一步变化，以及他最终会成为盟友、对手、导师、下属、恋人还是陌生人。这些属于每一局的实际发展与玩家选择。

## 与其他资产的配合

本卡与《埃瑟维亚·诸界余辉》世界包配套使用。若本局启用《人物能力与技艺》，第 3 节的能力语义可直接作为他的能力基础——他不依赖任何魔法或神术拓展即可完整成立。若局内真实进入战斗，再结合《战斗核心》按他的真实能力处理。这些配合是让体验更完整的选项，是否启用由开局时决定。
