# 创作规范｜Canonical Creation Spec Store

本目录是仓库全部世界包、人物卡、拓展包创作规范的**唯一事实源**。

状态：draft（讨论稿，未经项目所有者定稿前不构成正式约束）。

## 背景

仓库全部资产已完成 DSH-native 迁移，创作目标宿主为 **The World on DeepSeek Harness (DSH)**。此前各资产族 `10_创作规范/` 下的规范包含大量旧 SillyTavern Runtime 绑定内容（Resolver / Bootstrap / Creator / asset-spec 需求台账），已不再适用。本目录的规范取代其中的旧架构部分，继承其中架构无关的创作纪律。

## 文件

| 文件 | 职责 |

## 与其它规范的关系

- 仓库根 `AGENTS.md`：仓库级治理规则（canonical 唯一正文、资产族边界、交付纪律），优先于本目录；
- 资产族 `10_创作规范/`：家族专属补充（题材、考据标准、生产规划），不得与本目录冲突；
- 目标宿主权威文档：`zhangchenjia21-dot/the-world` 的 `docs/PRODUCT_SPEC_CURRENT.md` 与 `docs/ARCHITECTURE_CURRENT.md`，是资产消费侧语义的事实源。

## 边界

本目录只管"资产怎么写"，不管：

- 资产在 The World 中如何被加载、组合、恢复（属 the-world 仓库）；
- 具体资产的内容创作（属各资产族工作区）；
- 旧资产的批量改写（迁移已完成，遗留清理见总规范第 12 章）。
