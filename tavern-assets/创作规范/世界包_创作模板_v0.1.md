# 世界包创作模板

配套规范：`DSH-native_创作总规范_v0.1.md`。本模板规定世界包的章节构成与写作要点；世界是多样的，章节可增删合拆，但**必备项**不得缺席。

## 一、文件与命名

- 路径：`世界包/作品名_World_Pack_vX.Y.Z.md`
- 体量不设上限，世界深度优先；但工程包袱一行不留。
- 范例：`../世界包/汉末三国_天下未定_World_Pack_v0.2.3.md`

## 二、Frontmatter

```yaml
---
title: 作品名｜世界包

historical_mode: 正史 | 演义 | 混合 | 原创
supernatural_default: 无 | 低 | 显在
tags: […]
---
```

## 三、章节骨架

### 开篇（必备，无编号）

- **这份材料是什么**：一句话定位 + 它服务谁（GM 直接使用）；
- **这份材料不负责什么**：逐条指出不拥有的领域及其归属（用"X 属于《Y》"句式）。

### 必备章

| 章 | 内容要点 |
|---|---|
| 世界定位 | 这是个什么世界；题材、基调、尺度；玩家可以期待什么体验 |
| T0 边界 | 过去已冻结、未来开放；原史 / 原设是参照不是剧本；不存在"剧情修正力" |
| 开局起点 | 可选的开局时点；每个起点"已经是过去"的事与"正在未定"的事 |
| 世界构成 | 地理、社会、制度、技术、通讯、信仰、物质生活——按世界性质取舍，深度优先 |
| 玩家身份空间 | 玩家可以成为什么样的人；身份对开局位置的影响 |
| 知识可见性 | 三层划分：玩家公开事实 / 仅 GM 掌握 / 永不预写（见总规范 3.1） |
| 超自然口径 | 有无超自然、其在世界内的可见性与社会态度；神若是真实角色，其知识同样有世界内来源 |
| 拓展包协同 | 可选性声明（总规范 4.1）；Required / Recommended / Optional 的自然语言分级建议 |
| 诚实声明 | 史实 / 设定来源的已核查 / 未核查 / 参考资料 / 既定取舍四分（历史类必备） |

### 按需章

时代分阶段细述、地区分述、势力格局、经济与生活细节、年表（只到 T0）、名词表、与其它世界的关系。

### 收尾（必备）

- **与其他资产的关系**：本包推荐 / 消费哪些拓展包与人物卡，逐条协同 + 降级双写；
- **相关资产**：相对路径链接清单；
- **Revision Notes**。

## 四、写作要点

1. **写给 GM，不写给机器**：GM 读完应能直接主持这个世界，不需要任何 Runtime 概念。
2. **历史有惯性，没有修正力**：可以写"局势的引力方向"，不得写"无论如何都会发生"。
3. **信息差是资产**：远方未传到的事件、真实归属、人物私密面，是有意的戏剧资源，标注清楚谁会知道、谁不会。
4. **稀缺性守恒**：名臣、神物、禁术保持稀缺；世界不因玩家点名就立即供货。
5. **生活层素材**：市集、节令、饮食、婚丧、日常营生——Life Loop 的燃料，与大势章节同等正当。
6. **一句话铭文**：世界定位章结尾可用一句玩家向铭文收束（范例："过去可以被继承，未来必须重新发生。"）。

## 五、检查表

- [ ] 开篇定位双段在；归属指引完整
- [ ] T0 边界显式；无未来预写
- [ ] 每个开局起点的"已是过去 / 正在未定"清单可读
- [ ] 知识三层划分显式，GM-only 内容有标注
- [ ] 超自然口径明确；神 / 系统的知识有世界内来源
- [ ] 拓展包分级建议为自然语言，无机器元数据，无静默激活
- [ ] 世界深度未因篇幅被削成短 prompt
- [ ] 无第 6 章宿主越权内容
- [ ] 相关资产链接为相对路径且有效
- [ ] Revision Notes 已更新，版本号已递增
