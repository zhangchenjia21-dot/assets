# 人物卡创作模板

配套规范：`DSH-native_创作总规范_v0.1.md`。人物卡是一个可复用的"人物 Source"，不是运行时输入包。核心判断：**GM 读完这张卡，能不能演出这个人。**

## 一、文件与命名

- 路径：`人物卡/作品或族名/CC-BATCH-XX/人物名__Character_Card__vX.Y.Z.md`
- 一人一卡；禁止"曹操_184 / 曹操_200"式年代复制卡，随时间变化的状态写进第 8 节。
- **不设字数门槛，不做强制压缩**。密度是唯一标准：每节都要能改变 GM 的判断；史料 / 设定不足就写短卡——**未知优先于虚构**；内容充实也不必削足适履。
- 考据过程、被舍弃细节、史料冲突归 Research Note（`人物名__历史人物研究附录__vX.Y.md`），不进正式卡。
- 范例：`../人物卡/汉末三国/CC-BATCH-01/曹操__Character_Card__v0.1.2.md`

## 二、Frontmatter

```yaml
---
title: 人物名｜人物卡
aliases: […]
type: character-card
status: candidate | current
version: 0.x.y
asset_family: 资产族名
historical_character: true | false
birth_year: …   # 允许范围或"未知"
player_character_supported: true | false
research_note: 相对路径   # 有则填
tags: […]
---
```

## 三、八节骨架

```text
一、身份锚点
二、人格核心
三、能力与局限
四、决策与行为逻辑
五、关系风格与自主性
六、语言与表现
七、知识与信息边界
八、开局状态与历史边界
可选｜极简史料备注
Revision Notes
```

### 一、身份锚点

姓名 / 字号 / 生年（或未知）/ 籍贯 / 身份消歧 / 一句话辨识度。时间字段最小化：只强制出生年份，不强制死亡年份与逐年履历。

### 二、人格核心

2–5 个核心价值、1–3 个核心矛盾、风险偏好、压力下的变化。写**生成式决策结构**，不写标签集合——"重实际成效、轻形式资格"可用，"奸雄"不可单独成立。后世标签（演义形象、民间定性）不是人格真相。

### 三、能力与局限

只写语义轮廓：擅长什么、不擅长什么、能力的世界内来源。禁止数值五维 / 技能等级表。若某拓展包（如《人物能力与技艺》）启用时可作语义基础，用引用式软依赖一句话带过。

### 四、决策与行为逻辑

这个人物如何收集信息、权衡、下决心、反悔。是 GM 推演其行为的引擎，不是剧情脚本。不写"他会做 X"，写"他在 X 类局面下如何想"。

### 五、关系风格与自主性

他如何对待人、如何建立与消耗信任；重要关系写风格不写数值。NPC 有独立动机与判断——不是玩家 / GM 的功能件，不预设恋爱或忠诚结果。

### 六、语言与表现

语感、措辞习惯、情绪外露程度。示例台词可选 0–3 条，仅校准语感，不是台词库。

### 七、知识与信息边界

按总规范 3.2 写：总纲 + 逐条边界（第一手领域 / 情报滞后与缺口 / 只能推断的事 / 不知自己"原本的未来" / 不自动采信超时代知识）+ 临场自检收束句。私密事实、未公开动机在此标注暴露层级。

### 八、开局状态与历史边界

- **随开局年份确定的状态**：不同起点下他的身份、位置、处境如何确定（写确定方法，不写年表流水账）；
- **历史参照的限制**：原史是他的来路，不是他的剧本；
- **玩家接管此人物**（`player_character_supported: true` 时必备）：T0 前哪些已锁定，T0 后哪些选择权归玩家。

### 可选｜极简史料备注

考据类人物可用 3–8 行注明关键史实依据与主要文学差异；详细内容永远归 Research Note。

## 四、Life Loop 要求

每张卡至少提供：一个日常面（嗜好、习惯、闲时状态）、一个非功能性互动面（不为推动剧情也存在的人格细节）。人物卡不是能力清单——谋士不只是一个会出主意的功能。

## 五、检查表

- [ ] 一人一卡，无年代复制卡；时间字段最小化
- [ ] 人格是决策结构而非标签；后世标签已剥离
- [ ] 能力为语义轮廓，无数值表
- [ ] 知识边界按"凭什么知道"逐条可答；隐藏信息已标注
- [ ] 不知自己原本的未来；不采信超时代知识
- [ ] 支持接管的卡写清 T0 前后归属；不预设重大承诺 / 阵营 / 恋爱结果
- [ ] Life Loop 两项素材在
- [ ] 无百科化注水，无该删未删的无判断价值内容；考据未混入正文
- [ ] 与其它卡共享的历史事实一致；关系对称
- [ ] 相对路径链接有效；Revision Notes 已更新
