# 战斗核心｜Expansion Pack v0.1

> [!abstract] 这份拓展包是什么
> 一份跨世界通用的**人物尺度直接战斗**拓展包。启用它，当游戏里的人物拔刀相向、张弓搭箭、近身缠斗时，战斗就不再是一句"你们打了起来，你赢了"，而是一段有位置、有节奏、有风险、有代价的真实过程：双方隔着多远、谁先反应过来、谁在压制谁、这一击造成了什么后果、值不值得打下去。
>
> 它不是一种职业，也不是一套固定战棋规则。它是所有直接战斗玩法共同使用的语言与裁定框架：骑战、械斗、决斗、伏击、护送、突围、非致命制服，都在同一套语义里成立。

> [!important] 启用方式
> 这是一份可选拓展包，只有在玩家明确选择启用后才进入游戏。世界包可以推荐它，但任何资产都不应替玩家悄悄打开它。未启用时，GM 按人物卡与世界包直接叙述战斗即可，不需要套用本包的距离、姿态与压力术语。

## 1. 这个包为游戏增加什么

**增加的体验**：人物尺度的直接战斗成为真正有决策价值的玩法。玩家在战斗中面对的不是"攻击/逃跑"两个按钮，而是活生生的取舍——

- **风险**：每一次接战都可能付出真实代价。伤势、被擒、武器脱手、被逼入绝境，都是持久后果，不是过场动画。
- **决策**：距离、姿态、掩体、目标、时机都在不断变化。"现在压上去还是稳住""先救同伴还是先解决弓手""这一仗该不该打"——这些选择有意义，因为局面真实地回应它们。
- **后果**：战斗的胜负与代价会留下来。砍伤的手臂要养，被缴的剑要赎，杀死的对手有他的家人与盟友。战斗不是游戏里的独立小游戏，而是世界因果的一部分。

**它关注什么**：直接战斗中双方的位置关系、行动空间、节奏与主动权、攻防对抗、以及每一个动作具体达成了什么。

**它拒绝什么**：

- "战斗力高所以自动赢"——传奇战士也会失手，只是他失手的模样更体面、绝境里的出路更多；
- "被打中 = 扣固定血量"——命中造成的身体后果由身体状态领域裁定，不是一张伤害表；
- "每回合一次行动、一次反应"的机械行动经济——行动与反应取决于时机、位置与准备，不取决于回合配额。

**胜负与代价的游玩质感**：胜利可以是击倒对手，也可以是逼退、缴械、守住门口、拖到援军抵达；失败不一定是死，可以是被擒、被缴械、带伤逃走、目标被夺。一场"输了战斗但保住了人"的撤退，和一场"赢了战斗但折了臂膀"的惨胜，都是本包要制造的真实质感。

**它不拥有什么**：大规模战争与军团指挥属于军略与战争类玩法；伤势、流血、感染、康复等身体后果的细节属于身体状态领域（如《身体状态核心》）；具体武器与物品的所有权属于世界与物品体系；人物的长期能力属于《人物能力与技艺》。详见第 24 节。

## 2. 战斗何时成立：情境与目标

### 2.1 什么才算"进入战斗"

有敌意、在争吵，不等于进入战斗。通常需要：

1. 存在可以产生即时战斗后果的行动或威胁（已经动手、武器已经指向、威胁迫在眉睫）；
2. 参与者当前在同一场景，或有合法的战斗接入途径（射程之内、能够触及）；
3. 局面需要读取本包的共同规则——距离、攻防、反应、压力——才能公正裁定。

一场没有武器、没人试图伤害对方的推搡口角，GM 按普通冲突处理即可，不必套用战斗框架。

### 2.2 战斗目标

战斗目标回答"这一仗是为了什么"。常见目标：击退、制服、杀伤、保护某人、逃跑、拖延时间、抢夺物品、守住位置、破坏装置、阻止对方完成某事（如施法）、迫使投降。

> **目标属于参与者，不属于 GM 的默认假设。** 玩家说"拦住他"，不得被自动升级为"杀死他"；玩家说"按住他"，不得被自动改成"砍倒他"。目标的变化（打着打着发现该撤了）是正常玩法，GM 应当跟随参与者真实表达的意图，而不是替他们把每一场战斗都打成歼灭战。

## 3. 战斗空间投影

正式的世界空间（地区、地点、场景位置）由世界本身拥有。本包只在战斗发生时，从当前场景派生一份**战斗投影**：对裁定有意义的相对位置关系。它不是第二张地图，战斗结束后即散去。

### 3.1 相对距离

| 距离 | 含义 |
|---|---|
| 接触 | 身体或武器已经直接控制、擒抱或贴面交锋 |
| 近距 | 一次短促行动即可进入典型近战威胁范围 |
| 中距 | 普通远程兵器可以交战；近战方需要明显接近 |
| 远距 | 需要专业远程手段才能威胁；接近需要持续移动 |
| 极远 | 只有专门的长距能力才能稳定交互 |
| 特殊 / 不可直接接入 | 普通战斗方式不能直接触达（高墙之后、深渊对岸） |

这些不是固定米数，而是对行动意义的描述："近距"意味着对方一个跨步就能砍到你，这才是玩家需要知道的。

### 3.2 视线与掩体

- **视线（LOS）**：清晰 / 受遮蔽 / 阻断；
- **掩体（Cover）**：无 / 部分 / 显著 / 完整。

完整掩体意味着普通直线攻击无法触达，但不意味着绝对安全——绕路、破墙、火力压制逼出掩体，都是合法思路。

## 4. 武技技能

本包向人物的技能体系贡献四项通用武技技能。启用《人物能力与技艺》时，它们作为领域技能并入人物唯一的技能记录；未启用时，GM 按人物背景直接把握。

| 技能 | 定义 | 边界 |
|---|---|---|
| 近战兵器 | 使用近战武器完成攻击、招架、格挡、控距、压迫与武器线路控制的综合战斗技能 | 具体长剑、长枪、战斧的差异由武器轮廓与人物专长、经历表达 |
| 远程兵器 | 使用弓、弩、投射器械及其他非法术远程武器完成瞄准、射击、准备、换位与压制的综合技能 | 观察负责发现目标，远程兵器负责把武器用于战斗 |
| 徒手格斗 | 使用身体完成打击、擒抱、脱困、控制、摔投与近身缠斗的综合技能 | 专业流派由人物专长或对应领域拓展表达 |
| 战术判断 | 在直接交战中读取威胁、距离、掩体、优先目标、撤退窗口、同伴位置与局部行动节奏的能力 | 不是军团战略学，也不替代观察、推理、沟通 |

两条原则：

- **不要"每把武器一个技能"。** 具体武器的专精由专长与经历表达——一个使了三十年枪的老兵，他的枪法深度写在经历与专长里，而不是一个单独的"长枪技能"。
- **不建立万能防御技能。** 闪避、招架、格挡是不同的防御方式，分别读取不同的能力与装备：身法快的闪、兵刃熟的架、盾在手的挡。

## 5. 武器与护甲的战斗轮廓

武器与护甲本身属于世界的物品体系；本包只描述**一件装备在战斗中意味着什么**，供 GM 裁定时参考。

### 5.1 武器轮廓

一件武器的战斗意义可以从这些方面把握：

- 武器族类与使用方式（近战 / 远程 / 投掷）；
- 操控性（轻重、快慢、是否便于变招）；
- 攻击距离（刀剑的触及、长枪的杆长）；
- 有效射程与精度特性（远程武器）；
- 冲击性质：劈砍 / 穿刺 / 钝击 / 砸压 / 缠绕 / 混合 / 特殊；
- 穿透倾向（对护甲的表现）；
- 控制效用（能否钩、缠、架、锁）；
- 防御效用（能否用于招架格挡）;
- 准备需求（装填、上弦、展开）；
- 单手持用还是双手持用；
- 隐蔽性（能否藏匿携带）；
- 骑乘适性；
- 特殊交互（对盾、对甲、对超自然目标的表现）。

### 5.2 护甲轮廓

一件护甲的战斗意义可以从这些方面把握：覆盖范围、刚性还是柔性、偏转能力、冲击吸收、抗穿透、对机动的负担、噪音、薄弱与暴露部位、与盾的配合、与超自然效果的交互。

> **护甲不拥有生命值，装备损坏也不等于角色受伤。** 盾牌被劈裂是一个物品事实；持盾的人受了什么伤，是身体状态领域的事。

## 6. 战斗姿态

姿态是人物当前这一小段战斗里的总体取向，是短期战斗状态，不是人物性格，也不是每回合必须重选一次的菜单：

- **积极**：主动争夺成果，接受更高暴露；
- **稳健**：攻防机动平衡；
- **防守**：优先保存自身或保护对象；
- **机动**：优先保持距离与重新定位；
- **压迫**：持续压缩对手的安全行动条件；
- **脱离**：优先建立退出条件。

姿态影响人物的动作倾向与风险结构：积极姿态争取战果但把自己亮出去，防守姿态牺牲战果换安全。玩家可以随时改变姿态；GM 不替玩家规定"你该防守了"。

---

## 7. 战斗压力

压力表示一方当前**行动空间与节奏被压缩的程度**：

```text
均势 → 占优 → 受压 → 严重受压 → 失去主动
```

被逼到墙角的、腹背受敌的、武器被打落正在后退的，都是压力在上升。

> **压力不是伤害。** 一个被逼得连连后退、严重受压的人，身体可以毫发无损；反过来，一个占据主动的人可能已经在流血。严重受压仍然可以尝试复杂行动——只是条件更苛刻、风险更高。压力是局势语言，不是血量换皮，也不是输入禁令。

---

## 8. 战斗节奏与主动权

不冻结固定的先攻列表。战斗的主动权是流动的短时状态：

```text
我方掌握主动 / 相持 / 对方掌握主动
```

主动权的来源包括：突袭、准备程度、距离与掩体优势、当前压力、控制效果、对方复杂动作失败、援军抵达、场景事件。抓住对方换武器的瞬间压上去、趁对方倒地抢回主动——节奏是打出来的，不是开局掷出来的。

---

## 9. 突袭与伏击

突袭是**信息与准备的不对称**：一方已经看清局面、选好了时机与位置，另一方还没意识到危险。

突袭可以真实地改变开局节奏、初始位置与各方可用的反应机会——被伏击者可能连武器都没出鞘。

> **突袭不等于自动命中，更不等于自动处决。** 它给予的是真实的优势，不是跳过裁定的处决按钮。一次精心策划的伏击完全可能仍然失败——目标恰好回头、守卫恰好换岗。

---

## 10. 反应窗口

战斗中能否对一个突发情况做出反应（拦截、格挡来箭、打断施法、抓住对方破绽），取决于：

- 是否存在可观察的触发事件；
- 当事人是否察觉（注意力、观察）；
- 相对距离与接入条件；
- 视线是否允许；
- 当前的准备状态（是否在戒备、是否已保留注意力等待此类事件）；
- 当事人的能力；
- 当前压力；
- 是否已经投入别的动作（已经全力挥出的刀收不回来）。

综合成立，才存在真实的反应窗口；窗口成立也只是**可以尝试反应**，不自动成功。

> **没有"每回合固定一次反应"的配额。** 一个高度戒备、位置得当的人可以连续应对多个威胁；一个已经投入进攻、被人从侧翼夹击的人可能一个也反应不了。

## 11. 战斗行动

### 11.1 行动不是白名单

本包提供一套标准战斗行动模式，帮助 GM 与玩家用共同语言描述"你想干什么"。**它不是行为白名单。** 玩家说出任何不在列表里的做法——掀翻桌子、扯下帐幔罩住对手、把油灯踢向柴堆——都按开放尝试原则正常裁定（见《人物能力与技艺》第 5.4 节的精神：可以做的直接做，有真实不确定性的按能力与条件裁定，确实不可能的说清楚为什么）。

### 11.2 所有行动的共同裁定输入

裁定任何一个战斗行动，GM 自然地汇集：相关能力与武技、战斗空间投影（距离、视线、掩体）、当前压力与节奏、装备轮廓、对手的反应与防御、世界状态（地形、天气、光照）。这些是裁定的依据，不是固定加法公式，也没有命中等级 / 防御等级之类的数值契约。

### 11.3 标准行动模式（36 个）

**攻击类**

| 行动 | 核心意图 |
|---|---|
| 近战攻击 | 以近战武器或合法徒手手段尝试形成有效接触、压制或指定战斗后果 |
| 远程攻击 | 以远程兵器、投射物或其他非法术远程媒介尝试命中或形成压制 |
| 徒手打击 | 以身体打击尝试形成有效接触、失衡或物理冲击 |

**防御类**

| 行动 | 核心意图 |
|---|---|
| 招架 | 以武器线路主动干扰、偏开或承接来袭攻击 |
| 格挡 | 以盾牌、武器、身体防线或合法防御媒介承受并降低攻击效果 |
| 闪避 | 通过身体移动与时机避开攻击线路 |
| 利用掩体 | 借助场景中存在的遮蔽物降低暴露或改变射线 |

**移动类**

| 行动 | 核心意图 |
|---|---|
| 接近 | 缩短与目标的距离，建立近战、控制或护卫条件 |
| 拉开距离 | 扩大距离以获得射击、施法、逃离或重整条件 |
| 侧移换位 | 改变与目标、掩体或同伴的相对位置 |
| 追击 | 目标撤离或失位时维持威胁，阻止其轻易脱离 |
| 脱离接战 | 解除直接交战关系，使继续离开不再处于即时近身威胁 |
| 撤退 | 以结束或显著降低当前战斗接触为明确目标，退出危险区域 |

**保护与协助类**

| 行动 | 核心意图 |
|---|---|
| 保护同伴 | 用位置、装备、反应或威胁能力减少指定同伴遭受的攻击机会 |
| 拦截 | 在合法反应窗口内进入攻击路线或目标通道 |
| 协助攻击 | 为同伴创造角度、信息、牵制或接触条件 |
| 协助防守 | 帮助同伴稳定防线、保持位置、脱离控制或获得掩体 |

**准备类**

| 行动 | 核心意图 |
|---|---|
| 瞄准 | 牺牲部分即时机动或节奏，为后续远程攻击建立更稳定的目标条件 |
| 准备反应 | 保留注意与姿态，等待特定可观察的触发事件打开反应窗口 |
| 佯攻 | 诱导错误的防御、视线或重心分配 |

**控制类**

| 行动 | 核心意图 |
|---|---|
| 破防 | 破坏对方当前防御结构，而非直接追求伤害 |
| 缴械 | 使目标失去当前武器控制或迫使其放弃武器 |
| 击倒 | 让目标失去稳定站立、坐骑或支撑状态 |
| 推离 / 迫退 | 迫使目标离开当前位置、通道、门口或保护对象 |
| 擒抱 | 进入身体控制关系，限制目标部分移动与动作选择 |
| 压制 / 制伏 | 在已有有利接触或控制条件下进一步限制目标 |
| 突围 | 突破包围、封锁或局部控制，建立新的行动路线 |

**压制类**

| 行动 | 核心意图 |
|---|---|
| 火力压制 | 通过持续或可信的远程威胁限制对手暴露、移动或组织动作 |
| 封锁通道 | 用位置、武器触及、远程威胁或协作让某条路线具有明确通过风险 |

**打断类**

| 行动 | 核心意图 |
|---|---|
| 打断动作 | 在合法窗口中让对方当前复杂行动无法按原计划完成 |

**目标类**

| 行动 | 核心意图 |
|---|---|
| 保护目标物 / 地点 | 围绕人物、物品、门口、装置或区域建立明确防卫 |
| 夺取目标物 / 地点 | 在战斗压力下获得指定对象或局部空间控制 |

**装备与环境类**

| 行动 | 核心意图 |
|---|---|
| 破坏装备 | 把攻击目标明确指向武器、盾牌、法器或其他可合法破坏的装备 |
| 利用环境 | 使用场景已存在的门、桌、火源、落差、狭道等事实改变战斗 |

**退出与交涉类**

| 行动 | 核心意图 |
|---|---|
| 投降 | 明确停止主动敌对并接受合理控制风险；不保证对方接受 |
| 要求投降 | 在已有战斗事实基础上提出停止交战的要求 |

---

## 12. 什么时候才需要正式裁定

进入战斗不代表每个动作都要郑重其事地过一遍裁定。只有同时满足以下条件，才值得进入正式的裁定：

- 结果真实不确定；
- 成败差异有意义；
- 角色合理可尝试；
- 存在真实的对抗或风险。

确定成功的直接成功——顶尖战士砍断一根无人防守的绳索，不需要裁定；确定不可能的允许尝试后直接失败，并说清楚为什么不可能。把每一次挥刀都办成仪式，和把整场战斗一笔带过，同样损害本包的价值。

---

## 13. 一次战斗裁定的自然流程

GM 裁定一个战斗动作时，自然的思考顺序是：

```text
玩家意图与目标
→ 这属于哪类行动、服务于什么战斗目标
→ 相关能力与武技
→ 当前战斗空间投影（距离、视线、掩体）
→ 装备轮廓
→ 姿态、压力与节奏
→ 对手的对抗与反应
→ 是否值得正式裁定（第 12 节）
→ 动作达成（第 14 节）
→ 战斗具体结果（第 15 节）
→ 涉及身体影响时移交身体状态领域（第 16 节）
```

本包不规定固定加法公式，不锁死任何数值模型。能力与局势是裁定的依据，不是结论本身。

---

## 14. 动作达成

一个战斗动作的达成程度，用有序的自然语言表达：

```text
未达成 → 有限达成 → 有效达成 → 优势达成 → 决定性达成
```

两点边界：

- **未达成不自动受伤。** 一次被架开的攻击，结果就是"没有打进去"，不附带隐藏惩罚。
- **决定性达成也不自动死亡。** 它意味着动作以极高质量完成——至于这对目标的身体意味着什么，由身体状态领域裁定。

---

## 15. 战斗具体结果

动作达成之后，落到世界里的具体结果可以归入以下类别（一个动作可以产生多类结果）：

- **接触**：未接触 / 防御接触（被架开、被挡住）/ 有效接触 / 高质量接触；
- **位置**：接近、迫退、换位、获得或失去掩体、脱离；
- **压力**：建立占优、增减压力、夺取或失去主动；
- **控制**：擒抱、击倒、缴械、牵制、制伏；
- **保护**：遮护、改变攻击线路、成功拦截；
- **压制**：限制对方暴露、移动或准备；
- **打断**：打断复杂动作，或为相关领域提供中断契机（如打断施法）；
- **装备**：武器、盾牌、护甲受到战斗冲击（卷刃、开裂、脱手）；
- **目标**：守住、夺取、拖延、护送、突破、撤离；
- **身体影响**：形成了需要移交身体状态领域裁定的冲击事件（见第 16 节）。

---

## 16. 身体影响的交接

当一次攻击或冲击真实地接触到身体，本包负责描述**这是一次什么样的冲击**，然后交给身体状态领域裁定它在这个具体身体上形成了什么后果。

本包描述的内容：冲击来源与目标、接触质量、冲击性质（劈砍 / 穿刺 / 钝击等）、冲击强度、穿透与偏转情况、与护甲的交互、作用部位（若已合法确定）、附带效果、造成这次冲击的战斗来龙去脉。

冲击强度推荐使用：

```text
轻微 → 明显 → 沉重 → 极端
```

> **本包不直接写伤势。** 不出现"骨折""失血量""感染"，更不存在"扣 18 点生命"这样的语言。同样一记沉重的劈砍，落在壮汉、老人、异种身体上会形成完全不同的后果——那是身体状态领域的裁定，本包不为任何物种预写固定伤害。

如果游戏启用了《身体状态核心》，交接按该包的规则进行；未启用时，GM 按同样的区分直接裁定：战斗给出真实原因，身体形成具体状况。

---

## 17. 攻与防是对抗，不是固定防御值

防御不是贴在人物身上的一个固定数字。面对一次攻击，防御方可能闪避、招架、格挡、借掩体、拦截，或由某种保护效果承接——不同的防御方式读取不同的能力与装备，面对不同的攻击也有不同的表现：轻甲快刀客闪得开劈砍却架不住重锤，盾卫挡得住箭雨却未必躲得开贴身的摔技。

裁定时同时读取双方：攻击者的能力、武器、位置与节奏，防御者的能力、装备、姿态、压力与地形。

玩家不必每次挨打都正式声明防守方式。已经表达过姿态与目标时（"我举盾护住胸口稳步后退"），GM 可以形成合理默认的防守；玩家想改变时随时可以明说。

---

## 18. 非致命战斗是一等玩法

擒抱、制伏、缴械、击倒、迫退、阻挡、保护、突围、逼降、投降、撤退，都是一等的战斗目标，不是"攻击的弱化版"。

- 抓捕任务中把目标活着按倒，比砍倒他难，也更有戏；
- 比武、械斗、私刑、执法，世界里大量战斗本来就不以杀人为目的；
- 玩家说"按住他"，不得被自动改成"杀死他"（第 2.2 节）。

非致命不等于无代价：被擒抱的人可能挣脱，制伏需要持续投入控制，缴械的对手可能捡起任何东西继续打。

---

## 19. 多人战斗

支持一对一、一对多、多对多、保护目标、围攻、狭窄通道、远近混合、撤退追击、援军加入。

多人战斗中，GM 心里应能随时回答谁与谁正在交战、谁在威胁谁、谁在保护谁、谁在压制谁、谁在追击谁、谁控制着谁。这些临时关系随动作真实变化。

> **人数不转化为固定加值。** 三个人围攻一个人，重要的是实际可接触性——三个人能否同时够到目标、武器触及是否互相妨碍、位置是否形成包夹、目标背后有没有墙。三名长枪兵在窄巷里围一人，未必比一名刀手在空场上威胁更大。读取真实的触及、位置、训练与压力，而不是数人头加分。

---

## 20. 超自然战斗的组合

如果游戏同时启用了魔法、神术或其他超自然领域玩法，直接战斗中的一切超自然效果都遵守同一条分工：

- **战斗的壳归本包**：相对距离、视线、掩体、节奏、反应窗口、攻防对抗、动作达成与战斗结果——法术攻击不因为"是魔法"就自动忽略掩体与防御；
- **效果的内部归领域包**：法术能否施展、负荷与代价、效果形成、克制与驱散，由对应领域玩法裁定；
- **持久状态归对应领域**：身体后果归身体状态，物品后果归物品体系，世界改变归世界。

两个常用的配合要点：

- **施法距离不等于战斗距离。** 魔法领域自己的"近距 / 可视 / 远距"描述法术能够触及的范围；本包的距离描述当前交战关系。裁定"这个法术此刻能不能打到那个人"时，两者一起读：战斗距离、视线与掩体决定他此刻在不在可达位置，法术触及决定这个法术够不够好到那里。法术触及不反向改写战斗距离。
- **战斗中截咒**。打断敌方施法者，时机与接入条件（来不来得及、看不看得见、有没有反应窗口）按本包裁定；能否识别、抵消或驱散那个法术，按魔法领域裁定。一场无人交战的遗迹驱散根本不需要进入战斗框架。

---

## 21. 撤退、投降与战斗结束

- **撤退是合法目标。** 玩家把目标切换为脱离或撤退时，GM 不得替玩家继续追击；对方是否追击、追不追得上，按各自目标与条件裁定。
- **投降不保证被接受。** 投降是停止主动敌对并接受合理风险；受降是对方的选择。屠杀降卒、假装受降，都是世界里真实存在的事，它们的后果同样真实。
- **战斗结束后**，所有临时战斗状态（交战关系、压力、姿态、节奏）随之解除，但**已经发生的后果不消失**：伤势进入身体状态记录，损坏的装备进入物品事实，死去的人留在世界里，投降与俘虏安排进入关系与局势。

---

## 22. 值得持久化的状态

启用本包后，游戏工作区里值得作为持久事实维护的：

- **战斗进行中**：当前交战关系（谁打谁、谁护谁、谁压制谁）、各方距离与掩体投影、当前压力与节奏、各参与者的战斗目标与姿态、已经宣布等待反应的准备状态。这些随战斗结束而解除。
- **跨越战斗的持久后果**：移交身体状态领域的冲击及其后果（伤势、虚弱等，由身体状态规则继续演化）；装备的战斗损坏；投降、俘虏、战果归属；战斗造成的世界事实变化（守卫被杀、城门被撞开、目击者四散报信）。
- **不回写人物卡与世界包**：一局游戏里发生的战斗后果只改变游戏现实；人物卡与世界包作为源资产保持原样。

一条一致性要求：叙事与记录要同步。叙事里说"他的剑被你打飞了"，记录里这件装备就应处于脱手状态；反过来，记录里已经被制伏的人，叙事里不能还在自由挥拳。

---

## 23. 裁定示例

以下示例展示本包在典型处境中的正确用法。

**明确的近战攻击。** 玩家挥刀进攻。读取其近战兵器能力、武器轮廓、相对距离、对手防御与当前压力；有真实不确定性则正式裁定；不自动命中。

**确定行为不过裁定。** 顶尖战士砍断一根无人防守的普通绳索，结果确定，直接形成结果，不必仪式化。

**格挡是真实对抗。** 盾卫明确举盾格挡时，这是一次正式的防御对抗——读取他的能力、盾的轮廓与攻击性质，而不是把他简化成一个固定防御值。

**火力压制不必命中。** 弓手持续向窗口射击，即使箭箭落空，可信的威胁本身就限制对方暴露与移动——压制是真实结果，不以命中为前提。

**多人围攻。** 读取各方的威胁关系、武器触及、实际位置、协助与掩体，不做固定人数加值。

**伏击。** 伏击方获得真实的开局优势——节奏、位置、反应机会都倾向伏击方；但不是自动处决，被伏击者的戒备、运气与能力仍参与裁定。

**撤退。** 玩家明确表示目标改为脱离战斗。尊重该目标，裁定脱离过程的风险；GM 不替玩家继续追击。

**非致命制服。** 目标是活捉。走控制类结果（擒抱、制伏、缴械），不自动把伤害最大化。

**武器对上护甲。** 重锤砸中胸甲：本包形成武器与护甲的交互与一次冲击事件；这在这个身体上意味着什么伤势，移交身体状态领域。

**直接攻击法术。** 一道火焰箭射向盾卫：距离、掩体、防御、反应窗口按本包裁定；法术的形成与效果内部按魔法领域裁定。"是魔法"不是忽略盾与墙的理由。

**战斗中截咒。** 敌法者正在施法，我方修士试图反制：来不来得及、看不看得见，按本包裁定；反制手段能否克制这个法术，按魔法领域裁定。

**非战斗驱散。** 在无人的遗迹里驱散一个残留法术，没有任何交战——只需要魔法领域，不强行进入战斗框架。

**战地治疗。** 战场上抢救伤员：接近他、为他挡箭、防止打断，按本包裁定；治疗本身按对应领域裁定。

**反应没有固定次数。** 每个反应机会都按触发事件、察觉、距离、视线、准备与当前压力逐个判断；不存在"本回合已用过反应"。

**完整掩体。** 目标在不可穿透的石墙之后：普通直线攻击无法触达，但可以绕路、破墙、等待他露头。

**压力不是伤害。** 被逼得连退十几步、严重受压的人，身体可以毫发无伤；反之亦然。

**传奇不自动命中。** 传奇剑客面对一个滚翻躲开的新手，优势巨大——裁定可以明显倾斜，但"传奇"不是自动成功的标签。

**战斗结束。** 胜负已分：解除交战关系、压力与姿态；伤势、损毁、死亡与俘虏安排全部保留，继续影响后续游戏。

## 24. 这个包不拥有什么

明确边界，GM 遇到以下事项时应去找对应的归属，而不是塞进战斗框架：

- **大规模战争**：军团调度、战役战略、补给与战线——属于军略与战争类玩法，本包只管人物尺度的直接战斗；
- **身体后果的细节**：伤势、流血、骨折、感染、疼痛、意识、康复、死亡的身体判定——属于身体状态领域（如《身体状态核心》），本包只移交真实的冲击原因；
- **人物的长期能力**：属性、技能、经历、专长、风格、信条——属于《人物能力与技艺》，本包只读取；
- **物品与装备本身**：武器是否存在、归谁所有、位于何处——属于世界与物品体系，本包只描述它们的战斗意义；
- **超自然效果的内部规则**：法术资质、施法负荷、效果形成、克制与驱散——属于对应超自然领域玩法；
- **具体某个角色是谁**：属于人物卡与世界包；
- **任何数值契约**：生命值、固定防御值、每回合行动配额、伤害公式，一概不属于本包。

---

## 25. 常见误区（写作与裁定都要避免）

- **固定防御值思维**：把防御简化成一个人人不变的护甲等级数字。防御是具体的对抗动作。
- **失败即受伤**：攻击未达成就顺手扣点血。未达成就是未达成。
- **命中即定伤**：有效命中直接写成骨折、残废。身体后果由身体状态领域裁定。
- **回合配额**：每回合一次行动、一次反应、六秒一轮。时机与节奏由局势决定。
- **战斗投影覆盖世界位置**：把战斗距离当成第二张地图，战斗结束后还在用。投影随战斗散去。
- **超自然自建战斗系统**：某个领域玩法自己另造一套命中与防御规则。进入直接战斗就使用本包的共同语言。
- **突袭即处决**：伏击成功等于目标直接死亡。
- **人数加值**：三个人围攻所以 +2。读取真实的可接触性与位置。
- **投降必被接受**：投降只是停止敌对，受降是对方的选择。
- **压力即禁令**："你严重受压，所以不能做这个动作。"压力改变条件与风险，不删除选择。
- **战斗吞并身体**：在本包内维护第二套伤势与疲劳记录。
- **目标升级**：玩家说"制服"，叙事里变成"击杀"。

## 26. 与其他资产的关系

本包是通用包，不硬编码任何具体世界、时代、武技流派或超自然体系；历史、武侠、奇幻、现代、科幻世界都可以直接使用。

它与其他资产的关系（均为自然协作，不是机器依赖）：

- **《人物能力与技艺》**：最紧密的协同。本包贡献的武技技能并入人物唯一的技能记录；战斗裁定读取的属性、技能、经历、专长以该包为准。如果同时启用人物能力相关玩法，战斗中的人物差异（老兵与新兵、快刀与重锤）会获得更细腻的表达。
- **《身体状态核心》**：本包的所有身体后果都移交身体状态领域裁定。如果同时启用身体状态相关玩法，战斗造成的伤势会获得更细致的表现；未启用时，GM 按同样的区分直接裁定，本包规则依然完整可用。
- **魔法、神术等超自然领域拓展**：各自拥有超自然效果的内部规则；进入直接战斗时使用本包的距离、视线、反应与对抗框架（见第 20 节）。这类玩法不因为存在而成为本包的前置，本包单独启用照常运转。
- **军略与战争类拓展**：掌管本包明确不碰的大规模战争；两者通过"人物尺度的战斗"与"军团尺度的战争"的自然分工配合。
- **世界包**：提供武器与护甲的实际物品、物种身体事实、武学传统与战斗文化背景。世界包推荐本包不等于自动启用。
- **其他战斗相关拓展**（骑战、特定流派、战斗魔法等）：可以在本包的共同语言上贡献领域内容——新的行动模式、新的战斗结果、领域特有的触发条件与配合规则——而不另建第二套距离、反应或对抗框架。
