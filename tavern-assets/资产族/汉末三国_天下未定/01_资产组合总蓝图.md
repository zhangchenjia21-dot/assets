`人物 / 地图 / 物品 / 信息 / 目标`

- `系统` → 穿越与系统（System ON）
- `势力 / 政务` → 政争与势力

主要 Contributors：

- Character Core → Player Character Detail / Status
- Health → Player Status / Person Detail / Contextual / Alert
- Survival → Player Status / Alert
- Combat → Narrative Contextual
- Relationship → 人物 / Person Detail
- Economy → 势力 / 政务 + Map / Place Detail
- History → 信息；Historical Assistance ON 时贡献 `系统 > 历史参照`

当前无 duplicate Extension Surface Owner。

## 5. Family Membership 与启用分离

