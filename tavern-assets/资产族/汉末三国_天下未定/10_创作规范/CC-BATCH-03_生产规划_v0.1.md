# CC-BATCH-03｜黄巾大乱时代人物卡生产规划 v0.1

> [!summary] 一句话结论
> 第三批人物卡按**主时代、次阵营**组织，专注黄巾大乱时代（约 184–189）活跃或开始冒头的角色，共 **14 张**，全部遵循 `创作规范/` 的 DSH-native 新规范创作。

## 一、定位与依据

- 本批是旧《核心人物库生产规划》（已归档至 `../99_归档/`）S/A 级名单全部完成后，第一个按真实需求自主设计构成的批次。
- 创作规范：`../../../../创作规范/DSH-native_创作总规范_v0.1.md` 与 `../../../../创作规范/人物卡_创作模板_v0.1.md`。旧 Resolver / Bootstrap 体系全部不再适用。
- 选角原则（项目所有者 2026-08-24 裁定）：
  - **批次按主时代、次阵营组织**。某时代的批次专注该时期活跃或开始冒头的角色；后续时代若角色数量多，再按阵营细分批次；
  - 时代对齐世界包的推荐开局锚点（`../../../../世界包/汉末三国_天下未定_World_Pack_v0.2.3.md` 第五章）；
  - 纳入非军政精英人物（女性、文化 / 技术、文学人物），不设每批数量上限。
- 本批时代：**阶段 I｜汉廷失序与地方军事化（约 184—189）**，覆盖世界包锚点 `5.1 184｜黄巾大乱`，并为 `5.2 189｜洛阳巨变` 提供前置人物。

## 二、与既有人物库的关系

既有 36 卡（CC-BATCH-01/02）的核心活跃期集中在 189 年以后；其中 184 年已活跃的曹操、刘备、关羽、张飞、袁绍、袁术、公孙瓒此时均处人生早期。本批不与既有卡重复，补齐的是：

1. 黄巾 / 叛乱阵营（此前完全空白）；
2. 汉廷中枢（皇帝、外戚、宦官、平叛三将——此前完全空白）；
3. 本时代冒头的地方势力源头人物。

跨卡一致性重点：黄巾起事与平叛的史实只属于世界包与各人物的个人经历，人物卡不复制战争年表；既有卡（如刘备从卢植学、曹操任骑都尉讨黄巾）与本批卡的共享经历必须在跨卡审核中对齐。

## 三、名单与功能定位（14 张）

### 黄巾 / 叛乱侧

#### 3.1 张角｜A｜中高复杂

- 时代另一方主角；太平道宗教运动领袖，全新人物类型。
- 测试重点：号召力来自信仰、组织与末世论，不是"法术"；超自然口径从严（本世界 `supernatural_default` 框架内处理）；他死于 184 年内——卡必须支持"开局时活着、原史轨迹中即将病死"的人物写法，不预写其死亡结局。

#### 3.2 张燕｜B｜中等

- 黑山军首领，黄巾余绪中持续最久的独立武装（活跃至 200s）。
- 测试重点：流民武装的生存逻辑；从"贼"到接受招安的弹性；松散联盟共主的权威边界。不写成山贼脸谱。

#### 3.3 韩遂｜B｜中等

- 185 凉州起兵，贯穿时代始终的边地叛乱 / 割据样本。
- 测试重点：凉州豪强的叛乱—招安循环；边地武人的实用主义；与马腾的同盟留作关系风格，不预写合离结局。

### 汉廷侧

#### 3.4 刘宏｜B+｜中等

- 汉灵帝，184–189 开局里他就是朝廷本身。
- 测试重点：**本族第一张皇帝卡**；卖官鬻爵背后的财政逻辑与个人欲望；昏庸不等于无人格——他的不信任、享乐与恐惧都是生成式决策素材；死于 189，不预写。

#### 3.5 何进｜B+｜中等

- 外戚大将军，184–189 朝局一极，洛阳巨变的导火索。
- 测试重点：屠户外戚的上升路径与结构性局限；"犹豫诛宦"要写成外戚、士人、妹妹（何太后）三方牵制下的决策结构，不是"优柔寡断"标签。

#### 3.6 张让｜B+｜中等

- 十常侍首领，朝局另一极。
- 测试重点：宦官人格的非脸谱化——权力完全依附皇权，其政治嗅觉与恐惧由此派生；宦官与皇帝、外戚、士人的关系网写法是新类型。

#### 3.7 皇甫嵩｜A-｜中高复杂

- 平叛主帅，184 开局玩家最可能遇上的朝廷军事核心。
- 测试重点：职业军人与士族身份的张力；将略与政治嗅觉的不对称（破贼果断、处朝局审慎）；不写成愚忠也不写成野心家。

#### 3.8 卢植｜B+｜中等

- 平叛三将之一，经学大家，刘备之师。
- 测试重点：士人 / 将领双重身份；直臣人格的生成式写法；与刘备卡的师生关系须在两张卡中保持对称。

#### 3.9 朱儁｜B+｜中等

- 平叛三将之三。皇甫嵩、卢植既做，缺他不成套。
- 测试重点：寒门武人凭军功上升的路径，与皇甫嵩（士族）形成对照；跨卡声线区分是本批 Voice Convergence 审核的重点对。

### 地方冒头 / 新势力

#### 3.10 董卓｜S 待遇｜核心复杂

- 凉州军事起家，本时代登场、时代末掌控朝廷；旧规划 S 后续候选首位。
- 测试重点：暴政与豪侠魅力并存——边军起家的务实、豪爽与入京后的暴虐是同一人格在不同权力环境下的展开，不是两张面孔的拼接；演义夸张（如"酒池肉林"）按史实分层剥离；废立、焚洛等 189 后事件不预写。

#### 3.11 孙坚｜A-｜中高复杂

- 平乱中冒头的地方武力，孙氏源头。孙策、孙权已有卡，父亲缺席不合理。
- 测试重点："轻佻果猛"的史料人格；冒险家气质与江东豪族的务实；与孙策卡的父子声线不得互相复制。

#### 3.12 刘虞｜B｜中等

- 宗室清望，188 任幽州牧。
- 测试重点：仁政与乱世武力的冲突（与已有卡的公孙瓒构成跨卡对照核心）；宗室身份带来的合法性想象与政治天真。

#### 3.13 刘焉｜B｜中等

- "废史立牧"倡议者，188 入益州；刘璋之父（刘璋已有卡）。
- 测试重点：宗室野心家——倡议州牧化的政治算计与避祸自全的私人动机并存；入蜀经营是手段不是结局，不预写其子继位。

#### 3.14 陶谦｜B｜中等

- 徐州方向，本时代已活跃。
- 测试重点：边郡武人到州牧的转型；晚年形象（演义偏向昏庸）与真实治绩的分层；与曹操日后的冲突不预写。

## 四、刻意不做的

- **张宝、张梁、波才、张曼成**：184 年内即死，史料稀薄，按 C 级由 GM 保守运行；张角卡覆盖其基本情况。
- **马腾**：187 年才冒头，归下一时代批。
- **王允、蔡邕**：戏剧核心在 189–192，归"洛阳巨变"批。
- **何太后**：189 政变核心（灵帝死后临朝），归"洛阳巨变"批，且是该批优先考虑的女性人物。
- **蔡琰、华佗、貂蝉**等非军政 / 文学人物：已获原则性许可，按时代归属分别进入 189 批或后续社会层批次。

## 五、生产顺序

交错阵营与人物类型，避免语料污染：

```text
董卓 → 张角 → 皇甫嵩 → 刘宏 → 孙坚 → 张让 → 卢植
→ 韩遂 → 何进 → 刘虞 → 朱儁 → 张燕 → 陶谦 → 刘焉
```

## 六、单卡要求

每卡默认配套 Research Note（史料极少时可极短），全部遵循新人物卡模板：

- 八节骨架（身份锚点 / 人格核心 / 能力与局限 / 决策与行为逻辑 / 关系风格与自主性 / 语言与表现 / 知识与信息边界 / 开局状态与历史边界）；
- 知识边界按"凭什么知道"写；本批多数人物死于 189–200 之间，"不知道自己原本的未来"一节是审核重点；
- Life Loop 素材：每卡至少一个日常面 + 一个非功能性互动面（如张角的传教与治病、刘宏的西园享乐、卢植的讲学）；
- `player_character_supported` 逐卡评估：董卓、孙坚、张角建议 true；刘宏、张让默认 false（皇帝与宦官首脑的接管体验需另行设计，本批不承诺）。

## 七、验收 Gate

单卡过 `人物卡_创作模板` 检查表；批次级额外审核：

- [ ] 共享历史一致：黄巾起事、平叛进程、凉州叛乱在各卡中的提及与世界包一致且不重复展开；
- [ ] 关系对称：卢植↔刘备、孙坚↔孙策、刘虞↔公孙瓒、刘焉↔刘璋、董卓↔吕布（已有卡）五组跨卡关系对齐；
- [ ] 声线收敛：皇甫嵩 / 朱儁 / 卢植三将、刘宏 / 何进 / 张让朝局三角分别通过区分度检查；
- [ ] 未来无污染：本批全部人物不得在卡内携带其死亡方式与后续政局；
- [ ] 名人标签核查：董卓≠魔王、张角≠妖道、刘宏≠昏君标签、何进≠优柔寡断；
- [ ] 索引 / 版本锁 / 成员索引同步更新。
