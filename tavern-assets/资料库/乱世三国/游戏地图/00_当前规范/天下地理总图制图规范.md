# 乱世三国｜天下地理总图制图规范

## 0. 当前状态

Level 1 天下地图标准版 v1 已由 Owner 接受，结束探索性制图阶段，进入维护状态。

当前正式原则：

> **可信的历史地理拓扑 + 为 16:9 游戏可读性服务的 Player Geometry。**

> **历史事实空间决定“在哪里、与谁相邻、位于山河哪一侧”；批准的玩家底图决定最终屏幕像素。**

后续除发现明确历史 / 地理硬错误外，不再重新生成天下底图，不再为了局部排版推翻已接受的整体构图。

---

# 1. 画布与正式玩家几何

## 1.1 标准输出

- 目标画布：`2560 × 1440`；
- 比例：`16:9`；
- 正式资产至少保留：无字底图、标准标注版、可编辑文字 / 矢量 Overlay；
- 若预览平台自动降采样，不改变 canonical 2K 坐标与 `Art U/V` 定义。

## 1.2 Fact Space 与 Artwork Space

### Fact Space

用于历史事实和校准：

- 历史经纬度；
- CHGIS / TGAZ / 遗址资料；
- Albers 工作投影；
- 历史州郡归属；
- 真实山河、邻接与方向关系。

### Artwork / Player Space

用于最终玩家显示：

- 已批准的 16:9 无字底图；
- GEO-3A 统一映射后的城市 Artwork Anchor；
- ADM-1 通过后的州郡显示布局；
- 最终文字与符号坐标。

正式玩家地图允许为了游戏性进行明显的整体舒展与局部拓扑保持形变。此前“不得为 16:9 拉伸”的绝对限制不再适用于最终玩家几何；它只作为“不得用简单经纬矩形粗暴拉伸”的事实校准警告保留。

允许形变的前提：

1. 东西南北关系不反转；
2. 一级山河与盆地关系不被改写；
3. 城市之间的邻接与关键交通关系可信；
4. 高价值叙事区域可获得更多视觉面积；
5. 形变服务游戏理解与排版，而非装饰。

原则：

> **比例可以游戏化，拓扑不能随意化。**

---

# 2. 正式世界范围

天下地图只保留汉末三国叙事需要的世界范围：

- 西到凉州 / 河西走廊，保留敦煌方向，不展开西域；
- 西南保留益州、南中必要空间，不展示大片高原；
- 北保留并州、幽州北缘和少量塞外背景；
- 东到辽东及必要海域；
- 南完整保留岭南、交州；
- 海域只承担自然收束与空间识别。

地图边缘优先由山地、荒漠、草原与海域自然收束，不采用 GIS 截图式硬切。

---

# 3. 自然地理硬约束

正式底图的一级自然地理已经冻结；后续 Overlay 不得修改底图。

必须维持：

- 祁连—河西走廊；
- 秦岭东西向屏障；
- 太行位于河北平原西缘；
- 汉中位于秦岭与大巴 / 米仓之间；
- 四川盆地内部开阔且东向经巫山—三峡出江；
- 五岭 / 南岭作为荆南—岭南屏障；
- 黄河、长江、汉水、淮水、渭水的一级拓扑。

历史水文继续遵守：

- 东汉黄河下游不照现代山东河道复制；
- 云梦泽是江汉复合湿地 / 湖沼系统，不是封闭巨湖；
- 彭蠡泽不直接复制现代巨大鄱阳湖轮廓；
- 长江、黄河、珠江三角洲按历史时期更内收 / 水域化表达。

# 4. 城市与具体节点

## 4.1 城市事实锚

历史定位状态继续使用：

- `LOCKED`
- `ANCHORED`
- `ANCHORED-REGION`
- `PERIOD-SENSITIVE`
- `PROVISIONAL`

这些状态描述历史定位确定度，不描述 Artwork 映射方法。

## 4.2 Player Anchor

GEO-3A 通过的 Artwork Anchor 原则上冻结。

- 城市符号不为州郡文字排版随意移动；
- 文字可以偏移；
- 新增地点应使用与 GEO-3A 相同的统一映射 / 局部校准逻辑；
- `DERIVED-TPS` 等属于 mapping metadata，不得替代 historical status。

# 5. 州级玩家显示策略

历史事实层仍保留汉末 13 州体系。

Level 1 标准玩家地图只显示 12 个州级大标签：

- 司隶
- 兖州
- 冀州
- 徐州
- 青州
- 荆州
- 扬州
- 益州
- 凉州
- 并州
- 幽州
- 交州

`豫州`：

- `historical_state = 豫州` 保留；
- `display_state_label = false`；
- 不在 Level 1 标准版显示州级大标题。

历史豫州对象的 Player Display Macro：

- 颍川郡 → 兖州显示区；
- 汝南郡 → 荆州显示区；
- 沛国 → 徐州显示区。

这是玩家宏观空间组织，不得改写为历史行政事实。

# 7. 文字与视觉层级

正式文字：

> **现代简体中文 + 汉末三国历史语境专名。**

必须使用真实字体 / 可编辑文字层，不允许图像模型生成伪汉字。

视觉层级：

1. 州：最大、较淡、区域标题感；
2. 郡国：中等字号、行政阅读层；
3. 城市：与符号绑定，局部识别优先级不低于郡国；
4. 战略节点：独立符号，不与城市混淆；
5. 山河湖泽：沿自然走势排版。

发生冲突时：

> **高价值具体地点 > 一级山河 > 玩家可读性 > 高价值郡国 > 区域标题完整感 > 扩展内容 > 装饰。**

留白是正式设计资源，不为填空增加低价值行政标签。

---

# 8. 行政线与 Runtime 信息

基础地图不是现代行政拼色图，也不是 SLG 势力沙盘。

- 州郡边界如显示，只能是极淡、低对比的辅助提示；
- 不使用强色块给不同州郡染色；
- 动态势力、军队、任务、玩家位置等 Runtime 信息不烘焙进中立底图；
- 玩家宏观 Display Macro 与历史行政归属必须数据分离。

---

# 9. v1 维护 Gate

除以下情况外，不重新打开 Level 1 空间设计：

- 发现明确历史硬错误；
- 发现城市位于错误山河一侧 / 区域邻接反转；
- 正式游戏 UI 证明当前 2K 资产不可用；
- 未来高信息版有独立、明确的新需求。

以下不构成重做理由：

- 某标签还可移动十几像素；
- 某扩展对象理论上还能加入；
- 某区域与真实中国比例不同；
- 预览平台降采样；
- 开发数据中存在不影响玩家成图的可后补字段。

当前 Level 1 进入维护状态，新的主生产线转入 Level 2 区域地图。
