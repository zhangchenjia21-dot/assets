## 8. R6｜QA Checklist

### Geography
- [ ] Level 1 核心地点关系未被破坏
- [ ] 山河两侧关系正确
- [ ] 主要道路符合地形
- [ ] 关隘 / 渡口确实控制对应交通
- [ ] 四向出入口合理

### Narrative
- [ ] 玩家能看懂主要旅行轴
- [ ] 高频地点优先级清楚
- [ ] 没有低价值行政百科化

### Art
- [ ] 与 Level 1 视觉 DNA 一致
- [ ] 地区性格可辨
- [ ] 古意而不做旧
- [ ] 文字真实可读
- [ ] 无字底图与标注层分离

### Game Readability
- [ ] 2K 全屏清楚
- [ ] 城市 / 道路 / 山河 / 门户一眼可分
- [ ] 保留必要留白
