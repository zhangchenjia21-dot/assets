# 2. R0｜最终区域范围

## 2.1 裁切原则

本图不是“完整四州”，而是：

> **中原东部平原核心 + 黄河下游 + 山东主体 + 淮北 / 淮水北缘。**

16:9 画幅必须同时做到：

1. 中央高密城市区获得足够面积；
2. 山东半岛仍可被一眼识别；
3. 黄河下游不是顶部装饰线，而是区域级空间屏障；
4. 淮水真正进入画面，形成南部世界边缘；
5. 海域只承担海岸识别和自然收束，不吞噬大量画布。

## 2.2 西界

最终采用：

> **荥阳—官渡—阳翟一带作为西部进入带。**

处理：

- 雒阳不作为本图正式城市重复展开；
- 西缘保留“雒阳 / 司隶方向”世界出口；
- 荥阳方向只承担与 L2-01 的连续语义；
- 官渡必须完整进入；
- 阳翟 / 颍川西部必须有稳定落位空间；
- 不继续向西展开完整河南尹。

这样可形成：

```text
L2-01 成皋 / 中原东出
→ 荥阳方向
→ 官渡
→ 陈留 / 许 / 兖豫核心
```

## 2.3 北界

最终采用：

> **黄河北岸少量冀州前场 + 平原 / 乐安方向 + 渤海南岸。**

必须保留：

- 黎阳 / 白马对岸世界语义；
- 东汉黄河下游转折；
- 平原方向；
- 山东北部与渤海岸线。

不展开：

- 完整邺城；
- 冀州腹地；
- 河北大平原北部。

北界的职责是让玩家理解：

> **黄河以北还有袁绍 / 河北世界，并且渡河点会控制中原战争。**

## 2.4 东界｜山东半岛保留策略

决定：

> **保留完整可识别的山东半岛大形，东至东莱 / 成山方向的自然海岸收束，但在 Artwork Space 中压缩东部横向面积。**

理由：

- 青州不是只有临淄一个点；
- 山东丘陵—平原—海岸过渡是本区地方性格的一部分；
- 完整半岛轮廓有很高的玩家空间识别价值；
- 直接切断胶东会让地图像一个任意矩形行政截图。

约束：

- 胶东 / 东莱不按中央核心同等密度铺城；
- 东部约作为低密度视觉缓冲与世界出口；
- 海面边距保持克制；
- 不为了保留半岛而压缩许—陈留—濮阳—徐州核心到不可读。

## 2.5 南界｜淮水 / 寿春

决定：

> **南界进入淮水，并把寿春保留为南缘高价值世界锚。**

同时：

- 淮北平原完整进入；
- 彭城—下邳—淮水的南北交通关系必须成立；
- 寿春位于南缘 / 西南缘，作为江淮—扬州方向门户；
- 淮阴 / 下游淮水可作为东南出图语义；
- 不继续展开完整长江、广陵—江东体系。

因此本图南部不是“徐州到边缘就结束”，而是：

```text
中原 / 淮北
→ 彭城 / 下邳
→ 淮水
→ 寿春 / 江淮方向（出图）
```

## 2.6 Fact Space 参考包络

只作为 R3 校准参考，不是最终矩形 GIS 裁切：

> 约覆盖今河南中东部—鲁西 / 山东主体—苏皖北部，北到渤海南缘，南到淮水—寿春一线。

最终像素由 Regional Artwork Space 决定，不用经纬矩形直接拉伸。

## 2.7 四向世界出口

- west：`荥阳 / 雒阳—司隶方向`
- north：`白马 / 黎阳 → 邺 / 河北方向`
- east：`北海 / 东莱 → 山东沿海 / 海上方向`
- south：`淮水 / 寿春 → 江淮 / 扬州方向`

辅助：

- southwest：`汝南 → 南阳 / 荆襄方向`
- southeast：`下邳 / 淮阴 → 广陵方向`

# 3. R0｜玩家第一眼必须理解什么

本图第一眼不应该读成“四块州界”，而应该读成：

> **一片被黄河—淮水包夹、被泰山—鲁中山地打断、由高密城邑和道路 / 水路连接起来的汉末中原东部核心世界。**

必须建立六个第一眼关系：

1. **许—陈留—濮阳**构成曹操早期政治 / 军事核心三角；
2. **官渡—白马 / 黎阳—黄河**解释中原与河北战争为何围绕渡口和北向门户展开；
3. **兖州—徐州之间不是空白**，而是定陶 / 任城 / 泗水 / 彭城等连续交通世界；
4. **彭城—下邳**构成徐州双核心，并由泗水—淮水体系连向南北；
5. **泰山—鲁中山地**真实改变道路走向，青州 / 徐州交通必须绕行或穿过有限谷地；
6. **临淄—北海—山东半岛**让青州 / 海岱方向成为真正可进入的东部世界，而不是地图右侧装饰。

Narrative 总体语义：

> **中原权力核心 + 黄河战争前线 + 曹操早期兖州根基 + 徐州走廊 + 海岱 / 青州方向 + 淮北南向出口。**

# 6. Historical Identity / Display Object / 行政背景

## 6.1 Level 2 豫州显示决定

Level 1 隐藏“豫州”大标签的决定**不机械传播到本图**。

L2-03 标准版决定：

> **显示低对比“兖州 / 豫州 / 徐州 / 青州”四个州级历史背景标签。**

理由：

- 本图 Narrative 本身就是四州交汇；
- 画布足够大；
- 玩家需要理解“许 / 谯 / 汝南对象为什么属于历史豫州”；
- 继续隐藏豫州会在局部尺度造成不必要的历史空间歧义。

约束：

- 州名仅作低对比背景；
- 不做 SLG 式彩色填区；
- 不使用粗重州界；
- 州名不得压过城市、山河和道路。

## 6.2 historical / display 分层

继续使用：

- `historical_identity`
- `display_name`
- `display_role`
- `historical_parent`
- `display_region`
- `display_macro_state`

L2-03 默认：

```text
historical_parent = 真实汉末行政归属
display_macro_state = 本 L2 图的低对比历史州背景
```

它不继承 Level 1 的“颍川→兖州显示区 / 汝南→荆州显示区 / 沛国→徐州显示区”宏观合并。

## 6.3 典型避免错误

- 不建立一个与“彭城”并列的历史古城“徐州”；`徐州`是州级背景，`彭城`是具体城市；
- 不把“北海”当成一座城市；可显示 `北海国` 背景，具体城市使用历史城邑；
- `许`保持历史显示，不因现代熟悉度改成同级古城“许昌”；
- `谯`保持历史城邑，不因现代对应改成“亳州”；
- `小沛`如显示，数据层写为历史沛县 / Narrative display，不制造第二座重复古城。

# 11. R3｜Regional Artwork Space

## 11.1 构图类型

本图采用：

> **“中央高密平原网络 + 北部黄河屏障 + 东部山东山地 / 半岛 + 南部淮水边缘”构图。**

不是：

- L2-01 的单一水平走廊；
- L2-02 的湿地三核 Y 型；
- 四州平均分配的行政拼图。

## 11.2 画面权重

建议视觉面积：

- west 12–15%：荥阳 / 官渡—阳翟进入带；
- center-west 30–35%：许—陈留—濮阳—鄄城高密核心；
- center-east 25–30%：任城—泰山—徐州 / 鲁中转换；
- east 20–25%：临淄—北海—山东半岛，允许横向压缩；
- south 18–22% 高度：淮北—淮水—寿春边缘带；
- north 15–20% 高度：黄河 / 河北前场 / 渤海岸。

这些百分比是构图目标，不是历史坐标。

## 11.3 必须放大的空间

- 官渡—陈留—许；
- 濮阳—鄄城—东阿 / 定陶；
- 任城—彭城—下邳；
- 许—谯—小沛—彭城；
- 泰山北侧向临淄的通道；
- 泰山南侧向琅邪 / 东海的通道；
- 临淄—北海核心；
- 淮水—寿春南缘门户。

## 11.4 可压缩空间

- 雒阳以西完整司隶；
- 黄河北岸冀州深部；
- 胶东半岛最东端低 Narrative 细节；
- 海域；
- 泰山 / 沂蒙深山区内部；
- 淮水以南完整江淮；
- 低价值县邑之间的空白行政空间。

## 11.5 绝不能改变

- 许在陈留西南 / 南侧的大方向关系；
- 濮阳位于陈留以北、东汉黄河战争空间附近；
- 彭城在下邳以西 / 西北的大方向关系；
- 泰山位于兖州东部—青徐西部之间，不得移到海边；
- 临淄 / 北海位于泰山东北—东部世界；
- 淮水位于彭城 / 下邳南部世界；
- 寿春在淮水南缘 / 江淮方向；
- 黄河不能按现代山东河道穿图；
- 主路不得直穿泰山主体；
- 山东半岛大形不能变成陌生幻想海岸。

## 11.6 平原与山地比例

硬约束：

> **连续平原 / 可居住陆地是本图主体。**

建议：

- 全图陆地主体中约 65–75% 读为平原 / 低地 / 缓丘；
- 山体集中在泰山—鲁中—沂蒙、胶东，不平均撒满；
- 泰山体量可强化，但不形成横贯全图的封闭山墙；
- 中原、兖州西部、淮北必须留足高密 Overlay 的安静面。

## 11.7 水体比例

- 海域保持克制，不因完整山东半岛让右侧变成巨大空海；
- 黄河视觉权重最高；
- 淮水次一级；
- 泗水是区域级高价值纵向河；
- 济水 / 汴水 / 颍水等明显更细；
- 不把河网画成江南水乡；
- 本图是“平原河网世界”，不是“湿地群岛世界”。
