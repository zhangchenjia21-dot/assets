# 乱世三国｜关中—弘农—雒阳区域地图输入

## 0. Pilot 目标

首张 Level 2 Pilot 用于验证：

- 天下图视觉 DNA 是否能自然下沉到区域尺度；
- 城市—道路—关隘—山河能否形成清楚的旅行空间；
- 区域图是否能增加生活痕迹而不变成行政百科；
- Level 2 是否可以使用简化流程，不重复 Level 1 全套 Gate。

本图 Narrative 主轴：

> **长安 → 渭水 / 关中平原 → 弘农 / 崤函通道 → 雒阳**

辅助轴：

> **长安 → 蓝田 → 武关 → 南阳方向（出图）**

东侧出口：

> **雒阳 → 成皋（虎牢语义）→ 中原方向（出图）**

# 2. R0｜最终语义裁切

本 Pilot 不做完整“司隶行政图”，而做一个东西向旅行走廊区域。

## 2.1 西界

- 长安必须完整进入；
- 保留长安以西少量关中平原 / 渭水背景；
- 不继续展开完整右扶风、凉州或关中西端；
- 西缘只需让玩家感到长安仍有向西世界出口。

## 2.2 东界

- 雒阳必须完整进入；
- 东侧保留巩县—成皋方向的缓冲；
- 以“中原仍向东延伸”的出图语义结束；
- 不扩展完整荥阳—陈留—兖豫核心区。

## 2.3 北界

- 保留黄河及河东南缘必要背景；
- 能看出关中 / 弘农与黄河北岸并非同一片开阔平原；
- 不展开完整河东郡、并州或山西腹地。

## 2.4 南界

- 保留秦岭北麓；
- 向东南延伸到蓝田—武关通道，使南向出口成立；
- 不深入完整汉中或南阳盆地；
- 山地只绘制与主路 / 南向门户有关的结构。

## 2.5 Regional Artwork Space 构图目标

16:9 构图建议：

- 长安位于画面约西侧 `20–25%`；
- 雒阳位于画面约东侧 `72–78%`；
- 长安—弘农—雒阳主轴横贯中部；
- 黄河占上部重要空间，但不变成北半幅主体；
- 秦岭 / 华山—崤山系统构成南侧与中段地形压力；
- 蓝田—武关支线向东南形成明确分岔。

上述百分比只是构图目标，不是历史坐标。

# 6. 道路 / 交通控制骨架

道路采用控制链，不逐像素复制历史地图线条。

## 6.1 一级东西主干

```text
长安
→ 新丰
→ 华阴 / 潼关方向
→ 弘农
→ 陕县
→ 黾池
→ 新安 / 函谷关
→ 雒阳
```

画法要求：

- 主路明显但不现代公路化；
- 在华阴—弘农—崤渑段体现山河约束；
- 不允许一条笔直粗线穿山；
- 关隘必须真正控制道路。

## 6.2 南向支线

```text
长安
→ 蓝田
→ 武关
→ 南阳方向（出图）
```

本图只展示到武关与出图方向，不进入完整南阳地图。

## 6.3 东向出口

```text
雒阳
→ 巩县方向（可选中间点）
→ 成皋
→ 中原方向（出图）
```

成皋既是城邑，也是地形门户语义。

## 6.4 北侧辅助交通

黄河北岸 / 河东南缘只保留“存在另一侧世界与渡河可能”的空间语义。

第一张 Pilot 不强制绘制一条完整北岸道路，除非后续构图确认存在不可替代的 Narrative 需要。

# 8. R3｜游戏化构图

## 8.1 必须放大

- 长安及关中东部；
- 华阴—潼关方向；
- 弘农—陕—黾池—新安的狭长过渡；
- 雒阳及西侧门户；
- 蓝田—武关分岔。

## 8.2 可以压缩

- 长安以西低价值背景；
- 黄河北岸深部；
- 秦岭内部无交通价值的深山区；
- 雒阳以东除成皋出口外的中原背景。

## 8.3 不可改变

- 长安—雒阳东西顺序；
- 渭水—关中—秦岭关系；
- 华阴 / 潼关位于关中东门方向；
- 弘农—崤函位于长安与雒阳之间；
- 武关是南向分支；
- 成皋是雒阳东向出口，不应跑到雒阳西侧。

# 9. R4｜地方性格与无字底图要求

视觉关键词：

> **关中沃野 / 渭水平原 / 秦岭北麓 / 华山险峻 / 崤函狭道 / 帝都驿路**

区域图可比 Level 1 增加：

- 关中农田 / 灌溉带的轻度生活痕迹；
- 渭水及河谷层次；
- 山麓林地；
- 少量道路沿线聚落；
- 关隘 / 山口的门户地形；
- 雒阳周围更密集的人类活动感。

避免：

- 满屏村庄；
- 现代公路网；
- 每座山都画成一级山脉；
- 秦岭画成没有通道的连续墙；
- 潼关、函谷、武关都画成夸张巨型城堡；
- 旧纸污损与奇幻装饰。
