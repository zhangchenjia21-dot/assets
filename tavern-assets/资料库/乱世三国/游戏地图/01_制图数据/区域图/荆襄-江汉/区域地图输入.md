## 0. Identity / Pilot 目标

本图不是完整“荆州刺史部行政地图”，而是以汉末三国最重要的荆襄—江汉叙事空间为核心的 Level 2 区域图。

核心目标：

> **让玩家理解宛—新野—襄阳 / 樊城—江陵—江夏 / 夏口—洞庭北缘这一大片区域如何通过汉水、长江、湿地、道路、渡口与门户形成一个水陆复合交通网络。**

本图用于验证 Level 2 模板在以下环境中的表现：

- 高密度核心城邑；
- 水陆交通并重；
- 江汉湿地 / 湖沼 / 洲滩；
- 多个 Narrative 战略节点；
- 2K 画布下的重要地区高信息密度。

### 0.1 高密度原则

与 Level 1 天下图不同，本图允许明显提高信息密度。

原则：

> **提高“有叙事与交通价值的信息密度”，不提高行政百科密度。**

推荐最终预算：

- 城邑 / 地点：`18–24` 个；
- 关隘 / 渡口 / 港口 / 战略节点：`8–14` 个；
- 水陆交通骨架：`7–10` 条；
- 自然地理标签：`12–18` 个；
- 必要行政背景标签：`3–5` 个，低优先级、低对比。

# 1. R0｜区域范围与 Narrative 目标

## 1.1 玩家必须理解什么

1. 宛—新野—襄阳是中原进入荆襄的连续南北门户链；
2. 襄阳 / 樊城控制汉水与南北陆路，是北部核心枢纽；
3. 江陵控制长江中游与江汉—荆南交通，是中南部核心枢纽；
4. 江夏 / 夏口承担汉水—长江—东向航运的东部水路枢纽角色；
5. 江汉平原不是空白平原，而是湖沼、水网、洲滩、湿地共同构成的复杂环境；
6. 长江、汉水、洞庭及主要渡口会直接改变行军、航运与城市布局；
7. 当阳—夷陵方向是向巴东 / 三峡世界离开的西向出口；
8. 江陵—洞庭—临湘方向是向荆南 / 长沙区域延伸的南向出口。

## 1.2 四向进入 / 离开方向

- north：`宛 → 中原方向（出图）`
- west：`当阳 / 夷陵 → 巴东 / 三峡方向（出图）`
- east：`夏口 → 长江下游 / 江东方向（出图）`
- south：`洞庭北缘 → 临湘 → 荆南方向（出图）`

另保留：

- northwest：汉水上游 / 上庸方向只作世界延伸语义，不展开完整汉中；
- northeast：南阳东部 / 安陆方向可作为辅助连接，但不扩展完整豫州 / 江淮。

## 1.3 最终语义裁切

### 北界

- 完整包含宛、新野；
- 保留南阳盆地南部 / 中原来路语义；
- 不继续展开完整颍川、汝南与中原腹地。

### 西界

- 保留襄阳以西少量汉水上游背景；
- 中南部保留当阳—夷陵方向的西向出口；
- 不进入完整巴东 / 三峡区域图。

### 南界

- 保留洞庭湖北缘；
- 临湘必须进入；
- 可保留湘水北段与荆南出图语义；
- 不展开完整零陵、桂阳、岭南。

### 东界

- 完整覆盖江夏 / 夏口水陆枢纽；
- 长江继续向东留出明显出图空间；
- 不展开完整柴桑—豫章—扬州体系。

## 1.4 视觉主体

推荐三核结构：

1. **襄阳 / 樊城**：北部门户核心；
2. **江陵**：中南部长江核心；
3. **江夏 / 夏口**：东部水路核心。

主 Narrative 轴：

```text
宛
→ 新野
→ 襄阳 / 樊城
→ 汉水 / 江汉平原
→ 江陵
```

东向水路轴：

```text
襄阳 / 樊城
→ 汉水下行
→ 江夏 / 夏口
→ 长江东出
```

南向轴：

```text
江陵
→ 洞庭北缘
→ 临湘
→ 荆南方向
```

西向轴：

```text
江陵
→ 当阳
→ 夷陵
→ 巴东 / 三峡方向
```

# 6. 自然地理对象

## 6.1 一级必须

- 汉水；
- 长江；
- 云梦泽 / 江汉湿地系统；
- 洞庭湖 / 洞庭水域；

## 6.2 高价值建议

- 湘水；
- 大洪山（若裁切范围与构图允许）；
- 襄阳盆地 / 汉水河谷（可只通过地貌表达，不强制文字）；

- 当阳—夷陵西向山地；
- 江汉水网 / 洲滩环境。

## 6.3 水环境表现硬规则

### 云梦泽

禁止画成单一、封闭、现代形态“大湖”。

应表现：

> **平原 + 湖沼 + 水网 + 湿地 + 洲滩 + 漫流河道**

### 洞庭

保留大尺度湖泽认知，但不逐像素复制现代洞庭湖岸线。

### 汉水 / 长江

必须形成明显视觉等级：

- 长江：全图一级大河；
- 汉水：北部—东部最重要内河轴；
- 次级河流不得抢夺二者视觉权重。

## 7.1 构图类型

本图不沿用 L2-01 的水平走廊构图。

> **“三核 + Y 型 / 三叉水陆网络”构图。**

- 北核：襄阳 / 樊城；
- 中南核：江陵；
- 东核：江夏 / 夏口；
- 南支：洞庭—临湘；
- 西支：当阳—夷陵；
- 北支：新野—宛。

## 7.2 必须放大的空间

- 宛—新野—襄阳门户链；
- 襄阳 / 樊城汉水两岸；
- 襄阳—江陵走廊；
- 江陵周边长江与江汉连接空间；
- 江夏 / 夏口水陆枢纽；
- 云梦 / 江汉复合湿地；
- 洞庭北缘—临湘；
- 当阳—夷陵西向出口。

## 7.3 可压缩空间

- 南阳北部低 Narrative 背景；
- 襄阳以西深山；
- 武陵深山区；
- 洞庭以南完整荆南腹地；
- 夏口以东完整江东背景；
- 非交通轴上的低价值县邑空间。

## 7.4 绝不能改变

- 宛—新野—襄阳顺序；
- 襄阳—江陵南北 / 西南方向联系；
- 江陵—夏口长江东西联系；
- 汉水从襄阳进入江汉低地并汇入长江体系；
- 洞庭位于江陵以南；
- 当阳—夷陵位于江陵西向 / 西北向世界；
- 山地不能封死汉水、长江或主要陆路门户。

# 8. R4｜环境与地方性格

- terrain_character：南阳—襄阳盆地 / 河谷、江汉大低地、西部山地、洞庭湖泽；
- vegetation：河湖湿地芦苇 / 林带，平原农业带，西部山地林地；
- water_character：大河 + 内河 + 复合湿地 + 湖泽，为本图第一视觉系统；
- settlement_character：河港、渡口、堤岸聚落、平原城邑、交通路口；
- agriculture / economy cues：江汉水田 / 农田、河渠、航运、港口与集镇感；
- atmosphere：**水陆交织 / 湿润 / 繁忙 / 战略枢纽 / 河湖世界**。

与 L2-01 区别：

- 山体不应占据半幅画面；
- 水体与低地网络必须成为主角；
- 道路不能独占交通表达，水路与渡口至少同等重要；
- 云梦 / 洞庭不是装饰性水面，而是决定旅行方式的空间本体。

- 主陆路：2–3；
- 高价值渡口 / 港口：3–5；
- Narrative / 战略点：4–7；
- 一级自然地理：6–8。

## 9.2 可选层

在 2K 全屏仍清楚的前提下：

- 次级县邑增加到总城邑 `18–24`；
- 二级道路 / 联络线总计不超过 `4–5`；
- 自然地理标签可增加至 `12–18`；
- 允许 `3–5` 个低对比行政背景标签，例如：南阳郡、南郡、江夏郡、长沙郡；必要时加武陵郡边缘语义。

行政背景标签仅用于空间认知：

- 不画厚重郡界；
- 不给郡国不同填色；
- 不压过城市、水系与交通。

## 9.3 删除优先级

碰撞时优先删除：

```text
低价值可选县邑
→ 次级行政背景标签
→ 次级道路
→ 低优先 Narrative 节点
```

不得优先牺牲：

- 襄阳 / 樊城；
- 江陵；
- 江夏 / 夏口核心；
- 汉水 / 长江；
- 关键渡口 / 港口；
- 主水陆交通轴。
