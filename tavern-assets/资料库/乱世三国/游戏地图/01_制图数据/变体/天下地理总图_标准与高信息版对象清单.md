# 乱世三国｜天下地理总图标准与高信息版对象清单 CURRENT

## 0. 决策

本文件把已审核的宽候选池收敛成下一轮正式排版的确定输入。

Owner 已接受：

- 2K 全屏下，第二张概念图附近的信息密度量级是可接受的；
- 后续重点不是继续扩大名单，而是提高位置准确性、文字清晰度和底图洁净度；
- 天下图不追求完整东汉行政目录。

因此第一轮标准版采用：

> **132 个有效信息对象基线。**

构成为：

- 州级空间：13
- 重点郡国：48
- 城市 / 具体地点：38
- 战略 / 关隘 / 战役空间：11
- 自然地理文字：22

这 132 个是**排版输入基线**，不是“无论碰撞都必须全部显示”的死 KPI。若 2560×1440 实际排版发生不可解决的局部碰撞，按照本文件的删减规则处理，不能通过把所有文字缩到难读来强行容纳。

高信息版第一阶段恢复到约 **152 个主候选对象**；更冷门的郡国仅作为二级 reserve，不默认进入高信息版。

# 6. 高信息版恢复顺序

高信息版不重新设计世界，只在相同底图和相同坐标事实层上恢复信息。

优先恢复顺序：

```text
标准版 132
→ + 7 个主候选郡国
→ + 4 个城市 / 地点
→ + 4 个战略对象
→ + 5 个自然地理标签
= 约 152 个主候选对象
```

如果 2560×1440 高信息版仍然有余量，再从以下二级 reserve 郡国中按区域需求选择，而不是一次全部加入：

# 7. 碰撞时的删减优先级

标准版发生不可解决的局部碰撞时，按以下顺序考虑降级：

```text
高信息 / reserve 对象
→ 标准版中的低重复价值 B 级郡国
→ 与郡名高度重复的次级城市
→ 次级战略节点
→ 次级自然地理文字
```

以下内容最后才考虑删除：

- A 级具体城市 / 高价值 Narrative 地点；
- 黄河、长江、汉水、淮水、渭水等一级水系；
- 秦岭、太行等决定大区关系的一级地形；
- 13 州的区域认知能力。

关键原则继续有效：

> **高价值具体地点 > 低价值行政完整性。**
