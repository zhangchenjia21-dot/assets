# 乱世三国｜天下地理总图一级地理骨架控制表 CURRENT

## 0. 用途

本文件把 `GEO-2` 从原则进一步收敛为可画结构底稿的控制对象。这里定义的是**路径 / 山带 / 面域的约束**，不是最终美术线条。

原则：

> **先冻结自然地理拓扑和相对位置，再让美术去表现它。**

---

# 1. 一级水系

## 1.1 黄河｜必须历史校正下游

上中游在天下尺度可参考现代地貌 / 水系骨架；进入河南以后必须切换到东汉河道逻辑。

东汉王景治河后的下游控制关系：

```text
荥阳方向
→ 河南北部主河道
→ 长寿津 / 今濮阳县西南一带分出东汉大河
→ 今范县南
→ 今山东莘县 / 阳谷一带
→ 东阿 / 茌平附近
→ 禹城西一带
→ 滨州方向
→ 利津附近入渤海
```

正式结构图不得照现代黄河的山东河道直接描绘。

天下图的黄河需要明显形成：

- 关中北缘—河东弯曲；
- 雒阳北部大河；
- 河北 / 兖州之间的历史空间屏障；
- 东汉下游向东北入渤海，而非采用近现代入海路径细节。

## 1.2 长江

天下尺度主干整体沿现代河谷骨架，但需避免把现代水库 / 堤岸 / 三角洲岸线当作汉末状态。

控制节点：

```text
巴蜀东部
→ 鱼复 / 三峡
→ 夷陵
→ 江陵南侧荆江
→ 江汉平原南缘
→ 武汉江段 / 汉水入江
→ 柴桑附近
→ 江淮南缘
→ 秣陵 / 丹阳北缘
→ 吴郡北部
→ 东海古岸线
```

江汉平原段应表现曲流、洲滩与湖沼环境，但不要画成现代工程化河槽。

## 1.3 汉水

控制关系：

```text
汉中盆地
→ 上庸以北 / 东北山地
→ 襄阳—樊城节点
→ 江汉平原北部
→ 夏口战略区域
→ 长江
```

汉水是解释“汉中—襄阳—江夏”叙事空间的核心水系，视觉权重仅次于黄河、长江。

## 1.4 淮水

控制关系：

```text
豫南 / 桐柏山方向
→ 汝南北缘 / 江淮北部
→ 寿春北部水网
→ 淮北—淮南交通带
→ 东部平原
→ 古代下游入海 / 水网区域
```

正式结构图先保证淮水东西骨架正确，不在 GEO-2 强画完整现代支流网。

## 1.5 渭水

控制关系：

```text
陇西东部
→ 关中平原
→ 长安北侧
→ 潼关附近汇入黄河
```

渭水与秦岭北麓共同定义关中盆地。

# 2. 二级高价值水系

第一张结构图建议加入但降低视觉权重：

- 汾水：太原盆地 → 河东黄河；
- 泾水：关中北部 → 渭水；
- 洛水：雒阳南 / 东南 → 黄河；
- 漳水：邺附近河北南部水系；
- 湘水：荆南 → 洞庭湖；
- 沅水：武陵方向 → 洞庭湖；
- 赣水：豫章 / 柴桑方向的江西主水系；
- 济水：只作为历史高价值水系处理，路径需要继续按历史资料核，不直接套现代同名水道。

---

# 3. 一级山地 / 地貌带

## 3.1 秦岭

必须成为天下图最清晰的东西向山地屏障之一：

- 北侧：关中平原；
- 南侧：汉中盆地与巴蜀北缘；
- 连接陇山—秦岭—伏牛等山地体系时不必画成单一墙体；
- 武关方向需自然形成关中东南出口。

## 3.2 太行山系

必须清楚解释：

- 并州 / 上党与河北平原的东西分隔；
- 井陉等通道为什么重要；
- 河内、邺、太原之间的地形关系。

山带整体东北—西南延伸，不得由 AI 随机画成散山。

## 3.3 祁连山

控制河西走廊南缘：

```text
敦煌—酒泉—张掖—武威走廊
北：荒漠 / 戈壁
南：祁连山带
```

河西走廊必须通过山地与荒漠关系自然“被看出来”，而不是只靠文字标签。

## 3.4 阴山

承担并州北部—朔方方向的北疆地形背景，不需要画到和秦岭同等细节，但要形成明显北缘山带。

## 3.5 巴蜀盆地周缘

必须明确：

- 成都平原 / 四川盆地是相对开阔、低平的内部空间；
- 北缘有秦岭—大巴山 / 米仓山方向屏障；
- 东缘通过巫山 / 三峡与荆州连接；
- 西部与南部山地更强烈但不必全部标名。

## 3.6 巫山—三峡山地

鱼复—夷陵之间的长江必须呈现明显峡谷感，不能像普通平原河段。

## 3.7 五岭 / 南岭体系

承担荆南 / 扬州南部与岭南 / 交州之间的空间屏障。天下图表现为连续但有通道的山地区，不画成封闭墙。

---

# 4. 盆地 / 平原面

必须在无字结构图中能通过留白、坡度和山地围合看出来：

- 关中平原；
- 华北平原 / 河北南部平原；
- 中原平原；
- 成都平原 / 四川盆地；
- 汉中盆地；
- 江汉平原；
- 洞庭湖平原；
- 江淮平原；
- 长江下游 / 江南水网平原；
- 河西走廊。

平原不是“空白没画东西”，而是主动保留视觉安静面，为后续州郡、城市和道路留空间。

---

# 5. 湖泽 / 湿地策略

## 5.1 云梦泽

不画成现代意义上一整块边界清楚的大湖。

汉末江汉平原应表现为：

> **平原 + 湖沼 + 水网 + 湿地 + 洲滩的复合系统。**

可以通过数块浅水 / 湿地区域表达“云梦泽余绪”，但不能让玩家误解为一座现代轮廓的大湖。

## 5.2 洞庭湖

保留高价值大水域认知，但古代湖群 / 洲滩形态不照现代岸线逐像素描绘。

## 5.3 彭蠡泽 / 鄱阳湖区域

汉末三国阶段不能直接使用现代鄱阳湖巨大南扩轮廓。

结构图策略：

- 重点表现九江—柴桑—湖口附近的水域与赣水下游低地；
- 湖体比现代鄱阳湖明显更克制；
- 对“彭蠡泽”采用历史水域概念，不用现代鄱阳湖岸线当唯一真值。

## 5.4 震泽 / 太湖

可以保留大尺度水域，但避免把现代人工岸线细节带入。

---

# 6. 海岸线策略

大部分基岩海岸在天下尺度可以以现代海岸为几何参考，但以下区域需要历史化：

- 长江三角洲 / 上海—太仓—吴淞一带：汉末海岸线应比现代更内收；
- 黄河三角洲 / 利津一带：东汉大河正在塑造古三角洲，不能直接使用现代黄河口形态；
- 珠江三角洲：现代围垦与三角洲增长显著，汉末应更水域化、海湾化；
- 其他冲积三角洲视 2K 尺度做适度历史化，不追求海岸测绘级复原。

---

# 7. GEO-2 第一张结构底稿内容

第一张结构底稿**只画**：

- 海岸 / 大陆轮廓；
- 一级山带；
- 盆地 / 平原面；
- 一级水系；
- 必要的二级水系；
- 湖泽 / 湿地区域。

第一张结构底稿**不画**：

- 州郡边界；
- 城市符号；
- 关隘符号；
- 任何汉字；
- 纸张做旧纹理；
- 装饰图案；
- 势力信息。

审核目标只有一个：

> **不看任何文字，也能判断关中、河北、中原、汉中、巴蜀、荆襄、江东、岭南这些空间关系是可信的。**
