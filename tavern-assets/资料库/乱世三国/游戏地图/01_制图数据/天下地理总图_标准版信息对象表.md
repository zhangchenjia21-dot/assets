# 乱世三国｜天下地理总图标准版信息对象表

## 0. 当前决策

Level 1 标准版 v1 已通过玩家视觉验收，本表记录正式显示对象集合。

目标不是行政百科，而是：

> **让玩家在 16:9 全屏状态下理解三国世界的主要区域、城市、交通和山河关系。**

当前实际通过的信息量：

| 类别 | 数量 |
|---|---:|
| 玩家州级标签 | 12 |
| 郡国 | 50 |
| 城市 / 地点 | 39 |
| 战略节点 | 8 |
| 自然地理文字 | 约 26 |

旧候选预算仅作为历史规划，不再为了命中区间硬增 / 硬删对象。

司隶、兖州、冀州、徐州、青州、荆州、扬州、益州、凉州、并州、幽州、交州。

## 1.2 历史保留但 Level 1 隐藏

**豫州**：历史事实保留，但标准玩家地图不显示州级大标签。

历史豫州对象的 Player Display Macro：

- 颍川郡 → 兖州显示区；
- 汝南郡 → 荆州显示区；
- 沛国 → 徐州显示区。

注意：Display Macro 不改变 historical parent。

# 6. 删减优先级

若未来维护版本出现真实碰撞：

```text
非当前标准对象
→ 低价值扩展城市 / 专题节点
→ 可替代行政标签
→ 最后才考虑当前核心城市、一级山河或已由 Owner 明确保留的高价值郡国
```

禁止通过把全图字号一起缩小到难读来解决碰撞。

---

# 7. 维护原则

本表已从“候选预算”进入“v1 正式对象集”。

未来只有在以下情况下修改：

- 明确历史事实修正；
- 游戏 Narrative 出现持续、真实的新高价值地点需求；
- 正式 UI 证明当前对象不可读；
- 生成独立高信息版 / 区域图时需要恢复对象。

普通视觉微调不重新打开对象池。
