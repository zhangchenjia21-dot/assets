# 乱世三国｜天下地理总图核心点位坐标表 CURRENT

## 0. 职责

本文件是天下总图的**点位事实工作表**。它只负责具体城市 / 城邑 / 关隘 / 战略节点的空间锚点，不负责州郡文字排版，也不允许图像生成模型自行决定地点位置。

硬规则：

> **历史坐标先于美术构图。**
>
> **符号锚点可以锁死，文字标签可以偏移。**
>
> **资料不足时标记不确定，不伪造精确度。**

---

# 1. 定位状态

- **LOCKED**：已有 CHGIS / TGAZ、官方遗址或等价高可信资料支持，可进入 GEO-3 点位测试图。
- **ANCHORED**：历史城址所在现代区域可靠，但当前引用精度不足以声称“古城中心点已精确锁定”；足以限制大方向，正式点位图前仍可微调。
- **ANCHORED-REGION**：可以锁定到城市 / 遗址区域，但暂不指定唯一像素锚点；不得在 GEO-3 中冒充精确点。
- **PROVISIONAL**：名称、时期、关址或具体点位仍有明显争议；不得直接进入正式点位图。

状态描述的是**制图确定度**，不是历史重要性。

# 2. 工作投影与 2K 草图框

统一采用空间规划文件中的 Albers Equal Area Conic 工作投影：

```text
proj = aea
lon_0 = 105°E
lat_1 = 25°N
lat_2 = 47°N
WGS84
reference extent = 85°E–131°E / 17°N–43°N
```

2K 草图框：

```text
canvas = 2560 × 1440
projected body ≈ 2020 × 1280
origin ≈ (270, 80)
```

`U / V` 为投影参考范围内归一化位置；`2K X/Y` 只用于当前排版草图。正式事实源始终是历史经纬度 / 投影坐标与来源记录。

# 6. 关隘定位：必须先分清“历史关”与“现代景区”

## 6.1 函谷关｜PROVISIONAL

当前资料明确存在至少两套需要区分的历史空间：

- **秦函谷关 / 函关古道**：今河南灵宝一带；
- **汉函谷关遗址**：今河南新安县东关村。

汉末三国地图不能因为现代知名景区位于灵宝，就自动把“函谷关”钉到灵宝。必须继续核实东汉末文献语境中的具体关址 / 通道。必要时标准版可改用**崤函通道**的区域表达，而不是伪精确单点。

## 6.2 武关｜ANCHORED AS CORRIDOR

陕西文物资料有丹凤武关城遗址；历史交通资料明确长安—蓝田—武关—襄阳的武关道。当前足以锁定丹凤武关镇及武关河通道，但正式关隘符号仍应结合古城墙 / 古道位置，而非现代镇中心。

## 6.3 井陉｜ANCHORED AS CORRIDOR

河北文保资料可确认井陉古驿道、古关隘及太行东西交通功能。天下图优先表达**井陉陉口 / 古道通道**，不缩成现代单一景区 POI。

## 6.4 剑阁 / 剑门｜ANCHORED AS CORRIDOR

三国时期蜀北道路与大剑山—剑阁道空间可靠；“剑门”建制 / 关名的具体时代需继续核。第一阶段先锁蜀北山地门户，不急着强画一个后世关楼。

## 6.5 潼关｜PROVISIONAL

现存全国重点文物保护对象“潼关故城”主要反映唐至明清城址，不可直接把该保存遗址当成建安十六年（211）汉末“潼关”的唯一精确位置。需要继续做时代关址核验。

## 6.6 暂不锁点

- 成皋 / 虎牢
- 壶关
- 阳平关
- 葭萌
- 白帝 / 白帝城（鱼复本身已经 LOCKED，可先用鱼复城址承担三峡西端锚点）
