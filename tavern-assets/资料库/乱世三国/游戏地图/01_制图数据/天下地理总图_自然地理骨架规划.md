# 乱世三国｜天下地理总图自然地理骨架规划

## 0. 职责

本文件是 `GEO-2｜自然地理骨架` 的 Data Owner，负责冻结天下总图应遵守的海岸、一级山脉、盆地 / 平原、水系、湖泽与关键交通地形关系。

本阶段不生成正式带文字地图。

核心原则：

> **先继承可信的真实地形走势，再做范围控制、历史校正和游戏化重点化。**
>
> **不要让图像生成模型重新“理解”中国山河。**

---

# 1. 2026-08-27 superseding decision｜一级地形参考锁定

Owner 已明确指定：当前聊天中重新提供并确认的**无字中国 / 东亚地形参考图**，其山脉、盆地、平原和主要水系的大尺度走势，作为后续天下图一级自然地理的**结构基准**。

该决策 supersede 此前让图像生成模型根据文字 Prompt 自由重构一级地貌的尝试。

后续生产方法固定为：

```text
Owner 认可的地形参考
→ 提取一级山脉 / 盆地 / 平原 / 主水系走势
→ 按汉末历史地理校正会显著变化的河道、湖泽、三角洲
→ 收缩到三国有效世界范围
→ 对高价值区域做拓扑保持的游戏化空间强化
→ 再进行美术风格化
```

不是：

```text
描述“中国地形”
→ 让生成模型重新画一张类似中国的幻想大陆
```

## 1.1 必须继承的结构

后续底图必须从已认可参考中继承并保持可辨识：

- 中国大陆东部整体走势与海岸大形；
- 渤海湾、辽东半岛、山东半岛及东南沿海基本关系；
- 祁连—河西走廊结构；
- 秦岭的东西向屏障；
- 太行山位于华北平原西缘的南北向山带；
- 汉中位于秦岭与米仓 / 大巴山之间的狭长盆地 / 谷地；
- 四川盆地的真实开阔盆地结构，而非圆形封闭山墙；
- 四川盆地东向经巫山—三峡接长江中游的出口；
- 五岭 / 南岭作为荆南—岭南屏障；
- 黄河、长江、汉水、淮水、渭水的大尺度拓扑关系。

## 1.2 允许改变的内容

可以为了游戏化而调整：

- 世界裁切范围；
- 高价值区域的视觉面积；
- 山脉的绘画体量与醒目程度；
- 河流视觉宽度；
- 平原 / 盆地的留白与可读面积；
- 边缘地区的压缩程度；
- 局部标签空间所需的轻微拓扑保持形变。

不得改变：

- 一级山脉的基本走向；
- 关键盆地的开口与围合关系；
- 主要河流的流域拓扑和汇流关系；
- 东部大陆轮廓到“已不像中国”的程度；
- 决定重要历史交通 / 战役成立的山河关系。

一句话：

> **游戏化改造发生在真实山河骨架之上，不重新发明山河骨架。**

当前自然地理资料职责：

- Owner 认可的无字地形参考：**一级山地 / 盆地 / 平原 / 海岸大形的主结构参考**；
- `中国立体地势图.jpg`：辅助核对高程和大地貌；
- `中国河流水系图.jpg`：现代水系拓扑辅助，不直接决定汉末下游河道；

- `三国州郡地图.png`：只承担宏观区域认知。

优先级：

> **已认可地形结构参考 > 其他现代地貌辅助 > AI 自由构图。**

历史时期发生显著变化的水文对象仍以历史地理核验优先。

# 4. 一级山地骨架

## 4.1 祁连—河西

祁连山控制河西走廊南缘。河西必须读成狭长可通行走廊：

```text
北部荒漠 / 北山背景
↓
敦煌—酒泉—张掖—武威走廊
↓
祁连山
```

后续范围裁切止于凉州 / 敦煌方向，但不能破坏走廊自身走势。

## 4.2 秦岭—关中—汉中

秦岭是天下图最重要的东西向屏障之一：

- 北：关中平原、渭水；
- 南：汉中盆地；
- 东：向南阳 / 中原过渡；
- 西：与陇山、陇右山地衔接。

秦岭不得被画成围绕四川盆地的随机弧形山墙。

## 4.3 太行山系｜必须明确存在

太行山必须按认可参考保留为**华北平原西缘的南北向山地带**：

```text
并州 / 太原 / 上党
｜
太行山
｜
冀州 / 河北平原
```

要求：

- 连续可辨，但不是绝对封闭墙；
- 井陉等通道在地貌上具有成立空间；
- 不得拆成无方向碎山；
- 不得移到华北平原中央。

## 4.4 四川盆地—汉中体系｜禁止“封闭圆盆”

必须清楚区分：

```text
关中
↓
秦岭
↓
汉中盆地 / 汉水上游
↓
米仓山—大巴山
↓
四川盆地
↓东
巫山—三峡
↓
荆州
```

四川盆地要求：

- 内部是较开阔、可生活 / 可叙事的大盆地；
- 成都平原位于盆地西部并应最为开阔；
- 中东部允许有柔和丘陵与河谷，不能是一块完全平坦圆盘；
- 北缘山地形成阻隔但存在通往汉中的历史通道体系；
- 东缘必须由长江穿越巫山—三峡形成明确出口；
- 不允许画成连续无缺口的环形山墙。

## 4.5 巫山—三峡

巫山必须与长江绑定表达：山体形成峡谷，长江从四川盆地东部穿出进入荆州。这里是**门户**，不是封锁线。

## 4.6 武陵—五岭 / 南岭

承担荆南—岭南之间的空间屏障。山带连续但必须留有交通可能，不画成无缝巨墙。

# 6. 一级水系

## 6.1 黄河｜汉末下游历史校正

上中游沿已认可结构参考保持真实大势。

河南—山东下游按王景治河后的东汉大河逻辑：

```text
河南北部 / 濮阳附近
→ 范县一带
→ 鲁西北
→ 滨州—利津方向
→ 渤海
```

不得直接采用 1855 年以后现代山东黄河下游。

## 6.2 长江

大尺度主干继承认可参考，必须保持：

```text
巴蜀
→ 鱼复 / 三峡
→ 夷陵
→ 江陵 / 荆江
→ 汉水入江
→ 柴桑 / 九江
→ 江淮南缘
→ 江东
→ 古长江口
```

## 6.3 汉水｜高视觉权重

必须明确：

```text
汉中
→ 上庸方向
→ 襄阳 / 樊城
→ 江汉平原
→ 入长江
```

汉水是三国叙事轴，不得被当作普通细支流弱化。

## 6.4 淮水

保留豫南—江淮—东部低地的东西向主干，不把后世黄河南徙夺淮状态带回汉末。

## 6.5 渭水

必须清楚定义关中：长安处于渭水—关中体系内，向东汇入黄河。

# 8. 湖泽与海岸

## 8.1 陆地主体原则

湖泽用于解释空间，不得吞噬地图主体。

> **天下底图以陆地为主，河流为骨架，湖泽为辅助。**

禁止把江汉、洞庭、彭蠡、江东水网画成“千岛湖式”大片碎水域。

## 8.2 云梦泽

表现为江汉平原的湖沼、湿地、水网、洲滩复合系统，不画单个巨湖。

## 8.3 洞庭

保留重要湖区认知，但湖体面积克制，以历史湖群 / 洲汊感表现。

## 8.4 彭蠡泽

禁止套现代鄱阳湖巨大南展轮廓；重点保留北部历史水域、赣水汇入与长江关系。

## 8.5 太湖 / 震泽

可以存在，但面积与视觉权重服从陆地主体和江东排版空间。

## 8.6 海岸

东部大陆总体走势必须保持“中国可识别性”。重点保留：

- 渤海湾；
- 辽东半岛；
- 山东半岛；
- 江东沿海大形；
- 岭南海岸。

历史化仅针对真实变化显著的冲积区：

- 黄河三角洲；
- 长江三角洲；
- 珠江三角洲。

不得为了游戏化把东海岸重构成陌生幻想大陆。

---

# 9. 历史机动可行性 QA

一级地貌不只要“像地形”，还要支持重要历史交通 / 战役的基本空间逻辑。

后续 GEO-2 审核至少检查：

## 9.1 汉中之战 / 蜀道体系

地图必须支持：

```text
关中
↕ 秦岭通道
汉中 / 阳平关—汉水体系
↕ 米仓 / 大巴山通道
四川盆地
```

同时定军山一带应在汉中南缘山地具有成立空间。

## 9.2 太行通道

太行必须形成并州—河北屏障，同时井陉等东西通道具备地貌意义。

## 9.3 巴蜀东出口

长江必须能从四川盆地东部穿越巫山—三峡进入荆州。

## 9.4 关中—雒阳

崤函 / 黄河—秦岭关系应支持关中向中原的战略门户结构。

## 9.5 荆襄轴

汉水—襄阳—江汉平原—长江关系必须使荆襄交通轴自然成立。

如果重要历史事件只有在“山脉不存在”或“河流改道”时才有可能发生，则 GEO-2 失败。

---

# 10. 游戏化处理边界

在以上真实结构固定后，允许：

- 裁掉青藏高原和西域的大面积背景；
- 西界收至凉州 / 河西；
- 东至辽东，南至交州；
- 适度放大关中、河北南部、中原、荆襄、巴蜀、江淮、江东；
- 强化一级山脉体量；
- 扩大平原留白；
- 简化二级丘陵、水网和海岸细节。

所有形变必须拓扑保持。

原则：

> **真实参考决定山河怎么走；游戏设计决定哪些地方更醒目、更宽、更好读。**

# 12. 下一版验收重点

下一版无字结构 / 美术底图只有在以下全部成立后才可过 GEO-2：

1. 大陆东部大形仍明显像中国；
2. 河西—关中—秦岭—汉中—大巴—四川盆地层级正确；
3. 太行山明确位于华北平原西缘；
4. 四川盆地围而不死，北向与东向通路逻辑存在；
5. 汉中与四川盆地是两个明确地貌单元；
6. 黄河下游使用东汉大河逻辑；
7. 长江、汉水、淮水、渭水主干拓扑正确；
8. 湖泽面积克制，以陆地主体为主；
9. 海岸只做历史校正与受控简化，不奇幻化；
10. 关中、中原、荆襄、巴蜀、江淮、江东获得足够游戏可用空间；
11. 主要历史交通 / 战役在地貌上具备可行性；
12. 2560×1440 下仍有足够安静面容纳后续标注。
