# 乱世三国｜天下地理总图空间定位与排版规划 CURRENT

## 0. 本轮反馈后的流程修正

本文件落实第一、第二张概念图暴露的问题，并在下一次生成美术前先冻结空间定位方法。

Owner 已确认：

- 第二张概念图的**信息密度量级基本合适**；
- 当前主要问题不是信息太少，而是**地点错位、繁简混用、字体不清、底图偏脏**；
- 下一阶段必须**先规划与校准，再生成图**。

因此从本文件开始执行以下硬规则：

> **AI 不负责历史地理定位。**
>
> **AI 不负责正式地图中文字。**
>
> **AI 只在已冻结的空间骨架上负责地图美术表现。**

在 `GEO-1` Gate 通过前，不再生成新的正式地图概念成图。

# 1. 地理参考与证据优先级

## 1.1 用户提供的四张原始资料

- `三国州郡总图.jpeg`：州郡与历史地名空间关系主参考；
- `三国州郡地图.png`：宏观区域认知辅助；
- `中国立体地势图.jpg`：现代自然地貌骨架参考；
- `中国河流水系图.jpg`：水系骨架参考。

这些图用于建立地图整体结构，但不单独承担高价值城市的精确落点。

## 1.2 精确点位核验

高价值城市 / 城邑 / 关隘优先使用：

1. **CHGIS / 复旦 TGAZ 时空地名辞典**；
2. 文物考古 / 政府遗址资料；
3. 用户提供的历史地图经纬网；
4. 可靠历史地理研究中的现代对应位置；
5. 只有前述资料不足时，才保留为 provisional，不得由图像模型自行猜测。

CHGIS / TGAZ：`https://tgaz.fudan.edu.cn/tgaz/`

# 2. 投影与画布：禁止直接拉伸经纬度矩形

## 2.1 纠正上一轮简单经纬映射

曾提出将约 `85°E–131°E / 17°N–43°N` 直接按经纬度比例映射到 16:9。该方法会因为经度实际尺度随纬度变化而造成明显东西向拉伸，不再采用。

正式方法改为：

```text
历史经纬度
→ 统一地图投影
→ 保持投影后的几何比例
→ 等比装入 16:9 画布
→ 仅允许受控的制图排版偏移
```

## 2.2 当前规划投影

制图规划阶段采用中国区域适用的 Albers Equal Area Conic（等面积圆锥）作为**工作投影**：

```text
proj = aea
lon_0 = 105°E
lat_1 = 25°N
lat_2 = 47°N
WGS84
```

该投影只是美术定位工作基线，不是游戏 Runtime GIS Contract；如果后续真实地图底稿使用更高权威的历史 GIS 投影，可整体替换，但所有点位仍必须由同一投影统一转换。

## 2.3 当前地理参考范围

首轮参考范围：

```text
85°E – 131°E
17°N – 43°N
```

范围用于容纳：

- 河西走廊与敦煌方向；
- 并、幽北缘；
- 辽东；
- 中原、关中、巴蜀、荆襄、江东；
- 岭南、交州与日南方向。

**范围不等于强制行政疆域边界。** 画面边缘允许表现外围山地、海域和自然背景。

## 2.4 16:9 装框

玩家审核目标：`2560 × 1440`。

源母版目标：`7680 × 4320`。

投影后地图几何不得为填满 16:9 而横向拉伸。首轮 2K 规划中，地图主体投影框建议：

- 上下约留 `80 px` 基础安全余量；
- 投影主体高度约 `1280 px`；
- 按投影比例等比缩放后，主体宽约 `2020 px`；
- 左右自然产生约 `270 px` 量级空间，可用于海域、边疆环境、标题 / GUI 安全区，而不是把大陆强行拉宽。

以上为 v0.1 排版基线，可在真实 GUI 设计出现后整体调整。

# 3. 点位 / 区域 / 文字三类坐标必须分离

## 3.1 城市与具体地点 = 点

城市、县城、古战场、关隘等具体对象拥有真实地理锚点。

规则：

- **城池 / 节点符号以历史坐标为准，不为排版随意搬家**；
- 2K 标准版一般不允许城池符号因排版偏移超过约 `10–15 px`；
- 如历史地点本身存在数公里级学术争议，使用 canonical 点位并记录置信度，而不是在成图中画问号；
- 文字标签可以从点位向外偏移；
- 标签偏移较大时可以使用克制的 leader line / 指示线。

## 3.2 郡国 / 州 = 区域，不是一个“城市点”

郡国标签不能用“郡治坐标 = 郡名文字位置”处理。

正式流程：

```text
所属高价值城邑 / 郡治
+ 郡的大致空间范围
+ 山河边界与邻接关系
→ 确定视觉区域
→ 在区域空白处放郡名
```

因此：

- 郡名可以远离郡治；
- 郡名位置可以为城市与山河让位；
- 郡名排版偏移不代表行政范围改变；
- 不创建伪郡名或伪行政实体。

## 3.3 正式文字 = 独立排版层

下一张 AI 无字底图中**不允许出现正式汉字**。

正式标注阶段统一使用：

- 简体中文；
- 真实字体渲染；
- 可编辑文字层；
- 州 / 郡 / 城 / 关隘 / 山河各自独立视觉层级。

图像模型生成出的中文、异体字、繁体字、伪汉字均不得成为正式资产文字。

# 7. 自然地理：先锁“路径 / 面”，不是只锁文字

第二张概念图的问题之一是大量河流和山脉由模型自由生成。

下一阶段自然地理必须拆为：

## 7.1 水系路径

一级水系必须先有明确路径：

- 黄河
- 长江
- 淮水
- 汉水
- 渭水

二级水系再加入：

- 汾水
- 泾水
- 洛水
- 漳水
- 济水
- 湘水
- 沅水
- 赣水

特别是**济水、古湖泽、历史河道变化区**，不得直接照现代水系描线。

## 7.2 山地面 / 山脊方向

一级地形骨架：

- 秦岭
- 太行山系
- 阴山
- 祁连山
- 巫山
- 五岭 / 南岭体系
- 巴蜀盆地周缘

模型只能在这些已经确定的山地范围和走向上进行绘画化表现，不能重新发明山脉走向。

# 8. 正式文字与清晰度规范

## 8.1 简体中文硬约束

正式地图：

> **100% 使用现代简体中文显示字形。**

历史专名保留历史名称，但字形使用简体。除非某专名没有常用简体对应，才单独记录例外。

## 8.2 不让 AI 生成文字

无字美术母版中：

- 不生成州名；
- 不生成郡名；
- 不生成城市名；
- 不生成河山名；
- 不生成伪文字装饰。

正式文字由可编辑真实字体层后置完成。

## 8.3 2K 清晰度审核

字体视觉测试必须直接在 `2560×1440` 预览，不以 8K 母版放大观看代替。

建议后续测试至少包含四档：

1. 州级大标题；
2. 郡国中字号；
3. 城市 / 地点小字号；
4. 山河沿线文字。

中小字号以阅读性优先，不使用过度狂草 / 难辨识书法字形。

# 9. “古意而不做旧”的底图洁净度规范

第二张概念图的信息量接近目标，但视觉偏脏。下一张无字底图明确禁止通过随机噪声制造古意。

## 9.1 底材

允许：

- 浅暖米白 / 绢本色；
- 极弱纸绢纤维；
- 轻微自然色差。

禁止：

- 大面积黄褐旧纸；
- 污渍；
- 霉点；
- 折痕；
- 大颗粒噪点；
- 随机墨污。

## 9.2 地貌密度

- 平原保持较大安静面；
- 一级山脉明确，二级山地克制；
- 普通丘陵不铺成满屏碎山；
- 河流线宽有清楚层级；
- 海面简洁，不用密集水纹填满；
- 装饰纹理永远不得压过地理结构。

目标是：

> **现代高清游戏地图 + 中国传统舆图 / 山水艺术语言**

而不是：

> **泛黄、破旧、难读的古董地图。**

# 10. 当前信息密度冻结

Owner 已确认第二张概念图的信息密度量级可接受。

因此当前标准版仍以：

> **约 120–140 个有效信息对象**

作为首轮 2K 全屏排版量级。

下一阶段不再主动扩大候选池；重点从“增加内容”转向：

- 位置准确；
- 层级明确；
- 简体清晰；
- 局部碰撞合理；
- 底图干净。

# 11. 后续 Gate

## GEO-1｜核心点位锁定

通过条件：

- A 级城市 / 地点大部分完成历史坐标核对；
- 已知时代敏感点有明确 canonical / provisional 状态；
- 不再存在“模型自己判断城市在哪”的空间。

**GEO-1 通过前不生成新的正式地图概念成图。**

## GEO-2｜自然地理骨架

通过条件：

- 海岸线基准；
- 一级山脉 / 盆地 / 平原；
- 一级水系路径；
- 主要湖泽历史形态策略。

输出：无字、无城、无标签的结构图。

## VIS-1｜干净无字美术底图

在 GEO-2 结构上进行美术化，只审核：

- 地貌；
- 色彩；
- 干净度；
- 中国传统艺术语言；
- 2K 全屏整体观感。

## GEO-3｜点位测试图

在已经通过的无字底图上加入真实位置的城市 / 关隘符号，**仍不加文字**。

审核城市是否真正处于正确的山河空间。

## TXT-1｜正式简体标注

最后才加入真实字体文字层，并做 2560×1440 碰撞与清晰度审核。
