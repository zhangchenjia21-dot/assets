# 乱世三国｜天下地理总图 GEO-1 通过记录 CURRENT

## 0. Gate 结论

`GEO-1｜核心点位锁定` **通过**。

通过不表示所有历史地点都已经达到考古测绘级精度，而表示：

> **决定天下图空间结构的高价值地点已经有历史坐标、遗址区域或明确的区域型约束；不存在需要图像模型凭感觉决定核心地点位置的情况。**

从本 Gate 起，AI / 图像生成模型仍然不得自行移动、创造或重新解释城市、关隘和战略节点位置。

---

# 1. 最后六组 A 级点处理

## 1.1 襄平｜ANCHORED-REGION

- 东汉辽东郡治襄平可以可靠锁定在**今辽宁辽阳市老城区核心范围**；
- 当前没有足够依据声称某一个现代街区坐标就是汉末古城中心；
- GEO-3 点位测试时采用“辽阳老城区域锚”，不由 AI 猜测；
- 后续如取得更精确考古城垣资料，再微调符号点。

结论：**不阻塞 GEO-1。**

## 1.2 濮阳｜ANCHORED-REGION

- 秦汉濮阳县为东郡核心县；历史地理资料明确其故城位于**今河南濮阳县西南一带**，与后世澶州 / 现代濮阳城市中心不是同一个可以无条件替代的点；
- 建安中东郡治复还濮阳，因此三国 Narrative 中濮阳必须处于古黄河南岸、东汉大河起始转折附近的正确空间；
- GEO-3 采用“古濮阳故城区域锚”，不使用现代濮阳市中心作为历史点。

结论：**不阻塞 GEO-1；精确古城中心可后补。**

## 1.3 南郑｜ANCHORED-REGION

- 东汉初汉中郡治迁回南郑，汉末张鲁、曹操、刘备时期汉中郡治均在南郑；
- 汉中市政府与陕西地方志均明确南郑对应**今汉中城市核心 / 汉中盆地古城区域**；
- 地方志还记载南郑大城、小城等古城结构，足以约束在盆地与汉水关系中的正确位置。

结论：GEO-3 先使用**汉中老城 / 南郑古城区域锚**，不阻塞 GEO-1。

## 1.4 合肥｜ANCHORED-REGION

- 汉合肥县属九江郡；历史地理资料明确**汉合肥故城在后世合肥城北 / 东北**，不能把现代市中心直接当作汉县唯一点；
- 合肥在三国中的战略价值很高，因此符号必须保留；
- GEO-3 采用“汉合肥故城区域锚”，后续再结合故城 / 金斗门等遗址资料细化。

结论：**不阻塞 GEO-1。**

## 1.5 姑臧｜ANCHORED

- 《一统志》等资料明确“姑臧故城，今武威县治，汉置为武威郡治”；
- 东汉武威郡与凉州核心空间可可靠落在**今甘肃武威老城区域**；
- 当前足以作为天下尺度点位，不需要为了 2K 图追求城墙某一角点坐标。

结论：升级为 **ANCHORED**，可进入 GEO-3。

## 1.6 夏口｜PERIOD-SENSITIVE STRATEGIC AREA

“夏口”不能在中立天下图中简单处理成一个永恒不变的城市点：

- 汉末“夏口”首先是**汉水入长江口及武汉江面一带的战略空间概念**；
- 刘表 / 黄祖时期的重要据点包括汉阳鲁山一带的郤月城、沙羡等；
- 孙权在黄武二年（223）于今武昌蛇山一带筑夏口城，这是一个明确的阶段性城市形态；
- 因当前总图不冻结单一历史时点，直接用 223 年后的夏口城点去代表整个汉末会造成时代混合。

因此当前处理改为：

> **把夏口列为“汉水—长江汇合口战略区域”，不作为 GEO-1 必须锁死的城市点。**

正式标准版是否显示“夏口”文字，留到 TXT-1 根据地图整体年代中立策略决定；无字底图只需保证汉水入江、武汉江段及周边地形正确。

# 2. GEO-1 通过后的制图权限

现在允许进入：

- `GEO-2` 一级河流水系路径；
- 一级山地 / 盆地 / 平原结构；
- 历史湖泽与海岸策略；
- 第一张**无文字、无城名、无州郡名**的结构底稿。

仍然禁止：

- AI 自行决定城池位置；
- AI 生成正式中文；
- 直接生成完整标注成图；
- 为填满 16:9 横向拉伸地理；
- 把现代河道 / 湖岸无条件复制成汉末状态。

# 3. GEO-3 点位测试使用规则

后续点位测试图：

- `LOCKED`：绘制明确点符号；
- `ANCHORED`：绘制点符号，但允许在历史区域内小幅校正；
- `ANCHORED-REGION`：先绘制小型区域圈 / 区域锚，不伪装成精确城中心；
- `PERIOD-SENSITIVE`：不在中立点位图中强制绘制城市符号；
- `PROVISIONAL`：继续禁止进入正式点位测试。
