# 乱世三国｜关中—弘农—雒阳关隘与交通核验

## 0. 职责

本文件只记录会直接改变 `L2-01` 画法的最小历史核验，不建立整个司隶县级数据库。

本轮资料基线：

1. Owner 提供的“汉末司隶 / 司隶部”历史地图扫描：作为长安—弘农—雒阳一线的主要城邑、行政与道路相对关系参考；
2. Owner 此前提供的景元三年（262）司隶地图：仅作为雒阳—河南尹—河内等东半段补充，不决定汉末完整区域范围；
3. Level 1 已批准天下图 / 一级山河数据：继续作为地形拓扑与视觉 DNA 的上位 Authority；
4. 经典地理文献与后世地志用于核高风险关隘的时期与位置语义。

> 资料图用于相对关系和候选对象筛选，不按扫描像素直接当测绘底图。

---

# 1. 函谷关

## 1.1 结论

`L2-01` 默认显示 **函谷关**，采用汉武帝以后东移至新安方向的“汉函谷关”语义，而不是把秦代旧函谷关与汉代新关混为一个点。

历史地志材料一致指出：汉武帝元鼎三年（前114）徙关于新安；东汉仍有函谷关守备与屯田记载。汉末献帝西迁时，相关材料仍将所出之关记为函谷关。

## 1.2 制图策略

- canonical display：`函谷关`；
- 位置语义：新安—谷城交界附近 / 新安以东的崤函通道；
- 状态：`ANCHORED-REGION`，不冒充单一现代景区点；
- 视觉职责：弘农—河南尹之间的东向门户；
- 不在同一标准图上再额外突出“秦函谷关”，除非高信息版需要解释新旧二关。

---

# 2. 潼关

## 2.1 结论

潼关在三国叙事中价值极高，但其名称 / 关防在汉末前段并非始终与后世潼关等价。

《元和郡县志》材料指出：献帝初平二年（191）西迁仍“出函谷关”；至建安十六年（211）曹操破马超时已明确出现“潼关”。因此对于覆盖“汉末—三国”的中立区域图，潼关应标记为 **PERIOD-SENSITIVE**。

## 2.2 制图策略

- canonical display：`潼关`；
- metadata：`PERIOD-SENSITIVE`；
- 位置语义：华阴东北、黄河南岸、关中东门；
- 可以进入标准区域图，因为其三国 Narrative 价值不可替代；
- 不把它描述成整个东汉时期都已固定存在的同名关隘；
- 如游戏 UI 支持 tooltip，应说明“汉末建安时期已见于史料”。

---

# 3. 武关

## 3.1 结论

武关是关中向南阳 / 荆襄方向的重要南向门户，长期地理意义稳定，适合进入 `L2-01`。

传统地理文献持续记录“出武关—抵南阳 / 洛阳”等南北交通语义，其功能不是普通山中装饰节点，而是控制关中南出路线的真实门户。

## 3.2 制图策略

- canonical display：`武关`；
- 状态：`ANCHORED-REGION`；
- 路线语义：`长安 → 蓝田 → 武关 → 南阳方向（出图）`；
- 画面中必须让武关落在山地通道上，不得放在开阔平原或与长安—雒阳主轴混成同一路线。

---

# 4. 成皋 / 虎牢

## 4.1 结论

汉代行政上存在 **成皋县**，其地与虎牢险要高度重合；后世“虎牢关”名声很大，但在汉末中立地图上直接把一个永久正式关隘写成“虎牢关”会过度吸收后世 / 演义语义。

## 4.2 制图策略

标准版优先：

- 地点 / 城邑：`成皋`；
- alias / tooltip：`虎牢`；
- 空间职责：雒阳东侧、黄河南岸的东向门户；
- 如未来专题图需要强调十八路诸侯等叙事，可单独使用“虎牢”专题语义；
- 本 Pilot 不默认把“虎牢关”作为与成皋并列的第二个永久关隘点。

---

# 5. 主交通骨架

Owner 提供的汉末司隶图清楚支持一条从关中向雒阳的东西向连续城邑 / 道路轴。`L2-01` 不逐像素描摹旧图道路，而冻结以下控制链：

```text
长安
→ 新丰
→ 华阴 / 潼关方向
→ 弘农
→ 陕县
→ 黾池
→ 新安 / 函谷关
→ 雒阳
```

其中：

- `潼关` 为时期敏感战略节点，不要求所有历史阶段都作为同一正式关门；
- `函谷关` 负责新安方向的崤函门户语义；
- 主路应受渭水、黄河、华山—崤山等地形约束，不画成贯穿山体的现代直线。

---

# 6. 南向通道

冻结最小控制链：

```text
长安
→ 蓝田
→ 武关
→ 南阳方向（出图）
```

本 Pilot 只需要表现“关中存在一条受山地门户控制的南向替代路线”，不深入完整南阳盆地，也不建立沿线所有县邑。

---

# 7. 雒阳东向出口

为了让雒阳不是贴在地图东边缘的终点，本 Pilot 东侧保留少量河南尹缓冲：

```text
雒阳
→ 巩县方向
→ 成皋（虎牢）
→ 中原方向（出图）
```

东部只承担“世界继续向东”的出口语义，不扩展完整荥阳—陈留地图。
