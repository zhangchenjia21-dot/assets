# 乱世三国｜天下地理总图历史地理核验记录 CURRENT

## 0. 用途

本文件记录会直接改变天下总图画法的历史地理核验结论，避免后续只剩“某次 Prompt 是这样画的”而无法追溯依据。

原则：

> **只记录会影响制图的事实；不把资料中的不确定结论伪装成绝对真值。**

---

# 1. 黄河下游｜东汉河道必须区别现代黄河

## 结论

东汉明帝永平十二年（69），王景治河后形成长期相对稳定的东汉黄河下游河道。制图层面采用：

```text
河南北部 / 濮阳附近
→ 范县方向
→ 鲁西北
→ 滨州方向
→ 利津附近入渤海
```

因此：

- 不直接描现代山东黄河下游；
- 黄河在兖、冀、青之间的屏障关系需要按东汉大河重新组织；
- 黄河三角洲不复制现代入海口。

参考：

- 山东黄河文化经济发展促进会，《黄河国家文化公园建设探究》：记载王景治河及东汉故道经濮阳、范县、莘县、阳谷、东阿、茌平、滨州，利津附近入海。
  `https://www.sdhhcjh.com/sys-nd/748.html`

# 2. 南郑｜汉末汉中核心位置

## 结论

东汉建武六年（30）汉中郡治由西城迁回南郑。官方地方资料将当时南郑古城约束在今汉中市汉台区二道关、新桥一带；隋代以后又有迁城。

因此：

- 三国汉中核心城不能拿现代行政意义的“南郑区中心”替代；
- 天下尺度可以使用汉中老城 / 南郑古城区域锚；
- 汉水与汉中盆地关系必须围绕该历史核心组织。

参考：

- 汉中市政协，《往事并不如烟——说说与西汉三遗址有关的老照片及其背后的那些事儿》。
  `https://zx.hanzhong.gov.cn/hzzxwz/dsjl/202511/7896c69aae3143bcbbc4e21ecf40abc1.shtml`

# 3. 姑臧｜东汉晚期使用武威城区核心，而非早期三盘磨治所

## 结论

资料指出：姑臧县治早期在今武威市凉州区金羊镇三盘磨村一带，**东汉桓帝延熹初年迁到今武威城区**。

这对汉末三国尤其重要，因为我们的 Narrative 高价值阶段主要晚于这次迁治。

因此：

- 天下图 `姑臧` 可以使用今武威老城区域作为汉末锚点；
- 不应因为西汉 / 东汉早期治所在三盘磨就把汉末姑臧画到错误位置。

参考：

- 凉州文化网，《两汉时期武威郡县治所略述》。
  `https://www.lzwenhuawang.com/show-21-773-1.html`
- 《通典》《旧唐书》亦长期记录姑臧为凉州 / 武威核心。

# 4. 濮阳｜古濮阳故城与现代城市中心不能直接等同

## 结论

历史文献长期把秦汉濮阳与帝丘联系起来，并明确后世存在迁治。旧濮阳城相对后世州治存在位置差异。

因此：

- 当前使用 `ANCHORED-REGION`；
- 不把现代濮阳市中心直接钉为东汉濮阳县点；
- 无字地理图首先确保濮阳战争空间位于东汉黄河下游转折区域；
- GEO-3 再使用古濮阳故城区域符号。

参考：

- 《通典》州郡有关濮阳 / 濮州条；
- 《舆地广记》有关濮阳故城与后世迁治记载；
- 历史地方志关于帝丘 / 濮阳故城记录。

# 5. 夏口｜作为时期敏感战略区域，不做跨时代固定城市点

## 结论

“夏口”在汉末至孙吴时期涉及汉水入江口、沙羡、沔口以及孙权黄武二年（223）所筑夏口城等不同空间 / 城防阶段。

因此中立天下图不把 223 年后的具体夏口城址倒推成整个汉末的固定城市点。

处理：

> **无字底图固定汉水—长江汇合与武汉江段；“夏口”文字 / 城市符号留到 TXT-1 做时期敏感决定。**

参考：

- 《水经》《水经注》关于沔水、沙羡和江水关系；
- 后世文献关于孙权黄武二年筑夏口城的记录；
- 汉末沙羡 / 夏口治所研究存在不同解释，因此当前保留时期敏感状态。

# 6. 彭蠡泽 / 鄱阳湖｜不能直接复制现代鄱阳湖轮廓

## 结论

历史地理研究对于古“彭蠡泽”具体指称存在讨论，但对制图最重要的一点相对一致：**秦汉 / 三国阶段不能直接套用现代鄱阳湖向南大幅扩展后的巨大轮廓。**

研究资料指出秦汉时期今鄱阳湖南部大面积区域仍是河网 / 平原环境，后世湖体继续扩展。

因此：

- 天下图用较克制的北部 / 湖口—赣水下游水域与湿地表达；
- 不复制现代鄱阳湖形状；
- 正式文字采用“彭蠡泽相关历史水域”时保持资料不确定意识。

参考：

- CCTV 国家地理，长江专题关于彭蠡泽—鄱阳湖演变。
  `https://www.cctv.com/geography/special/changjiang/20040607/101390.shtml`
- 中国人民大学国学院相关历史地理研究报道。
  `https://guoxue.ruc.edu.cn/wzsy/xwsd/4573c8416f9642d49cc134d3a73dbe5f.htm`

# 7. 云梦泽｜复合湖沼湿地，不是单一巨湖

## 结论

江汉地区在长期演变中经历湖沼、河流分汊与陆地扩展。天下图如果把“云梦泽”画成一块边缘完整的大蓝湖，会制造错误空间印象。

因此：

- 江汉平原表达为平原 + 湖沼 + 水网 + 湿地 + 洲滩；
- 允许若干浅水块，但不画单一封闭湖体；
- 后续文字“云梦泽”代表历史区域概念，不要求对应一个现代湖岸多边形。

参考：

- 中国人民大学清史研究所历史地理资料关于云梦泽解体与江汉—洞庭水系演变。
  `https://iqh.ruc.edu.cn/old/zglsdlyj/lsdl_lzjj/qsdlyj/b94f7f4c2cff49b0a17fdb8286398a39.htm`

# 8. 三角洲 / 海岸历史化

## 8.1 长江三角洲

原则：现代上海—长江口冲积形态是长期泥沙堆积结果，汉末不复制现代突出岸线与围垦地。

处理：

- 海岸整体更内收；
- 长江口更宽、更水域化；
- 不追求 2K 天下尺度的考古海岸逐公里复原。

## 8.2 黄河三角洲

因东汉大河入海位置与现代不同，直接跟随第 1 节东汉河道重建，不使用现代黄河三角洲。

## 8.3 珠江三角洲

珠三角同样经历长期淤积、围垦和岸线推进。汉末整体应比现代更海湾 / 水域化。

当前属于制图级历史化原则；正式海岸形态在 GEO-2 结构图里只做天下尺度的合理收缩，不宣称测绘级复原。

# 9. 资料置信等级

后续研究记录统一：

- `HIGH`：CHGIS、官方遗址 / 文保、稳定历史地理共识可以直接支持制图；
- `MEDIUM`：多个历史地理来源支持大方向，但精确城址 / 水岸仍有不确定；
- `LOW / DISPUTED`：存在明显不同学说，只记录，不让图像生成模型替我们选答案。

地图在天下尺度追求的是：

> **高可信空间关系 + 明确记录的合理抽象，而不是伪造精确。**
