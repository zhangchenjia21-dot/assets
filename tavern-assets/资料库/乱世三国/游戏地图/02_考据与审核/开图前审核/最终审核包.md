# 2. 本轮重新审核后的开图前提

## 2.1 世界范围

下一张天下底图必须以三国实际叙事世界为主体：

- 西到凉州 / 河西走廊，敦煌方向可保留，西域不展开；
- 西南保留益州、南中所需地理，不展示大片青藏高原；
- 北保留并州、幽州北缘与少量塞外背景；
- 东到辽东半岛及必要海域；
- 南覆盖岭南与交州；
- 东亚其他大面积区域不作为当前天下图主体。

该范围属于游戏世界构图，不修改历史行政事实。

## 2.2 地理事实层与玩家构图层分离

Albers 工作投影继续作为事实校准层。

但最终玩家画面允许在事实骨架上进行**受控、局部、拓扑保持的叙事性制图形变**，以给关中、中原、荆襄、巴蜀、江淮、江东、河北等高价值区域分配足够视觉面积。

不得：

- 全图统一横向拉伸；
- 单独搬动城市破坏周边山河关系；
- 为构图改变河流汇流、山脉屏障与区域邻接。

## 2.3 游戏化表达

下一版必须通过以下结构产生“游戏世界地图感”，而不是依靠换色滤镜：

- 一级山脉作为明显的屏障 / 门户；
- 黄河、长江、汉水等作为 Narrative 空间轴；
- 平原主动保留为安静的游戏 / 标注空间；
- 凉州、关中、河北中原、荆襄、巴蜀、江东、交州具有统一艺术语言下的区域环境差异；
- 四周边缘由荒漠、远山、云气、海域自然收束。

## 2.4 历史地理硬约束继续有效

以下既有数据 / 考据继续作为硬约束：

- 东汉黄河下游不能照现代山东河道复制；
- 云梦泽不能画成一个封闭巨湖；
- 彭蠡泽不能直接复制现代鄱阳湖巨大轮廓；
- 长江、黄河、珠江三角洲需要历史化；
- 城市 / 关隘位置由核心点位数据与证据约束，图像模型无定位权限。
