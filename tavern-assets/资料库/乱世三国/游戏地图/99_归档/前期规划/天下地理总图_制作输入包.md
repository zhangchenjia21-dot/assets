# 乱世三国｜天下地理总图制作输入包 CURRENT

## 0. 用途

本文件把地图核心规范转换为第一张 Level 1 天下地理总图的实际制作输入。

它负责：

- 当前参考资料如何使用；
- 16:9 / 2K 全屏目标；
- 地理骨架优先级；
- 标注候选池的信息预算；
- 郡国、城市、关隘与自然地理的筛选方法；
- 从无字母版到正式标注版的制作顺序与审核 Gate。

它不负责游戏本体 GUI 实现、势力状态、交互、缩放、Runtime Overlay 或 World Pack 机器协议。

现代河道、湖岸与行政线不自动等同汉末历史形态；存在明显历史变化的水体在正式落笔前单点核实。

# 2. 画幅与实际使用目标

## 2.1 玩家目标视图

Level 1 天下地理总图的主要产品使用形态：

> **16:9 全屏地图 GUI**

主要审阅目标：

> **2560 × 1440（2K）**

地图应在 2K 全屏状态下直接承担较丰富的世界认知，而不是按照侧栏缩略图的信息密度设计。

## 2.2 美术母版

首选生产基线：

> **7680 × 4320（8K UHD，16:9）**

或同等 / 更高质量的可编辑 16:9 源。

8K 母版用于：

- 精细地貌；
- 分层标注；
- 后期调整；
- 2K 等比缩小后的抗锯齿与清晰度；
- 未来不同导出尺寸。

不得因为 8K 状态下文字看得清，就跳过 2560×1440 实际预览审核。

# 3. 天下总图覆盖与构图原则

覆盖范围应足够表达汉末三国主要叙事世界：

- 西部：河西走廊及敦煌方向；
- 北部：并、幽北缘；
- 东北：辽东；
- 东部：山东与东海岸；
- 南部：岭南、交州方向；
- 西南：巴蜀、南中方向。

视觉重心优先落在：

> **关中—河北—中原—荆襄—巴蜀—江淮—江东**

边疆存在，但不与核心三国叙事区使用同等标签密度。

构图不得为了填满 16:9 画面而任意拉伸或扭曲关键地理关系。

---

# 4. 信息预算

2K 全屏允许比普通地图面板更高的信息密度，但天下图仍然是叙事世界地图，不是行政志。

当前候选池目标：

| 类别 | 候选池量级 | 原则 |
|---|---:|---|
| 州级标签 | 全部 | 天下空间第一层框架 |
| 重点郡国 | 45–55 | 只保留高价值，不追求全部郡国 |
| 城市 / 地点 | 35–45 | 优先真正可能被玩家遇到、提及、前往的地点 |
| 关隘 / 战略节点 | 10–15 | 只保留显著帮助空间与旅程理解者 |
| 山河湖泊标签 | 20–30 | 地貌可以丰富，文字不必覆盖全部地貌 |

上述是**宽候选池**，不是最终成图 KPI。

最终数量必须通过 2560×1440 排版测试收敛；如果地图拥挤，删减低价值标签优于缩小全部文字。

# 5. 郡国筛选方法

天下图允许省略、弱化和视觉合并低价值郡国，不追求东汉全部郡国完整呈现。

## 5.1 重点郡国进入候选池的判断维度

优先判断：

1. **三国历史知名度**：玩家是否高频接触该郡国名称；
2. **政治价值**：是否长期承担重要政治中心 / 区域中心；
3. **军事价值**：是否长期影响战争、边防或战略纵深；
4. **交通价值**：是否是重要水陆通道、山口、边疆或区域连接处；
5. **叙事价值**：是否高频关联重要人物、事件、旅程或生活叙事；
6. **空间认知价值**：是否能帮助玩家理解一个仅靠城市名难以表达的大区域；
7. **游戏使用可能**：未来世界内容是否很可能频繁用到该名称。

通常满足多个维度者才进入总图候选池；低价值者留到 Level 2 区域地图。

## 5.2 合并边界

允许：

- 天下尺度省略低价值郡国标签；
- 不画全部郡界；
- 相邻低价值行政空间在视觉表达上合并为连续区域。

禁止：

- 创造历史上不存在的新郡名；
- 为了排版改变关键城市 / 郡国之间的基本空间关系；
- 让视觉合并被误读成新的历史行政实体。

---

# 6. 城市 / 地点筛选方法

高价值具体地点的优先级高于低价值行政完整性。

候选城市 / 地点重点看：

- 历史与大众知名度；
- 政治中心地位；
- 军事重镇；
- 水陆交通节点；
- 重要人物长期活动地；
- 著名历史事件 / 三国叙事关联；
- 未来 Narrative 高频使用可能；
- 是否显著帮助玩家理解区域。

排版冲突时：

> **重要城市 / 地点优先于冷门郡国标签。**

候选池可以包含行政等级不高但三国叙事价值极高的具体地点。

---

# 7. 关隘 / 战略节点筛选方法

天下图不追求完整军事设施目录。

一个关隘 / 战略节点值得进入总图的核心判断是：

> **如果不显示它，玩家是否会明显更难理解区域之间为何难以通行、为何成为战争与旅行关键节点。**

候选包括真正关隘，也可以包括对天下尺度有意义的山口、渡口、战略通道和高知名度战役地理节点。

正式标注前逐项核实汉末名称适用性，避免直接把后世习惯称谓当作无时间条件的汉末事实。

# 8. 自然地理优先级

## 8.1 一级水系骨架

第一版无字母图优先建立：

- 黄河；
- 长江；
- 淮水；
- 汉水；
- 渭水。

## 8.2 二级水系候选

后续依据画面空间与历史核实加入，例如：

- 汾水；
- 泾水；
- 洛水；
- 漳水；
- 湘水；
- 沅水；
- 赣水；
- 济水等历史高价值水系。

## 8.3 一级山地 / 地形屏障

至少在地貌中明确表达：

- 秦岭；
- 太行山系；
- 阴山；
- 祁连山；
- 巴蜀周边山地；
- 巫山；
- 五岭 / 南岭体系；
- 其它决定大区域空间关系的高价值山地。

并非所有山地都必须标文字；**地貌存在与文字标注是两个层级。**

## 8.4 湖泽

重点核查并表达对三国空间认知有价值的大型湖泽。古代湖泽与现代湖岸存在明显差异者，不直接照现代地图轮廓描绘。

# 9. 第一版不做

第一轮天下总图不优先处理：

- 势力范围；
- 势力颜色；
- 军队 / 战线；
- 玩家 / NPC 位置；
- 任务 / 事件图标；
- 全县级行政体系；
- 所有村镇；
- 完整道路网；
- 所有小型支流；
- 所有三国故事发生地点；
- 大量抢占地图空间的装饰性建筑插画。

# 11. 审核 Gate

## Gate A｜地理骨架

检查：

- 大陆 / 海岸轮廓是否合理；
- 山脉、盆地、平原关系是否可信；
- 黄河、长江等主干水系是否合理；
- 16:9 构图是否自然；
- 是否仍有足够空间承载后续信息。

通过后再进入行政 / 点位层。

## Gate B｜候选标注池

先建立宽候选池，不要求全部显示。

审核重点：

- 是否遗漏明显高价值地点；
- 是否存在大量仅为行政完整而保留的低价值郡国；
- 城市 / 关隘 / 山河是否获得足够地图空间。

## Gate C｜2K 全屏排版

使用 2560×1440 等比预览检查：

- 第一眼是否能读出山河与州；
- 第二层是否能读到主要城市；
- 仔细查看时是否能读到重点郡国 / 关隘；
- 中原、荆襄、江淮等高密度区域是否发生严重文字碰撞；
- 边疆是否因低密度而显得空洞或被无意义装饰填满。

如果拥挤：

> **优先删除低价值标签，不通过把所有文字整体缩小解决。**
