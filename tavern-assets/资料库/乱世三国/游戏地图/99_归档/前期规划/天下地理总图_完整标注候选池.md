# 乱世三国｜天下地理总图完整标注候选池 CURRENT

## 0. 文档用途

本文件是第一张 Level 1 天下地理总图的**标注候选池**，供 Owner 做取舍审核，并在后续 2560×1440 实际排版中继续收敛。

本文件不追求东汉行政体系完整复原，而遵循已经冻结的游戏地图原则：

> **行政完整性不得压过游戏可读性。**
>
> **历史决定它在哪里；叙事价值决定它有多醒目。**
>
> **高价值具体地点 > 低价值行政完整性。**

当前目标不是把所有候选都塞进成图，而是先建立**足够宽、可审计、可删减的候选池**。

- 对具体高价值点位再进行单点历史核对。

《后汉书·郡国志》提供的是完整行政事实底稿；**本文件的取舍等级属于游戏地图美术决策，不是史料自身的“重要性排名”。**

## 1.2 优先级含义

本文件统一使用：

- **A｜标准版核心候选**：优先进入 2K 全屏标准地图；除非实际排版发生严重冲突，否则应保留。
- **B｜标准版扩展候选**：具有较高价值，优先尝试进入标准版；局部拥挤时可以降级到高信息版。
- **C｜高信息 / 区域备用**：不要求进入标准版；用于填补空间、增强边疆或作为后续区域图输入。

A / B / C 表示**天下图空间优先级**，不是历史价值的绝对排名。

## 4.1 城市去重原则

发生郡名与城名空间冲突时：

- `颍川郡` 与 `阳翟` 可以同时存在，但郡名更区域化、城市更点状；
- `平原郡` 与 `平原` 若 2K 预览显得重复，可优先保留城市符号 + 郡名弱化；
- `长沙郡` 与 `临湘` 可以共同表达“区域 + 城”；
- 重要具体地点不得因为同名 / 近名行政标签而被机械删除。

# 9. 历史时期敏感标签清单

当前不冻结单一历史基准时点，因此以下名称不得在没有单点核对的情况下直接当作“整个汉末三国永久不变标签”：

- 许 / 许昌：基础地图优先用汉末高价值名称“许”；不同阶段名称另核。
- 夏口：高价值，但名称与具体城市 / 港口形态具有阶段性。
- 秣陵 / 建业：同一核心区域存在明显时代更名，当前中立图优先把“秣陵”作为候选，最终文字需按地图目的确认。
- 公安：高价值但明显属于特定历史阶段，不作为无时点标准图强制项。
- 成皋 / 虎牢：空间价值高，名称表达需避免把后世熟称无条件前置。
- 阳平关：不同资料对关名、关址与时代存在差异，正式落图前专门核。
- 剑阁 / 剑门：三国叙事价值极高，但具体关防名称与阶段需要专门核。
- 白帝 / 白帝城：高知名度，具体显示名与城市 / 山城关系需单点核。

这些问题**不阻塞无字地理母版**。
