# 乱世三国｜游戏地图

这里保存《乱世三国》游戏地图的**当前规范、制图数据、考据证据与美术产出**。

> Root is map; subfolders are depth.

## AI Start Here

默认读取顺序：

1. [`AGENTS.md`](AGENTS.md)
2. [`00_当前规范/游戏地图美术核心规范.md`](00_当前规范/游戏地图美术核心规范.md)
3. 按任务层级读取对应 Rule Owner：
   - Level 1 → [`00_当前规范/天下地理总图制图规范.md`](00_当前规范/天下地理总图制图规范.md)
   - Level 2 → [`00_当前规范/区域地图制图规范.md`](00_当前规范/区域地图制图规范.md)
4. 只读取任务需要的 `01_制图数据/` Owner
5. 只有追溯“为什么这样定 / Gate 是否通过”时进入 `02_考据与审核/`
6. 图片、母版和正式输出进入 `03_产出/`
7. `99_归档/` 默认不进入初始上下文

不要一次性读取整个目录。
