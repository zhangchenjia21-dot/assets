# 通用拓展包资产库总蓝图 v1.0

> 当前通用资产库已有 **13 个 Existing Reusable Expansion**；其中 10 个稳定语义基线、3 个通用超自然候选。`EP-POLITICS-CORE｜政治与公共权力核心 v0.1` 已 PASS / AUDITED CURRENT；汉末 Politics 迁移规划已完成，当前安全 NEXT = **Han Politics migration execution**。

## 1. 顶层原则

```text
Generic Expansion != World Pack
first consumer != generic owner
Full Semantic Asset != Model Prompt Payload
Dependency Graph != Context Inclusion Graph
Hard Dependency != Transitive Prompt Inclusion
Whole Relation Graph != Model Prompt
World / Instance Growth != Prompt Growth
```

资产 / 模型不拥有 RNG、Program Judge、Formal Outcome、Atomic Commit、Save / Restore authority。

## 5. Politics Reference

`EP-POLITICS-CORE v0.1` 冻结：

```text
Regime != Government Organization
Role Holding != Public Authority
Internal Authority != Public Authority
Claim != Recognition != Control != Occupation != Jurisdiction
Public Reputation != Political Recognition
Kinship Fact != Succession Outcome
Political Agreement != Commitment Promise Lifecycle
```

Politics Hard Depend ORG；Kinship / Reputation / Relationship / Character / Health 为 optional integrations。

不建立 universal loyalty / legitimacy / stability / control score。
