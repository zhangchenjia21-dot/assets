# 通用拓展包资产库总蓝图 v0.9

> 当前通用资产库已有 **12 个 Existing Reusable Expansion**；其中 9 个稳定语义基线、3 个通用超自然候选。`EP-KINSHIP-CORE｜家族与亲缘核心 v0.1` 已 PASS / AUDITED CURRENT，Shared Foundation 当前 NEXT = `EP-POLITICS-CORE`。

## 1. 顶层原则

```text
Generic Expansion != World Pack
first consumer != generic owner
Full Semantic Asset != Model Prompt Payload
Dependency Graph != Context Inclusion Graph
Hard Dependency != Transitive Prompt Inclusion
World / Instance Growth != Prompt Growth
```

资产 /模型不拥有 RNG、Program Judge、Formal Outcome、Atomic Commit、Save / Restore authority。

## 5. Kinship Reference

`EP-KINSHIP-CORE v0.1` 新增稳定边界：

```text
Family / Lineage != Organization
Kinship Truth != Relationship Sentiment
Marriage Truth → Relationship
Affinal Structure → Kinship derived view
Genealogy Claim != Authoritative Kinship Truth
Surname != Family Identity
Biological Parentage != Legal / Political Recognition
```

大型谱系采用“源关系 + 程序图查询 + 当前问题有界切片”，不保存全部 pairwise 亲属称谓。

Pattern：`[[通用资产库_RuntimeContextContract模式_v0.5]]`；Index：`[[通用资产库_RuntimeContextContract索引_v0.5]]`。


## 7. World / Game-local Reality

```text
Generic Source Asset
→ World-specific composition / bind
→ Game-local canonical definition
→ Runtime State
```

Kinship 的具体 Family / Character / parentage 都属于单局 Game-local reality；Source Generic Core 只定义语义合同，不被单局反写。
