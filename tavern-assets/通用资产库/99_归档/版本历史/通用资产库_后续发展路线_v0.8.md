## 3. Kinship 已完成价值

Kinship 现在为 Politics / Law 等未来消费者提供：

- 家系 / 分支身份；
- 亲本 / 后代路径；
- 收养 /正式认亲结构；
- 谱系主张 /证据边界；
- 争议亲缘状态；
- 当前问题所需的 bounded genealogy slice。

不提供继承结果、政治合法性或法律判断。

## 4. Politics 开工前必须守住

```text
家族出身 != 政治权力
官职 / Role != Public Authority
政治主张 != 政治承认
政治承认 != 实际控制
社会声望 != 统治合法性
```

汉末三国迁移不得再次让 World-specific Politics 成为 ORG / Kinship 的重复 Owner。

## 5. Context / Scale

后续 Politics 需要特别检查：

- 势力 /政治关系图增长时普通 Turn 是否仍 bounded；
- Kinship 只提供当前政治主张所需谱系切片；
- ORG 只提供当前 Role / Organization projection；
- Reputation 只提供相关社会评价；
- 不因“政治可能产生经济 /战争后果”提前加载 Economy / War。

Kinship 未暴露新的阻塞性上游缺口。`源关系优先 + 程序图查询 + 有界局部投影` 当前先作为 Kinship 领域实践；待 Politics / Knowledge 等第二个大型图领域验证后，再决定是否升级为通用 Skill / Pattern 规则。
